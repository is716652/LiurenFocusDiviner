## 0. 当前策略与现状速览（先校准，再上清单）

| 策略声明（README & 鸿蒙规范文档） | 实际代码现状 | 是否一致 |
|---|---|---|
| 免费版全功能开放、无锁、无付费痕迹 | `MODE='free'` 下 `PayGate.isUnlocked()` 恒 true；`Index.ets` 的“🔒/解锁”行还有 `!PayGate.isUnlocked(...)` 条件，免费模式不会渲染 | ✅ 当前成立；关键约束是**免费版永远保持 `MODE='free'`** |
| 免费版隐藏新增收费研习入口 | `FeatureFlags.SHOW_ANCIENT_CASE_GALLERY`：主版 `true`，免费版同步后置 `false` | ✅ 一致 |
| 免费版零权限 | 免费版同步脚本移除 `module.json5` 的 `requestPermissions` | ✅ 一致；残留 `permission_internet_reason` 字符串可清理 |
| `PREVIEW_FREE` 旧开关语义 | 注释仍写“true=免费上架版隐藏付费区”，但当前策略已改为“免费版全开放、无锁”；`PREVIEW_FREE=false` 只表示开发/收费区可见，不等同出现锁 | ⚠️ 旧注释易误导，后续应重命名为 `DEV_SHOW_PAID` 或删除该开关 |
| 古籍断法为有出处可溯源的内容呈现 | 毕法教练、行年打分、管辂类神取用 JSON 均有古籍原文标注 + 白话/直释 | ✅ |

**核心结论**：当前免费版的合规红线不在 `PREVIEW_FREE=false`，而在三件事必须永远成立：① 免费版 `MODE='free'`（锁 UI 因 `isUnlocked=true` 不渲染）；② 免费版无 `INTERNET`/IAP；③ 新增收费研习内容（案例鉴赏）在免费版只随包隐藏、不出入口。真正收费前必须处理的是**祈使断语文案降级**。
