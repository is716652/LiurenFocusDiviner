### 1.1 核心功能模块评估

**1. 古籍案例重演功能** (`ClassicalCasesPage.ets`)

- **付费理由**：
  - 专业性极强，属于高端知识付费内容
  - 案例数量庞大，制作成本高
  - 对初学者具有很强的吸引力

**2. 格局识别与判断知识库** (`GejuKnowledgePage.ets`)
- **价值分析**：
  - 涵盖各种吉格凶格的专业判断标准

  - 包含古籍原文和现代解读
- **付费理由**：
  - 专业知识密集，学习门槛高
  - 实用性强，直接指导实践应用

**3. 基础知识深度学习** (`BasicKnowledgePage.ets`)
- **价值分析**：
  - 系统性的奇门遁甲理论体系
  - 图文并茂的专业教学内容
  - 从入门到精通的完整学习路径
- **付费理由**：
  - 替代传统书籍的价值
  - 结构化学习体验优于零散资料

**1. 九宫排盘研习** (`DunjiaPalacePage.ets`)

#### 主推方案：一次性买断制
- **价格区间**：¥29.9 - ¥49.9
- **适用模块**：古籍案例重演功能

  - 符合知识付费用户习惯

#### 第四步：核心代码实现
```typescript
// 支付功能实现示例
import iap from '@hmscore/iap';

@Entry
@Component
struct PremiumFeaturePage {
  @State isPurchased: boolean = false;
  @State productInfo: ProductInfo | null = null;
  
  aboutToAppear() {
    this.checkPurchaseStatus();
    this.loadProductInfo();
  }
  
  // 检查购买状态
  async checkPurchaseStatus() {
    try {
      const purchases = await iap.obtainOwnedPurchases({
        priceType: iap.PriceType.IN_APP_NONCONSUMABLE
      });
      this.isPurchased = purchases.itemList.length > 0;
    } catch (error) {
      console.error('检查购买状态失败:', error);
    }
  }
  
  // 加载商品信息
  async loadProductInfo() {
    try {
      const products = await iap.obtainProductInfo({
        priceType: iap.PriceType.IN_APP_NONCONSUMABLE,
        productList: ['fu_ying_case_studies']
      });
      if (products.productInfoList.length > 0) {
        this.productInfo = products.productInfoList[0];
      }
    } catch (error) {
      console.error('加载商品信息失败:', error);
    }
  }
  
  // 发起购买
  async purchase() {
    if (!this.productInfo) return;
    
    try {
      const result = await iap.createPurchaseIntent({
        priceType: iap.PriceType.IN_APP_NONCONSUMABLE,
        productId: this.productInfo.productId,
        reservedInfor: ''
      });
      
      // 处理购买结果
      if (result.returnCode === 0) {
        this.handleSuccessfulPurchase();
      }
    } catch (error) {
      console.error('购买失败:', error);
    }
  }
  
  // 处理购买成功
  handleSuccessfulPurchase() {
    this.isPurchased = true;
    // 保存购买状态到本地存储
    // 解锁相应功能
  }
}
```

### 2.3 安全与风控措施

#### 1. 本地状态保护
```typescript
// 购买状态本地存储
class PurchaseStorage {
  static readonly STORAGE_KEY = 'premium_purchase_status';
  
  static savePurchase(productId: string) {
    const status = {
      productId,
      purchaseTime: Date.now(),
      signature: this.generateSignature(productId)
    };
    Preferences.set(STORAGE_KEY, JSON.stringify(status));
  }
  
  static isPurchased(productId: string): boolean {
    const statusStr = Preferences.get(STORAGE_KEY, '');
    if (!statusStr) return false;
    
    try {
      const status = JSON.parse(statusStr);
      return status.productId === productId && 
             this.verifySignature(status.productId, status.signature);
    } catch {
      return false;
    }
  }
}
```
