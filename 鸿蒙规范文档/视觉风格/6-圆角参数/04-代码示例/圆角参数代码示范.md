# 圆角参数代码示范

> 本示例展示如何在 HarmonyOS ArkTS 中使用官方圆角参数，并通过 `float.json` 统一管理圆角 token。

---

## 一、定义圆角 Token

在 `entry/src/main/resources/base/element/float.json` 中新增圆角 token：

```json
{
  "float": [
    {
      "name": "radius_xsmall",
      "value": "4vp"
    },
    {
      "name": "radius_small",
      "value": "8vp"
    },
    {
      "name": "radius_medium",
      "value": "16vp"
    },
    {
      "name": "radius_large",
      "value": "20vp"
    },
    {
      "name": "radius_xlarge",
      "value": "32vp"
    }
  ]
}
```

> 如果项目中已有其他 float token，直接在原有数组中追加即可，不要覆盖。

---

## 二、基础用法：为组件设置圆角

### 2.1 标签（4vp）

```typescript
Text('新课')
  .fontSize(12)
  .fontColor(Color.White)
  .padding({ left: 8, right: 8, top: 4, bottom: 4 })
  .backgroundColor($r('app.color.brand_secondary'))
  .borderRadius($r('app.float.radius_xsmall'))
```

### 2.2 图片（8vp）

```typescript
Image($r('app.media.cover'))
  .width('100%')
  .height(180)
  .objectFit(ImageFit.Cover)
  .borderRadius($r('app.float.radius_small'))
```

### 2.3 内容卡片（16vp）

```typescript
Column() {
  Text('今日复习')
    .fontSize(18)
    .fontWeight(FontWeight.Bold)
    .fontColor($r('app.color.text_primary'))

  Text('加法 · 减法 · 乘法')
    .fontSize(14)
    .fontColor($r('app.color.text_secondary'))
    .margin({ top: 8 })
}
.width('90%')
.padding(20)
.backgroundColor($r('app.color.surface'))
.borderRadius($r('app.float.radius_medium'))
.shadow({ radius: 8, color: 'rgba(0,0,0,0.08)', offsetY: 2 })
```

### 2.4 按钮（20vp）

```typescript
Button('开始练习')
  .fontSize(16)
  .fontWeight(FontWeight.Medium)
  .fontColor($r('app.color.text_on_brand'))
  .width('70%')
  .height(48)
  .backgroundColor($r('app.color.brand_primary'))
  .borderRadius($r('app.float.radius_large'))
```

### 2.5 半模态 / 弹窗（32vp）

```typescript
Column() {
  Text('练习完成')
    .fontSize(20)
    .fontWeight(FontWeight.Bold)
    .margin({ bottom: 16 })

  Button('知道了')
    .fontColor($r('app.color.text_on_brand'))
    .backgroundColor($r('app.color.brand_primary'))
    .borderRadius($r('app.float.radius_large'))
}
.width('100%')
.height(300)
.padding(24)
.backgroundColor($r('app.color.surface'))
.borderRadius({
  topLeft: $r('app.float.radius_xlarge'),
  topRight: $r('app.float.radius_xlarge'),
  bottomLeft: 0,
  bottomRight: 0
})
```

## 三、统一圆角工具类（可选）

如果项目中多处使用，可以封装一个 `RadiusTokens` 工具类：

```typescript
// entry/src/main/ets/styles/RadiusTokens.ets
export class RadiusTokens {
  static readonly xsmall: Resource = $r('app.float.radius_xsmall');   // 4vp
  static readonly small: Resource = $r('app.float.radius_small');     // 8vp
  static readonly medium: Resource = $r('app.float.radius_medium');   // 16vp
  static readonly large: Resource = $r('app.float.radius_large');     // 20vp
  static readonly xlarge: Resource = $r('app.float.radius_xlarge');   // 32vp
}
```

使用方式：

```typescript
import { RadiusTokens } from '../styles/RadiusTokens';

Column() { ... }
  .borderRadius(RadiusTokens.medium)
```

## 四、嵌套元素的圆角处理

当图片或按钮放在卡片内部时，内部元素圆角应小于外层卡片，形成层级关系：

```typescript
Column() {
  // 外层卡片：16vp
  Image($r('app.media.cover'))
    .width('100%')
    .height(160)
    .objectFit(ImageFit.Cover)
    .borderRadius($r('app.float.radius_small'))  // 内部图片：8vp

  Column() {
    Text('课程标题')
      .fontSize(16)
      .fontWeight(FontWeight.Bold)

    Button('去学习')
      .fontColor(Color.White)
      .backgroundColor($r('app.color.brand_primary'))
      .borderRadius($r('app.float.radius_large'))  // 按钮：20vp
  }
  .padding(16)
}
.width('90%')
.backgroundColor($r('app.color.surface'))
.borderRadius($r('app.float.radius_medium'))  // 卡片：16vp
.shadow({ radius: 8, color: 'rgba(0,0,0,0.08)', offsetY: 2 })
```

## 五、常见组件推荐映射速查表

| 组件 | 推荐圆角 | 说明 |
|------|----------|------|
| 标签/角标 | 4vp | 紧凑辅助 |
| 头像/缩略图 | 8vp | 轻微柔化 |
| 列表卡片 | 16vp | 标准容器 |
| 通知卡片 | 16vp | 标准容器 |
| 按钮 | 20vp | 操作控件 |
| 搜索框 | 20vp | 操作控件 |
| 菜单 | 20vp | 操作容器 |
| 底部 Sheet | 32vp | 顶层覆盖 |
| 弹窗/对话框 | 32vp | 顶层覆盖 |
| 全圆角胶囊按钮 | 高度的一半 | 特殊样式，非标准档位 |

## 六、注意事项

1. **统一 token 管理**：所有圆角尽量通过 `float.json` 引用，避免页面中硬编码 `borderRadius(12)` 等随意值。
2. **同层一致**：同类型组件使用相同 token。
3. **嵌套递减**：内部元素圆角 ≤ 外层容器圆角。
4. **特殊形状**：圆形按钮用 `borderRadius('50%')` 或高度的一半；异形卡片可单独定义。
5. **与阴影配合**：圆角卡片通常配合轻微阴影使用，增强层级感。
