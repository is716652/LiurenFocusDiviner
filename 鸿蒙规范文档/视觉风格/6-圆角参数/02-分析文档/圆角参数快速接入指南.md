# 圆角参数快速接入指南

> 圆角参数是 HarmonyOS 设计系统的基础视觉属性之一，**并非复杂的独立能力**。对于一般项目，只需要在合适的地方使用合适的圆角半径即可，不需要额外引入 API 或复杂配置。

---

## 一、什么时候需要关注圆角参数

### 1.1 建议使用标准圆角参数的情况

| 场景 | 说明 |
|------|------|
| 项目中存在多种矩形控件 | 卡片、按钮、图片、标签等需要用统一圆角风格 |
| 需要明确界面层级 | 通过圆角大小区分底层内容与顶层弹窗 |
| 希望提升界面亲和力 | 圆角比直角更柔和、现代 |
| 需要适配 HarmonyOS 设计规范 | 遵循官方 4/8/16/20/32vp 档位 |

### 1.2 可以简化处理的情况

| 场景 | 说明 |
|------|------|
| 极简工具类应用 | 少量直角元素也可以接受 |
| 内部管理后台 | 功能优先，圆角规范可适当放宽 |
| 完全自定义品牌风格 | 有独立设计系统时，可按品牌规范执行 |

## 二、快速接入三步法

### 第一步：识别页面中的矩形元素

浏览页面，找出需要圆角的元素：

- 标签、角标
- 图片、头像、缩略图
- 内容卡片、列表项
- 按钮、搜索框、输入框
- 菜单、弹窗、半模态 Sheet

### 第二步：按层级选择圆角半径

参考 HarmonyOS 5 档标准：

| 元素类型 | 推荐半径 | 原因 |
|----------|----------|------|
| 标签/角标 | 4vp | 小尺寸辅助元素，紧凑精致 |
| 图片/图标 | 8vp | 轻微柔化，不破坏内容 |
| 内容卡片 | 16vp | 标准信息容器 |
| 按钮/菜单 | 20vp | 操作控件，识别度高 |
| 弹窗/Sheet | 32vp | 顶层覆盖，层级最高 |

### 第三步：在代码中设置 `.borderRadius()`

```typescript
Column() {
  Text('内容卡片')
}
.borderRadius($r('app.float.radius_medium'))  // 16vp
```

## 三、快速决策树

```
开始
  │
  ▼
元素是什么类型？
  │
  ├─ 标签/角标 ──▶ 4vp
  ├─ 图片/头像/缩略图 ──▶ 8vp
  ├─ 内容卡片/通知卡片 ──▶ 16vp
  ├─ 按钮/搜索框/菜单 ──▶ 20vp
  └─ 弹窗/半模态/对话框 ──▶ 32vp
  │
  ▼
是否有嵌套关系？
  │
  ├─ 是 ──▶ 内部元素圆角 ≤ 外层容器圆角
  └─ 否 ──▶ 直接应用
  │
  ▼
同类型元素是否已存在？
  │
  ├─ 是 ──▶ 与已有元素保持一致的圆角 token
  └─ 否 ──▶ 按标准档位新增
```

## 四、最小可用示例

### float.json

```json
{
  "float": [
    { "name": "radius_xsmall", "value": "4vp" },
    { "name": "radius_small", "value": "8vp" },
    { "name": "radius_medium", "value": "16vp" },
    { "name": "radius_large", "value": "20vp" },
    { "name": "radius_xlarge", "value": "32vp" }
  ]
}
```

### 页面代码

```typescript
@Entry
@Component
struct CornerDemoPage {
  build() {
    Column({ space: 16 }) {
      Text('新课')
        .fontSize(12)
        .fontColor(Color.White)
        .padding({ left: 8, right: 8, top: 4, bottom: 4 })
        .backgroundColor($r('app.color.brand_secondary'))
        .borderRadius($r('app.float.radius_xsmall'))  // 4vp

      Image($r('app.media.cover'))
        .width(200)
        .height(120)
        .objectFit(ImageFit.Cover)
        .borderRadius($r('app.float.radius_small'))  // 8vp

      Column() {
        Text('内容卡片')
          .fontSize(16)
          .fontWeight(FontWeight.Bold)
      }
      .width(200)
      .padding(16)
      .backgroundColor($r('app.color.surface'))
      .borderRadius($r('app.float.radius_medium'))  // 16vp

      Button('操作按钮')
        .fontColor($r('app.color.text_on_brand'))
        .width(200)
        .height(48)
        .backgroundColor($r('app.color.brand_primary'))
        .borderRadius($r('app.float.radius_large'))  // 20vp
    }
    .width('100%')
    .height('100%')
    .justifyContent(FlexAlign.Center)
  }
}
```

## 五、注意事项

1. **不要 invent 新半径**：优先使用 4/8/16/20/32vp，避免 12vp、18vp 等中间值。
2. **同类型一致**：所有按钮统一用一个 token，不要有的 16vp 有的 20vp。
3. **嵌套递减**：卡片内部图片圆角小于卡片圆角。
4. **特殊形状单独处理**：圆形头像用 `borderRadius('50%')` 或宽高一半。
5. **与品牌协调**：如果品牌有独立圆角规范，可在标准档位基础上微调，但保持系统一致性。

---

## 六、一句话总结

> **圆角参数是“顺手就能做对”的基础规范。只要记住 4/8/16/20/32 五个档位，按元素层级和功能套用，就能让界面既统一又有层次感。**
