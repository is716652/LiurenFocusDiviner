# HarmonyOS Symbol 规范摘录

> 来源：[华为开发者文档 - System Icons](https://developer.huawei.com/consumer/cn/doc/doccenter-ux-design/system-icons-0000001929854962)

## 一、什么是 HarmonyOS Symbol

HarmonyOS Symbol 代表了 HarmonyOS 系统图标设计的一次重要演进。它通过简化的图形和直观的语义表达，不仅易于识别，同时融入了更多年轻化的设计理念，使得整体的视觉风格更加年轻和时尚。

同时，HarmonyOS Symbol 还具备了 **字体属性**，使其能够与系统字体无缝对接，确保了文本与图标的排版一致性。此外，它能够根据文本的粗细变化进行智能适配，确保在不同文本粗细下，图标能够灵活适应，保持视觉的连贯性和一致性。

## 二、核心特性

### 2.1 字体属性

HarmonyOS Symbol 具备字体的属性：

- 与文本混排时可以很好地与字体基线对齐。
- 支持粗细无极变化，允许开发者根据具体设计需求选择适合的图标粗细。
- 确保图标在不同使用场景下的风格一致性和视觉协调性。

### 2.2 颜色渲染

HarmonyOS Symbol 的设计采用了灵活的分层结构，确保图标在不同场景下的视觉一致性。图标的每个图层都可以独立设置颜色和不透明度，提供了高度的个性化定制能力。

#### 渲染策略 1：单色 (SINGLE)

- 可生效用户指定的一种颜色。
- 当输入多个颜色时，仅生效第一个颜色。

#### 渲染策略 2：分层 (MULTIPLE_OPACITY)

- 默认为黑色，可以设置一个颜色。
- 当用户设置多个颜色时，仅生效第一个颜色。
- 不透明度与图层相关，第一层 100%、第二层 50%。

#### 渲染策略 3：多色 (MULTIPLE_COLOR)

- 可生效用户指定的两种颜色。
- 当用户只设置一个颜色时，修改第一层颜色，其他颜色保持默认颜色。
- 颜色设置顺序与图标分层顺序匹配，当颜色数量大于图标分层时，多余的颜色不生效。

### 2.3 动效策略

HarmonyOS Symbol 超越了传统的静态图标功能，集成了多种动态效果。开发者可以将这些动画效果与用户操作紧密结合，例如点击、长按、输入和数据传输等，使 HarmonyOS Symbol 成为互动性强的组件。

HarmonyOS Symbol 支持以下动效策略（默认为无动效）：

| 动效 | 说明 |
|---|---|
| 无动效 | 默认状态，图标静态显示 |
| 出现 | 图标从不可见到可见的入场动画 |
| 消失 | 图标从可见到不可见的离场动画 |
| 弹跳 | 图标产生弹跳效果 |
| 缩放 | 图标整体缩放动画 |
| 替换 | 图标内容替换动画 |
| 快速替换 | 图标快速替换动画 |
| 脉冲 | 图标产生脉冲效果 |
| 可变颜色 | 图标颜色变化效果 |
| 禁用 | 图标禁用态效果 |

## 三、如何使用

HarmonyOS Symbol 是系统内置的一套图标资源库。开发者可以通过图标的资源名称，利用 Symbol 组件高效索引并使用相应的图标。

### 3.1 查询图标

- 通过 Symbol 图标网站查找所需图标。
- 图标的命名依据其形状进行描述。
- 每个图标对应一个 Symbol name ID，例如「加号」图标的 ID 为 `plus`。
- 在 ArkTS 中通过 `$r('sys.symbol.ohos_wifi')` 等形式引用。

### 3.2 属性标注

Symbol 图标支持与字体样式一致的属性，包括但不限于：

- **大小 (font size)**：控制图标尺寸
- **粗细 (font weight)**：控制图标线条粗细
- **颜色渲染策略 (rendering strategy)**：单色 / 分层 / 多色
- **动效策略 (effect strategy)**：出现 / 消失 / 缩放 / 替换等

### 3.3 SymbolGlyph 组件

`SymbolGlyph` 组件适用于独立图标的展示：

- 可以为图标设置字号大小和字体粗细。
- 支持自定义颜色渲染策略。
- 支持动效策略，使图标在用户交互时展现动画效果。
- 默认情况下，Symbol 图标的尺寸与其字号大小保持一致。例如，设定为 24vp 的字号，其图标宽高也将为 24×24vp。

## 四、关键摘录要点

1. **字体化图标**：HarmonyOS Symbol 具备字体属性，可与文本混排并对齐基线。
2. **智能适配**：能根据文本粗细变化自动适配图标粗细。
3. **三种渲染策略**：SINGLE（单色）、MULTIPLE_OPACITY（分层）、MULTIPLE_COLOR（多色）。
4. **丰富动效**：支持出现、消失、弹跳、缩放、替换、脉冲等多种动效。
5. **系统内置资源**：通过 `$r('sys.symbol.xxx')` 引用，无需额外引入资源文件。
6. **SymbolGlyph 组件**：用于独立展示 Symbol 图标，支持 fontSize、fontWeight、fontColor、renderingStrategy、effectStrategy。
