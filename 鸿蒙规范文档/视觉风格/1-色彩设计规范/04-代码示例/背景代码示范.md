>
> 本示例演示如何不依赖 AI，手动编写一段符合 HarmonyOS NEXT 色彩规范的背景代码。

## 一、从 AI 提示词中可以借鉴什么

即使你不用 AI，提示词里的核心规范仍然可以直接指导你手写代码：

| 提示词要点 | 手写代码时的做法 |
|---|---|
| 使用语义化 Token 命名颜色 | 颜色名用 `background`、`surface`、`brand_primary` 等，而不是 `blue`、`gray` |
| 浅色/深色模式使用相同 Token 名 | `theme.json` 和 `dark/theme.json` 中 Token 名称一致，只变色值 |
| 背景使用语义 Token | 用 `background`、`surface`、`container` 等语义名称 |
| 启动页背景突出品牌色 | 启动页背景可设为品牌色或品牌色系渐变 |
| 背景与前景对比度 ≥ 3:1 | 选择颜色时确保文本能清晰阅读 |
| 不硬编码色值 | 组件代码中全部使用 `$r('app.color.xxx')` 引用 |

## 三、定义颜色 Token

### 3.1 浅色模式：resources/base/theme.json

```json
{
  "color": {
    "brand_primary": "#3B6FF5",
    "brand_primary_light": "#E8EFFF",
    "background": "#F5F7FA",
    "surface": "#FFFFFF",
    "text_primary": "#1A1A1A",
    "text_secondary": "#666666",
    "divider": "#E0E0E0"
  }
}
```

### 3.2 深色模式：resources/dark/theme.json

```json
{
  "color": {
    "brand_primary": "#5B8CFF",
    "brand_primary_light": "#1A2A4D",
    "background": "#0D0D0D",
    "surface": "#1A1A1A",
    "text_primary": "#F5F5F5",
    "text_secondary": "#999999",
    "divider": "#333333"
  }
}
```

> 注意：浅色和深色模式下 Token 名称完全相同，只有色值不同。系统会根据当前模式自动切换。

## 四、启动页背景配置

在 `EntryAbility.ets` 中配置窗口背景：

```typescript
// entry/src/main/ets/entryability/EntryAbility.ets
import { AbilityConstant, UIAbility, Want } from '@kit.AbilityKit';
import { window } from '@kit.ArkUI';

export default class EntryAbility extends UIAbility {
  onWindowStageCreate(windowStage: window.WindowStage): void {
    // 加载内容前设置窗口背景色
    windowStage.getMainWindow().then((win) => {
      win.setWindowBackgroundColor('#3B6FF5'); // 品牌主色
    });

    windowStage.loadContent('pages/Index', (err) => {
      if (err.code) {
        console.error('Failed to load content');
        return;
      }
      console.info('Succeeded in loading content.');
    });
  }
}
```

> 说明：启动页背景通常使用品牌色，给用户强烈的品牌第一印象。

## 五、页面背景代码示例

### 5.1 简单品牌背景页面

```typescript
// entry/src/main/ets/pages/Index.ets
@Entry
@Component
struct Index {
  build() {
    // 页面根容器：使用 background Token 作为页面背景
    Column() {
      // 顶部品牌色背景区域
      Column() {
        Text('HarmonyOS')
          .fontSize(28)
          .fontWeight(FontWeight.Bold)
          .fontColor($r('app.color.text_primary'))

        Text('纯净、和谐的设计体验')
          .fontSize(16)
          .fontColor($r('app.color.text_secondary'))
          .margin({ top: 8 })
      }
      .width('100%')
      .height('40%')
      .backgroundColor($r('app.color.brand_primary')) // 品牌主色背景
      .justifyContent(FlexAlign.Center)

      // 内容卡片区域
      Column() {
        Text('内容区域')
          .fontSize(20)
          .fontWeight(FontWeight.Medium)
          .fontColor($r('app.color.text_primary'))

        Text('这里使用 surface Token 作为卡片背景')
          .fontSize(14)
          .fontColor($r('app.color.text_secondary'))
          .margin({ top: 12 })
      }
      .width('90%')
      .padding(24)
      .margin({ top: -40 }) // 卡片向上叠加，形成层次感
      .backgroundColor($r('app.color.surface'))
      .borderRadius(16)
      .shadow({ radius: 12, color: 'rgba(0,0,0,0.08)', offsetY: 4 })

      // 底部说明
      Text('背景与前景对比度满足 3:1 规范')
        .fontSize(12)
        .fontColor($r('app.color.text_secondary'))
        .margin({ top: 24 })
    }
    .width('100%')
    .height('100%')
    .backgroundColor($r('app.color.background')) // 页面主背景
  }
}
```

### 5.2 效果说明

| 区域 | 使用的 Token | 设计意图 |
|---|---|---|
| 页面背景 | `background` | 提供舒适的底层环境色 |
| 顶部品牌区 | `brand_primary` | 突出品牌识别 |
| 卡片背景 | `surface` | 与页面背景形成层次对比 |
| 主标题 | `text_primary` | 高对比度，确保可读 |
| 副标题/说明 | `text_secondary` | 次要信息，降低视觉权重 |

## 六、关键借鉴点总结

1. **颜色全部走 Token**
   - 所有 `backgroundColor` 和 `fontColor` 都使用 `$r('app.color.xxx')`。
   - 不直接写 `#3B6FF5` 在组件代码里。

2. **语义化命名**
   - 用 `background`、`surface`、`brand_primary` 描述用途，而不是颜色本身。

3. **浅色/深色自动适配**
   - 只需在 `base/theme.json` 和 `dark/theme.json` 中定义同名 Token。
   - 切换系统主题时，组件自动使用对应色值。

4. **品牌色与背景层次分明**
   - 启动页/品牌区用 `brand_primary`。
   - 页面背景用 `background`。
   - 卡片/内容区用 `surface`。

5. **可读性优先**
   - 文本颜色与背景保持足够对比度。
   - 主文本用 `text_primary`，次要文本用 `text_secondary`。
