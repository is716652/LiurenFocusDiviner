# HarmonyOS NEXT 应用图标设计 — AI 工作流提示词

> 适用于：HarmonyOS NEXT 应用图标、桌面图标、启动图标设计。
> 目标：让 AI 先按规范生成方案，再经用户迭代确认，最终转化为符合 HarmonyOS 审查规范的交付物。

---

## 第一阶段：设定 AI 角色（每次对话开头使用）

```text
你是一名精通 HarmonyOS NEXT 设计规范的视觉设计师与品牌顾问。
你擅长设计应用图标、桌面图标和品牌视觉资产。
请严格遵循以下规范：

1. 设计原则：
   - 简洁优雅：元素图标简洁，线条表现优雅，传递设计美学。
   - 极速达意：图标图形准确传达其功能、服务和品牌，具有易读性和识别性。
   - 情感表达：通过图形和色彩概括表达情感，传达品牌视觉形象。

2. 色彩规范：
   - 优先使用 HarmonyOS NEXT 系统色彩理念：以“宇宙蓝”和“雪域灰”为基础，追求干净、和谐、纯净。
   - 应用品牌色需具备识别性，与系统风格协调。
   - 所有颜色必须使用 HarmonyOS Token 思维命名（基础/语义/控件 Token）。
   - 控制色板数量，建议 1-2 种主色 + 1 种辅助色。
   - 确保图标在浅色/深色壁纸、浅色/深色模式下均有良好可读性。

3. 图标规范：
   - HarmonyOS NEXT 应用图标必须采用分层图标格式：由前景图（Foreground）和背景图（Background）两层组成。
   - 资源尺寸必须是 1024px × 1024px 的正方形 PNG，资源本身必须是正方形。
   - 不要自行裁切圆角或添加内间距，系统会根据不同场景自动生成遮罩效果。
   - 图标核心图形应位于安全区内，避免被系统裁切或动态效果影响。
   - 图标应简洁、具有品牌识别度，避免过多细节。
   - 提供桌面图标、小尺寸通知图标、大图标（如文件夹/快捷方式）三种尺度的适配思路。
   - 如需使用 HarmonyOS 官方标识，必须以单色形式放置在图标右下角固定位置，不可随意修改。

4. 输出要求：
   - 每个设计方案必须包含：设计说明、色彩 Token 表、使用场景、可读性分析。
   - 最终交付物需包含：规范命名的 PNG/SVG 导出建议、Token 映射表、审查自查清单。

请在所有回答中保持以上规范。
```

## 第二阶段：生成初始设计方案

### 2.1 应用图标设计

```text
请为一款 [应用类型，如：阅读/社交/工具/健康/教育] 应用设计一款 HarmonyOS NEXT 风格的应用图标。

应用信息：
- 应用名称：[名称]
- 核心功能：[一句话描述]
- 目标用户：[用户群体]
- 品牌关键词：[如：高效、温暖、科技、自然、专业]
- 希望传递的情感：[如：信任、活力、平静、创新]

设计要求：
1. 图标必须设计为分层图标：前景图（Foreground，Logo 主体/图形） + 背景图（Background，底色/纹理）。
2. 最终输出尺寸为 1024px × 1024px 正方形 PNG，不要自行裁切圆角或添加内间距。
3. 图标形状为圆角矩形，核心图形位于安全区内。
4. 遵循 HarmonyOS 三大设计原则：简洁优雅、极速达意、情感表达。
5. 使用 1-2 种主色 + 1 种辅助色，避免颜色过多。
6. 主色需作为品牌色，辅助色用于高光或细节。
7. 图形需简洁、可识别，在小尺寸（如通知栏 24dp）下依然清晰。
8. 提供浅色模式和深色模式下的图标变体思路。
9. 所有颜色使用语义化 Token 命名。

请输出：
- 3 个不同方向的方案
- 每个方案包含：
  - 设计概念说明（如何体现简洁优雅、极速达意、情感表达）
  - 前景图层描述（核心图形、颜色、位置、安全区说明）
  - 背景图层描述（底色、纹理、渐变）
  - 主色/辅助色 Token
  - 适用场景
- 推荐使用材质/风格（如毛玻璃、扁平、轻拟物、渐变）
```

### 2.2 图标变体设计（可选）

```text
请为 [应用名称] 设计以下 HarmonyOS NEXT 图标变体：

1. 桌面图标：1024×1024 分层图标（前景 + 背景）
2. 小尺寸通知图标：24×24dp，单色或简化版
3. 大图标/快捷方式：文件夹或快捷方式场景下的显示效果

要求：
- 各变体保持品牌识别一致性。
- 小尺寸图标需进一步简化细节，确保清晰可辨。
- 提供各变体的设计说明和导出规格。
```

## 第三阶段：迭代调整（用户选择方案后细化）

```text
我已选择第 [X] 个方案，请基于该方案进行细化，并根据以下反馈调整：

用户反馈：
- [例如：品牌色再深一点 / 图形更圆润 / 科技感更强 / 去掉渐变 / 核心图形放大]

调整要求：
1. 保留 HarmonyOS NEXT 设计规范（简洁优雅、极速达意、情感表达）。
2. 保留分层图标格式（前景 + 背景）。
3. 每次只调整 1-2 个要素，避免整体风格偏离。
4. 调整后重新说明：品牌色、辅助色、图形语义、可读性、安全区。
5. 确保小尺寸下图标依然清晰。

请输出：
- 调整后的设计方案
- 更新后的色彩 Token 表
- 调整说明
- 调整前后的对比说明
```

## 第四阶段：转化为审查规范交付物

```text
用户对以下设计方案已满意，请将其转化为符合 HarmonyOS 审查规范的完整交付物：

[粘贴最终设计方案描述或截图说明]

请输出以下内容：

### 1. 设计规范文档
- 应用名称与图标用途
- 设计理念（一句话 + 关键词）
- 图形构成说明
- 如何体现三大设计原则：简洁优雅、极速达意、情感表达
- 色彩系统（基础 Token + 语义 Token）
- 安全区与边距说明

### 2. 色彩 Token 映射表
| Token 名称 | 类型 | 浅色色值 | 深色色值 | 用途 |
|---|---|---|---|---|
| brand_primary | 基础 | #XXXXXX | #XXXXXX | 主品牌色 |
| icon_foreground | 语义 | #XXXXXX | #XXXXXX | 图标前景主色 |
| icon_background | 语义 | #XXXXXX | #XXXXXX | 图标背景色 |
| icon_accent | 语义 | #XXXXXX | #XXXXXX | 图标辅助色/高光 |
| ... | ... | ... | ... | ... |

### 3. 尺寸与导出规范
#### 包体内图标（必须遵循分层规范）
- 前景图（Foreground）：1024px × 1024px 正方形 PNG，核心图形位于安全区
- 背景图（Background）：1024px × 1024px 正方形 PNG，纯色或简单纹理
- 资源本身必须是正方形，不要自行裁切圆角或添加内间距
- 推荐导出格式：PNG
- 推荐命名：foreground.png / background.png

#### 商店展示图标（上架素材）
- 支持 216×216px 或 1024×1024px 两种尺寸
- 格式：PNG 或 WEBP
- 商店展示图标可以是合成后的展示效果，不一定需要分层

#### 其他尺寸
- 通知图标：24×24dp，通常为单色或简化版
- 安全区/边距要求说明

#### 矢量源文件
- 虽然上架需要 PNG，但建议同时保留 SVG/AI/Figma 源文件以便后续修改

### 4. 审查自查清单
- [ ] 图标已拆分为前景图（Foreground）和背景图（Background）
- [ ] 前景图和背景图尺寸均为 1024px × 1024px 正方形 PNG
- [ ] 未自行裁切圆角，未添加内间距
- [ ] 图标核心图形位于安全区内
- [ ] 设计体现简洁优雅、极速达意、情感表达三大原则
- [ ] 颜色满足 3:1 对比度
- [ ] 提供浅色/深色两种模式变体思路
- [ ] 品牌色具有识别性且与系统风格协调
- [ ] 小尺寸下图标依然清晰可辨
- [ ] 所有颜色均有 Token 命名
- [ ] layered_image.json 配置正确
- [ ] app.json5 中正确引用 $media:layered_image
- [ ] module.json5 中无错误图标配置覆盖 app.json5
- [ ] 使用 DevEco Studio 5.0.5.315 或更高版本处理图标
- [ ] 无版权/商标侵权风险

### 5. 开发实现建议
#### 图标资源配置
- 前景图存放路径：`AppScope/resources/base/media/foreground.png`
- 背景图存放路径：`AppScope/resources/base/media/background.png`
- 分层配置：`AppScope/resources/base/media/layered_image.json`
```json
{
  "layered-image": {
    "background": "$media:background",
    "foreground": "$media:foreground"
  }
}
```
- 在 `AppScope/app.json5` 中引用：
```json
{
  "app": {
    "icon": "$media:layered_image",
    "label": "$string:app_name"
  }
}
```
- 注意：`module.json5` 中的 `icon` 和 `label` 配置优先级高于 `app.json5`，若不需要多入口图标，建议删除或检查 module.json5 中的相关配置。

请使用 Markdown 格式输出，确保开发者和审查人员可直接使用。
```

```text
请为一款 [应用类型] 应用「[应用名称]」设计完整的 HarmonyOS NEXT 应用图标方案。

应用信息：
- 应用名称：[名称]
- 核心功能：[一句话]
- 目标用户：[群体]
- 品牌关键词：[3-5 个词]
- 期望风格：[如：极简科技 / 温暖生活 / 专业商务 / 年轻活力]
- 希望传递的情感：[如：信任、活力、平静、创新]

需交付内容：
1. 应用图标设计方案（分层图标：前景图 + 背景图，1024×1024px，含安全区说明）
2. 3 个不同方向的初始方案供我选择
3. 完整色彩 Token 体系
4. 尺寸与导出规范（区分包体内图标与商店展示图标）
5. 审查自查清单（含分层图标、layered_image.json、DevEco Studio 版本等）
6. 开发实现建议（含 layered_image.json 和 app.json5 配置示例）

设计原则：
- 简洁优雅、极速达意、情感表达
- 符合 HarmonyOS NEXT 系统视觉风格
- 品牌色识别性强
- 所有颜色使用 Token 命名
- 浅色/深色模式自动适配
- 对比度 ≥ 3:1

请分步骤输出：先给出 3 个图标方案供我选择，等我确认后再继续输出完整交付物。
```

## 使用建议

| 步骤 | 操作 |
|---|---|
| 1 | 将「第一阶段」提示词作为系统设定发送 |
| 2 | 使用「第二阶段」生成 2-3 个方向的初始方案 |
| 3 | 用户挑选方向后，用「第三阶段」迭代调整 |
| 4 | 用户满意后，用「第四阶段」一键转化为审查交付物 |
| 5 | 如需完整流程，可直接使用「第五阶段」的端到端提示词 |

---

## 注意事项

- AI 目前无法直接生成可上架的矢量源文件和 1024px 分层 PNG，最终图标仍需设计师在 Figma/Sketch/PS 中精修并导出。
- AI 更适合用于**概念发散、前景/背景分层设计、色彩规范制定、Token 映射、审查清单生成**。
- 包体内图标必须严格遵循 1024px 分层规范，商店展示图标可使用 216×216 或 1024×1024 的合成效果。
- 建议将 AI 输出作为设计稿的「规范说明书」，与视觉稿一起提交审查。
