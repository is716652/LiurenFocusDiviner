> 借鉴自：
> - `../03-AI提示词/HarmonyOS应用图标设计_AI工作流提示词.md`
>
> 以「数学复习进阶」项目为例，演示如何设计图标、配置资源，使其显示在手机桌面。

---

## 一、核心原理

在 HarmonyOS NEXT 中，应用图标显示在桌面需要以下配置：

1. **图标资源**：应用图标采用分层图标格式，由前景图（Foreground）和背景图（Background）组成。
2. **资源配置**：在 `AppScope/resources/base/media/` 下放置前景、背景 PNG 和 `layered_image.json`。
3. **应用配置**：在 `AppScope/app.json5` 中通过 `"icon": "$media:layered_image"` 引用。
4. **应用名称**：在 `AppScope/resources/base/element/string.json` 中定义 `"app_name"`，在 `app.json5` 中通过 `"label": "$string:app_name"` 引用。
5. **编译安装**：使用 `hvigorw assembleHap` 编译并签名，安装到手机后图标和名称会显示在桌面。

---

## 二、图标资源结构

```
AppScope/resources/base/media/
├── foreground.png          # 前景图层：图标主体（数学符号）
├── background.png          # 背景图层：底色/装饰
├── layered_image.json      # 关联前景和背景
└── app_icon.png            # 合成展示图标（可选，用于商店展示）
```

### 2.1 layered_image.json

```json
{
  "layered-image": {
    "background": "$media:background",
    "foreground": "$media:foreground"
  }
}
```

### 2.2 图标设计要求

- 前景图和背景图尺寸均为 **1024px × 1024px** 正方形 PNG。
- 不要自行裁切圆角，不要添加内间距。
- 系统会根据不同场景自动生成遮罩效果。
- 核心图形应位于安全区内。
- 遵循 HarmonyOS 三大设计原则：**简洁优雅、极速达意、情感表达**。

## 四、entry 模块配置

如果 `entry/src/main/module.json5` 中也配置了 `icon` 和 `label`，会覆盖 `AppScope/app.json5` 的配置。因此建议保持一致或删除 module.json5 中的图标配置。

## 五、图标设计示例（Python + PIL）

以下代码用于生成数学主题的分层图标：

```python
from PIL import Image, ImageDraw
import os

size = (1024, 1024)
brand_blue = (59, 111, 245, 255)      # 品牌蓝 #3B6FF5
light_blue = (232, 239, 255, 255)     # 浅蓝背景 #E8EFFF
accent_orange = (255, 159, 67, 255)   # 强调橙 #FF9F43
white = (255, 255, 255, 255)

def create_foreground(path):
    img = Image.new('RGBA', size, (0, 0, 0, 0))
    draw = ImageDraw.Draw(img)
    
    # 图标主体：圆角矩形
    margin = 112
    radius = 180
    draw.rounded_rectangle([margin, margin, size[0]-margin, size[1]-margin], 
                           radius=radius, fill=brand_blue)
    
    # 数学符号：1 + 2 = 3 风格
    draw.rounded_rectangle([260, 280, 320, 520], radius=24, fill=white)  # 1
    draw.rounded_rectangle([420, 360, 620, 420], radius=20, fill=white)  # 加号横
    draw.rounded_rectangle([500, 300, 560, 480], radius=20, fill=white)  # 加号竖
    draw.arc([680, 300, 780, 420], start=180, end=360, fill=white, width=36)  # 2 上半
    draw.line([(760, 420), (680, 520)], fill=white, width=36)  # 2 下半
    draw.rounded_rectangle([360, 600, 680, 660], radius=16, fill=accent_orange)  # 等号上
    draw.rounded_rectangle([360, 700, 680, 760], radius=16, fill=accent_orange)  # 等号下
    
    img.save(path)

def create_background(path):
    img = Image.new('RGBA', size, light_blue)
    draw = ImageDraw.Draw(img)
    
    # 装饰小圆点，增加童趣
    dots = [(180, 180, 20), (850, 220, 16), (220, 850, 18), (800, 820, 22), (500, 150, 14)]
    for x, y, r in dots:
        draw.ellipse([x-r, y-r, x+r, y+r], fill=(255, 255, 255, 180))
    
    img.save(path)

# 生成
base_dir = "D:/nutstore/HarmonyOS/HarmonyOS-Design/HarmonyOSDesign"
app_media = os.path.join(base_dir, "AppScope/resources/base/media")
os.makedirs(app_media, exist_ok=True)

create_foreground(os.path.join(app_media, "foreground.png"))
create_background(os.path.join(app_media, "background.png"))
```

### 5.1 设计说明

| 层级 | 内容 | 颜色 | 设计意图 |
|---|---|---|---|
| 前景 | 圆角矩形 + 数学符号 | 品牌蓝 #3B6FF5、白色、强调橙 | 极速达意：一眼识别数学学习应用 |
| 背景 | 浅蓝底 + 装饰圆点 | 浅蓝 #E8EFFF、半透明白 | 简洁优雅：提供柔和背景，不干扰主体 |

## 六、商店展示图标

商店展示图标可使用合成后的展示效果，尺寸支持 **216×216px** 或 **1024×1024px**，格式为 **PNG** 或 **WEBP**。

可以使用以下 Python 代码生成简单的合成展示图标：

```python
def create_app_icon(path):
    # 合成前景和背景为商店展示图标
    bg = Image.open(os.path.join(app_media, "background.png")).resize((1024, 1024))
    fg = Image.open(os.path.join(app_media, "foreground.png")).resize((1024, 1024))
    icon = Image.alpha_composite(bg, fg)
    icon.save(path)

create_app_icon(os.path.join(app_media, "app_icon.png"))
```

## 八、常见问题

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 桌面不显示图标 | `app.json5` 中 `icon` 配置错误 | 确保引用 `$media:layered_image` 且资源存在 |
| 图标显示为默认图标 | 分层图标资源缺失或格式错误 | 检查 foreground.png / background.png 是否为 1024×1024 PNG |
| 应用名称错误 | `string.json` 中 `app_name` 未定义 | 检查 `AppScope/resources/base/element/string.json` |
| module 覆盖 app 配置 | `module.json5` 中配置了旧图标 | 删除或更新 `module.json5` 中的 `icon`/`label` |
| 审核被驳回 | 使用了单层图标 | 按要求制作前景图和背景图，并使用分层配置 |

## 九、关键借鉴点总结

1. **分层图标是核心**
   - 必须提供 foreground.png 和 background.png。
   - 通过 layered_image.json 关联。

2. **尺寸严格 1024×1024**
   - 正方形 PNG，不裁切圆角，不加内间距。

3. **配置优先级需注意**
   - module.json5 会覆盖 app.json5，单入口应用建议在 app.json5 中配置。

4. **设计原则要落地**
   - 简洁优雅：控制细节和色彩数量。
   - 极速达意：图形直接关联应用功能。
   - 情感表达：通过色彩和图形传递品牌情感。

5. **包体内图标 vs 商店展示图标**
   - 包体内：必须分层，1024×1024 PNG。
   - 商店展示：可合成，216×216 或 1024×1024，PNG/WEBP。
