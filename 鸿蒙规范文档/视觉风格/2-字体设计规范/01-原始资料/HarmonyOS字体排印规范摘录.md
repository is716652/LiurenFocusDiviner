# HarmonyOS NEXT 字体排印规范摘录

> 来源：[华为开发者文档 - 字体排印](https://developer.huawei.com/consumer/cn/doc/design-guides/typography-0000002622688363)

---

## 一、什么是字体排印

字体排印指的是在操作系统中对文字的布局和呈现方式的定义。在 UI 设计中，字体排印起着关键的作用，包括字体的大小、样式、行间距等，这些因素直接影响用户界面的可读性和整体美观性。

通过合适的字体排印，设计师可以确保用户能够轻松阅读和理解应用的内容，提升用户体验。除了确保文本清晰易读外，字体排印方式还可协助：

- 阐明信息层级结构
- 传达重要内容
- 宣传品牌

---

## 二、排版体验要求

| 要求 | 说明 |
|---|---|
| **最小可读字号** | UI 排版中使用的字号应大于用户可阅读的最小字号，以确保在各种设备上都能提供清晰可读的文本。 |
| **色彩和对比度** | 选择适当的颜色并确保足够的对比度，以确保文本在各种背景下清晰可辨，提升可读性。 |
| **一致的字体风格** | 保持字体的一致性，包括字重和字体风格，以创造整体协调的用户界面，增强品牌一致性。 |
| **简洁的样式表达信息** | 避免过度使用字号、粗细和颜色等样式，以确保信息层级清晰，提升用户理解文本内容的效果，同时应避免过多的层级导致界面过于复杂。 |
| **支持系统大字体** | 确保字体能够适应系统无障碍设置中的大字体模式，以提供对视觉障碍用户的友好支持。 |

## 三、文本应用：官方文字比例系统

文字比例是一种规定了不同字体大小的系统，旨在确保在用户界面中保持一致的视觉层次结构。这包括主标题、子标题、正文等不同文本元素的字号选择，以及它们之间的比例关系，以提高设计的一致性、可读性和美观性。

在 UI 界面的字体排版中，官方将排版字体的类型分为 **「展示、标题、副标题、正文、说明」** 五大类，并根据使用场景使用推荐的样式，以达到与系统一致的阅读体验。

### 3.1 文字比例表

### 3.2 各类文本使用场景

| 类别 | 典型用途 |
|---|---|
| **Display（展示性文本）** | 用于吸引用户注意力的大标题或短语，通常具有较大的字号和鲜明的样式。例如天气应用里的「温度数值」、计算器应用里的「计算结果」。 |
| **Title（标题文本）** | 页面标题、卡片标题、区域标题，用于建立信息层级。 |
| **Subtitle（副标题文本）** | 段落标题、列表项标题、辅助性标题，用于进一步细分内容。 |
| **Body（正文文本）** | 主要内容、段落文字、说明文字，是应用中最常使用的文本层级。 |
| **Caption（说明文本）** | 辅助说明、标签、时间、状态提示等次要信息。 |

---

## 四、关键摘录要点

1. **五大文本层级**：Display / Title / Subtitle / Body / Caption
2. **三层子级**：每个大类下分 L / M / S 三个子级，满足不同程度的强调需求
3. **多设备适配**：同一 Token 在不同设备（phone / PC / watch）上有不同推荐尺寸
4. **字重规范**：
   - Display 使用 Light
   - Title 使用 Bold
   - Subtitle 使用 Medium
   - Body 使用 Medium / Regular
   - Caption 使用 Medium
5. **单位使用 vp**：官方推荐使用 vp（virtual pixel）作为字号单位，实现多设备适配
