# 手写 HarmonyOS NEXT 文本样式代码示范

> 借鉴自：
> - `03-AI提示词/HarmonyOS字体设计_AI提示词.md`
> - `02-分析文档/字体设计分析.md`
>
> 本示例演示如何不依赖 AI，手动编写一段符合 HarmonyOS NEXT 字体排印规范的文本样式代码。
> 严格遵循官方文字比例系统：Display / Title / Subtitle / Body / Caption，每类包含 L / M / S 三个子级。

---

## 一、从 AI 提示词和分析文档中可以借鉴什么

即使你不用 AI，文档中的核心规范仍然可以直接指导你手写代码：

| 规范要点 | 手写代码时的做法 |
|---|---|
| 默认使用 HarmonyOS Sans | 不强制设置 `fontFamily`，让 `Text` 组件使用系统默认字体 |
| 使用官方文字比例系统 | Token 命名为 `text_title_l`、`text_body_m`、`text_caption_l` 等，对应 Display / Title / Subtitle / Body / Caption |
| 每类分 L / M / S 三个子级 | 同一类别用子级区分强调程度，例如 `Title_L` / `Title_M` / `Title_S` |
| 字号单位使用 vp / fp | `float.json` 中使用 `30fp`、`24fp`、`16fp` 等，支持多设备与无障碍大字体 |
| 字重规范 | Display 用 Light（ArkTS 中对应 FontWeight.Lighter），Title 用 Bold，Subtitle / Caption 用 Medium，Body 用 Medium 或 Regular |
| 不硬编码色值 | 文本颜色使用 `$r('app.color.xxx')` 引用 Token |
| 文本与背景对比度 ≥ 3:1 | 主文本用 `text_primary`，品牌色背景上用 `text_on_brand` |
| 支持系统大字体 | 使用 `fp` 单位，不固定 px |

> - `Body_*`：正文内容，字重 Medium 或 Regular。
> - `Caption_*`：辅助说明、标签、脚注，字重 Medium。

## 四、定义可复用的文本样式

### 4.1 使用 ArkTS 样式常量

在 `entry/src/main/ets/styles/TextStyles.ets` 中定义文本样式常量，便于多个页面复用。

```typescript
// entry/src/main/ets/styles/TextStyles.ets

/**
 * HarmonyOS NEXT 文本样式常量
 *
 * 基于官方文字比例系统：
 * Display / Title / Subtitle / Body / Caption
 * 每类包含 L / M / S 三个子级。
 *
 * - 字号、行高通过 $r('app.float.xxx') 引用 Token。
 * - 文本颜色通过 $r('app.color.xxx') 引用 Token。
 * - 默认使用 HarmonyOS Sans，不指定 fontFamily。
 */

export interface TextStyle {
  fontSize: Resource;
  fontWeight: FontWeight;
  lineHeight?: Resource;
  fontColor: ResourceColor;
}

export class TextStyles {
  // Display：超大展示文本
  static readonly displayL: TextStyle = {
    fontSize: $r('app.float.text_display_l_size'),
    fontWeight: FontWeight.Lighter,
    fontColor: $r('app.color.text_primary')
  };

  static readonly displayM: TextStyle = {
    fontSize: $r('app.float.text_display_m_size'),
    fontWeight: FontWeight.Lighter,
    fontColor: $r('app.color.text_primary')
  };

  static readonly displayS: TextStyle = {
    fontSize: $r('app.float.text_display_s_size'),
    fontWeight: FontWeight.Lighter,
    fontColor: $r('app.color.text_primary')
  };

  // Title：标题文本
  static readonly titleL: TextStyle = {
    fontSize: $r('app.float.text_title_l_size'),
    fontWeight: FontWeight.Bold,
    lineHeight: $r('app.float.text_title_l_line_height'),
    fontColor: $r('app.color.text_on_brand')
  };

  static readonly titleM: TextStyle = {
    fontSize: $r('app.float.text_title_m_size'),
    fontWeight: FontWeight.Bold,
    fontColor: $r('app.color.text_primary')
  };

  static readonly titleS: TextStyle = {
    fontSize: $r('app.float.text_title_s_size'),
    fontWeight: FontWeight.Bold,
    lineHeight: $r('app.float.text_title_s_line_height'),
    fontColor: $r('app.color.text_primary')
  };

  // Subtitle：副标题文本
  static readonly subtitleM: TextStyle = {
    fontSize: $r('app.float.text_subtitle_m_size'),
    fontWeight: FontWeight.Medium,
    lineHeight: $r('app.float.text_subtitle_m_line_height'),
    fontColor: $r('app.color.text_secondary')
  };

  // Body：正文文本
  static readonly bodyL: TextStyle = {
    fontSize: $r('app.float.text_body_l_size'),
    fontWeight: FontWeight.Medium,
    lineHeight: $r('app.float.text_body_l_line_height'),
    fontColor: $r('app.color.text_secondary')
  };

  static readonly bodyM: TextStyle = {
    fontSize: $r('app.float.text_body_m_size'),
    fontWeight: FontWeight.Regular,
    lineHeight: $r('app.float.text_body_m_line_height'),
    fontColor: $r('app.color.text_secondary')
  };

  // Caption：说明文本
  static readonly captionL: TextStyle = {
    fontSize: $r('app.float.text_caption_l_size'),
    fontWeight: FontWeight.Medium,
    lineHeight: $r('app.float.text_caption_l_line_height'),
    fontColor: $r('app.color.text_secondary')
  };
}
```

### 4.2 方式二：使用样式构建函数

如果你希望在不同场景下复用同一样式但微调颜色，可以使用构建函数：

```typescript
// entry/src/main/ets/styles/TextStyleBuilder.ets

import { TextStyle } from './TextStyles';

export function buildTitleL(color?: ResourceColor): TextStyle {
  return {
    fontSize: $r('app.float.text_title_l_size'),
    fontWeight: FontWeight.Bold,
    lineHeight: $r('app.float.text_title_l_line_height'),
    fontColor: color ?? $r('app.color.text_on_brand')
  };
}

export function buildBodyM(color?: ResourceColor): TextStyle {
  return {
    fontSize: $r('app.float.text_body_m_size'),
    fontWeight: FontWeight.Regular,
    lineHeight: $r('app.float.text_body_m_line_height'),
    fontColor: color ?? $r('app.color.text_secondary')
  };
}
```

## 五、页面文本代码示例

### 5.1 使用官方文字比例系统的页面实现

```typescript
// entry/src/main/ets/pages/Index.ets
import { TextStyles } from '../styles/TextStyles';

@Entry
@Component
struct Index {
  build() {
    // 页面根容器：使用 background Token 作为页面背景
    Column() {
      // 顶部品牌色背景区域
      Column() {
        Text($r('app.string.welcome_title'))
          .fontSize(TextStyles.titleL.fontSize)
          .fontWeight(TextStyles.titleL.fontWeight)
          .lineHeight(TextStyles.titleL.lineHeight)
          .fontColor(TextStyles.titleL.fontColor)

        Text($r('app.string.welcome_subtitle'))
          .fontSize(TextStyles.bodyL.fontSize)
          .fontWeight(TextStyles.bodyL.fontWeight)
          .lineHeight(TextStyles.bodyL.lineHeight)
          .fontColor(TextStyles.titleL.fontColor)
          .opacity(0.9)
          .margin({ top: 8 })
      }
      .width('100%')
      .height('40%')
      .backgroundColor($r('app.color.brand_primary'))
      .justifyContent(FlexAlign.Center)

      // 内容卡片区域
      Column() {
        Text($r('app.string.content_title'))
          .fontSize(TextStyles.titleS.fontSize)
          .fontWeight(TextStyles.titleS.fontWeight)
          .lineHeight(TextStyles.titleS.lineHeight)
          .fontColor(TextStyles.titleS.fontColor)

        Text($r('app.string.content_desc'))
          .fontSize(TextStyles.bodyM.fontSize)
          .fontWeight(TextStyles.bodyM.fontWeight)
          .lineHeight(TextStyles.bodyM.lineHeight)
          .fontColor(TextStyles.bodyM.fontColor)
          .margin({ top: 12 })

        // 复习模块入口按钮
        Row() {
          Text($r('app.string.button_start'))
            .fontSize(TextStyles.subtitleM.fontSize)
            .fontWeight(TextStyles.subtitleM.fontWeight)
            .fontColor($r('app.color.text_on_brand'))
        }
        .width('70%')
        .height(48)
        .margin({ top: 24 })
        .backgroundColor($r('app.color.brand_primary'))
        .borderRadius(24)
        .justifyContent(FlexAlign.Center)

        // 底部说明
        Text($r('app.string.footer_note'))
          .fontSize(TextStyles.captionL.fontSize)
          .fontWeight(TextStyles.captionL.fontWeight)
          .lineHeight(TextStyles.captionL.lineHeight)
          .fontColor(TextStyles.captionL.fontColor)
          .margin({ top: 24 })
      }
      .width('90%')
      .padding(24)
      .margin({ top: -40 })
      .backgroundColor($r('app.color.surface'))
      .borderRadius(16)
      .shadow({ radius: 12, color: 'rgba(0,0,0,0.08)', offsetY: 4 })
    }
    .width('100%')
    .height('100%')
    .backgroundColor($r('app.color.background'))
  }
}
```

## 七、关键借鉴点总结

1. **字体全部走系统默认**
   - 不强制设置 `fontFamily`，让 `Text` 组件自动使用 HarmonyOS Sans。
   - 除非有强品牌需求，否则不引入第三方字体文件。

2. **遵循官方文字比例系统**
   - 使用 Display / Title / Subtitle / Body / Caption 五大类。
   - 每类使用 L / M / S 三个子级区分强调程度。
   - Token 命名与官方层级一一对应，便于设计与开发对齐。

3. **字号、行高使用 Token 管理**
   - 在 `float.json` 中定义 `text_title_l_size`、`text_body_m_line_height` 等语义化名称。
   - 组件代码中通过 `$r('app.float.xxx')` 引用，便于统一调整。
   - 使用 `fp` 单位，支持多设备适配和系统大字体。

4. **不硬编码色值**
   - 文本颜色全部使用 `$r('app.color.xxx')`。
   - 主文本用 `text_primary`，次要文本用 `text_secondary`，品牌色背景上用 `text_on_brand`。

5. **字重规范**
   - Display 用 `FontWeight.Lighter`（对应设计规范中的 Light 字重）。
   - Title 用 `FontWeight.Bold`。
   - Subtitle / Caption 用 `FontWeight.Medium`。
   - Body 用 `FontWeight.Medium` 或 `FontWeight.Regular`。

6. **可读性优先**
   - 为正文和辅助文字设置合适的 `lineHeight`。
   - 文本与背景对比度满足最小 3:1 规范。

7. **浅色/深色自动适配**
   - 颜色通过 `base/color.json` 和 `dark/color.json` 自动切换。
   - 字号 Token 只需定义在 `base/element/float.json` 中即可共用。
