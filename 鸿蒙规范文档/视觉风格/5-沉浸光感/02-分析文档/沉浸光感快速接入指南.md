# 沉浸光感快速接入指南

> 沉浸光感（Immersive Light）是 HarmonyOS NEXT 提供的增强型视觉能力，**并非所有应用的必选项**。它适合需要强化空间层级、提升精致度、处理背景重叠的界面。对于普通项目，按需局部引入即可，不需要全局改造。

---

## 一、什么时候需要使用沉浸光感

### 1.1 建议使用的情况

| 场景 | 说明 |
|------|------|
| 操作组件与内容背景重叠 | 顶部导航栏、底部操作栏悬浮在图片/视频/复杂内容之上时，使用材质可自然分离层级。 |
| 背景是图片、视频或动态内容 | 纯色背景无法体现光感优势，复杂背景下材质效果更明显。 |
| 需要提升界面精致度与空间感 | 如音乐、相册、阅读、天气等强调视觉氛围的应用。 |
| 存在临时弹出层 | 弹窗、菜单、Sheet、Toast 等覆盖层使用材质可增强层级表达。 |
| 希望交互有光影反馈 | 按钮、卡片等可触摸元素需要更生动的按压/滑动反馈。 |

### 1.2 不建议使用的情况

| 场景 | 原因 |
|------|------|
| 页面背景为纯色或简单渐变 | 光感效果不明显，增加复杂度却无收益。 |
| 信息密度极高的工具类页面 | 额外模糊/光影可能干扰阅读效率。 |
| 需要严格保持品牌色一致性 | 系统材质会自动调整背景色、边框、阴影，可能与品牌规范冲突。 |
| 低端设备或性能敏感场景 | 材质渲染涉及模糊、折射等计算，需评估性能开销。 |

## 二、快速接入三步法

### 第一步：判断是否有重叠场景

浏览应用页面，找出以下元素：

- 顶部悬浮导航栏
- 底部悬浮操作栏 / Tab 栏
- 搜索框
- 按钮（尤其叠加在图片上）
- 弹窗 / 菜单 / Sheet / Toast

如果这些元素下方有图片、视频或复杂内容，就适合使用沉浸光感。

### 第二步：选择合适的材质档位

根据元素位置与覆盖面积，参考下表快速选择 `ImmersiveStyle`：

| 元素类型 | 推荐档位 | 理由 |
|----------|----------|------|
| 顶部悬浮栏 | `ULTRA_THIN` | 最通透，不遮挡背景内容。 |
| 底部悬浮栏 | `THIN` | 适度分离操作区，保持轻盈。 |
| 搜索框 / 小型按钮 | `THIN` / `REGULAR` | 需要一定视觉重量。 |
| 菜单 / 提示气泡 | `THICK` | 复杂背景下保证可读性。 |
| 弹窗 / 半模态 Sheet | `ULTRA_THICK` | 大面积覆盖，强焦点。 |

### 第三步：一行代码接入

对需要添加材质的组件，只需设置 `.systemMaterial()`：

```typescript
import { uiMaterial } from '@kit.ArkUI';

Column() {
  Text('悬浮在背景上的内容')
}
.systemMaterial(new uiMaterial.ImmersiveMaterial({
  style: uiMaterial.ImmersiveStyle.ULTRA_THIN
}))
```

系统会自动处理背景色、边框、阴影和材质滤镜，无需手动写模糊或半透明背景。

## 三、典型场景快速模板

### 3.1 顶部导航栏悬浮在图片上

```typescript
Column() {
  Row() {
    Image($r('app.media.ic_back')).width(24).height(24)
    Text('标题').fontSize(18).fontColor(Color.White)
    Image($r('app.media.ic_more')).width(24).height(24)
  }
  .justifyContent(FlexAlign.SpaceBetween)
  .width('100%')
  .padding({ left: 16, right: 16, top: 50, bottom: 12 })
}
.systemMaterial(new uiMaterial.ImmersiveMaterial({
  style: uiMaterial.ImmersiveStyle.ULTRA_THIN
}))
```

### 3.2 底部操作栏

```typescript
Column() {
  Row() {
    Button('取消').fontColor(Color.White)
    Button('确定').fontColor(Color.White)
  }
  .justifyContent(FlexAlign.SpaceAround)
  .width('100%')
  .padding(16)
}
.systemMaterial(new uiMaterial.ImmersiveMaterial({
  style: uiMaterial.ImmersiveStyle.THIN
}))
```

### 3.3 弹窗 / 半模态 Sheet

```typescript
.bindSheet($$this.isShow, this.myBuilder(), {
  height: 300,
  backgroundColor: Color.Transparent,
  systemMaterial: new uiMaterial.ImmersiveMaterial({
    style: uiMaterial.ImmersiveStyle.ULTRA_THICK
  })
})
```

### 3.4 带交互反馈的按钮

```typescript
Button('播放')
  .systemMaterial(new uiMaterial.ImmersiveMaterial({
    style: uiMaterial.ImmersiveStyle.REGULAR,
    interactive: true,
    lightEffect: { color: undefined }
  }))
```

## 四、接入决策树

```
开始
  │
  ▼
该元素下方是否有图片/视频/复杂内容？
  │
  ├─ 否 ──▶ 不使用沉浸光感，保持纯色背景
  │
  ▼
该元素是否常驻悬浮？
  │
  ├─ 是，顶部 ──▶ ULTRA_THIN
  ├─ 是，底部 ──▶ THIN
  └─ 否，临时弹出 ──▶ 弹窗/Sheet 用 ULTRA_THICK，菜单/气泡用 THICK
  │
  ▼
是否需要点击反馈？
  │
  ├─ 是 ──▶ 开启 interactive + lightEffect
  └─ 否 ──▶ 仅设置 style
```

## 五、注意事项

1. **不要全局滥用**：只在真正需要层级分离的地方使用，避免整个页面所有组件都加材质。
2. **弱档下检查可读性**：用户可能将光感强度调到弱档，此时文字/图标仍需清晰。
3. **配合自动反色**：复杂背景上的文字建议开启 `colorInvert: true`。
4. **性能意识**：大面积频繁使用模糊材质可能影响帧率，关键页面需实测。
5. **与品牌色协调**：系统材质会改变视觉表现，若品牌对颜色要求严格，谨慎使用。

---

## 六、一句话总结

> **沉浸光感是“锦上添花”的能力，不是“雪中送炭”的必需品。只要记住「有重叠、背景复杂、需要层级分离」这三个关键词，就能快速判断是否使用，并在一行代码内接入。**
