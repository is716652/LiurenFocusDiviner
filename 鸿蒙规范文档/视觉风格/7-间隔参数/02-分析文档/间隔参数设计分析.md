# 间隔参数设计分析

## 一、核心概念解析

### 1.1 什么是间隔参数

间隔参数是设计系统中用于控制元素之间、元素与容器之间、元素与屏幕边缘之间空白距离的一组数值规范。它是界面布局的“呼吸空间”，直接影响：

- **视觉秩序**：让界面看起来规整、不拥挤。
- **信息层级**：通过间距大小区分内容的重要性和归属关系。
- **阅读舒适度**：合理的留白让眼睛更容易聚焦和移动。
- **触控体验**：避免元素过于密集导致误触。

### 1.2 间隔参数解决了什么问题

| 问题 | 间隔参数的作用 |
|------|---------------|
| 界面拥挤、信息堆叠 | 通过留白梳理模块边界 |
| 层级关系不明确 | 用间距大小区分上下级关系 |
| 同页面风格不一致 | 统一间距 token，保证多组件协调 |
| 内容贴边影响阅读 | 固定屏幕边缘安全边距 |
| 跨设备显示混乱 | 按设备类型定义不同边距 |

## 二、HarmonyOS 间隔体系

### 2.1 基础栅格：4vp / 8vp

HarmonyOS 推荐以 4vp 或 8vp 为基数，所有间距使用其倍数。这样能保证：

- 数值有规律，易于记忆和维护。
- 多组件拼接时自然对齐。
- 跨设备缩放时保持一致的视觉比例。

常用基础间距值：

| 数值 | 适用场景 |
|------|----------|
| 2vp | 主次文本上下紧密间隔 |
| 4vp | 极小间距、图标与文字间紧凑间隔 |
| 8vp | 普通元素间距、文本左右间隔 |
| 12vp | 卡片之间间距 |
| 16vp | 较大控件间距、有明显边界模块间距离 |
| 20vp | 大模块间距 |
| 24vp | 智慧屏等大屏设备的大间距 |
| 28vp | 手机底部边距 |
| 32vp | 平板左右边距 |
| 36vp | 手机/平板顶部边距 |
| 40vp | PC 左右边距 |
| 48vp | 智慧屏/智能座舱/PC 等大屏边距 |

### 2.2 按类型分类

| 类型 | 说明 | 示例 |
|------|------|------|
| 屏幕边缘间隔 | 内容到屏幕边缘的安全距离 | 页面左右 margin |
| 元素间间隔 | 控件与控件之间的距离 | 按钮之间、卡片之间 |
| 文本间间隔 | 文本段落或行之间的留白 | 标题与正文之间 |

---

## 三、两条核心设计原则

### 3.1 统一栅格体系

所有间距优先使用固定基数的倍数，避免随意数值。

**推荐做法**：
- 使用 4vp / 8vp 体系。
- 常见间距：2、4、8、12、16、20、24、28、32、36、40、48 vp。

**避免做法**：
- 使用 5vp、7vp、13vp、19vp 等无规律数值。
- 不同页面使用不同的间距尺度。

### 3.2 层级正相关

间距大小与信息层级呈正相关：

- 层级越高、独立性越强的元素，间距越大。
- 同级元素间距保持一致。
- 上下级内容间距逐级区分。

**示例层级关系**：

```
页面边缘到内容区：16vp（手机）
  ↓
大模块之间：20vp ~ 24vp
  ↓
模块内控件之间：12vp ~ 16vp
  ↓
紧密关联的控件之间：8vp
  ↓
图标与文字之间：4vp
  ↓
文本行之间：2vp ~ 4vp
```

## 四、多设备适配策略

HarmonyOS 是跨设备系统，不同屏幕尺寸需要不同的边缘间距：

| 设备 | 左右边距 | 顶部边距 | 底部边距 |
|------|----------|----------|----------|
| 手机 | 16vp | 36vp | 28vp |
| 折叠屏 | 24vp | 36vp | 28vp |
| 平板 | 32vp | 36vp | 28vp |
| 智慧屏 | 48vp | 27vp | 27vp |
| 穿戴 | 26vp | 20vp | 20vp |
| PC | 40vp | / | / |
| 智能座舱 | 48vp | / | / |

### 4.1 设计启示

- **屏幕越小，边距越小**：手机 16vp，平板 32vp，PC 40vp。
- **内容距离边缘要有足够“安全区”**，避免被系统栏或手势区域遮挡。
- **元素间距也需要随设备放大**：智慧屏的普通间距 12vp 对应手机的 8vp，较大间距 24vp 对应手机的 16vp。

## 五、各场景详细映射

### 5.1 手机屏幕典型间距

| 场景 | 推荐间距 | 说明 |
|------|----------|------|
| 页面左右边距 | 16vp | 内容不贴边 |
| 页面顶部边距 | 36vp | 包含状态栏安全区 |
| 页面底部边距 | 28vp | 包含导航栏安全区 |
| 卡片之间 | 12vp | 区分相邻卡片 |
| 有明显边界控件间 | 16vp | 模块感强 |
| 无明显边界控件间 | 8vp | 紧凑但清晰 |
| 主次文本上下 | 2vp | 紧凑关联 |
| 主次文本左右 | 8vp | 横向关系 |

### 5.2 智慧屏典型间距

| 场景 | 推荐间距 | 说明 |
|------|----------|------|
| 页面左右边距 | 48vp | 大屏需要更多留白 |
| 页面顶部/底部边距 | 27vp | 适配电视安全区 |
| 有明显边界控件间 | 24vp | 远距离观看清晰 |
| 普通控件间 | 12vp | 适中 |
| 较小控件间 | 8vp | 紧凑组合 |

## 六、常见误区

| 误区 | 正确做法 |
|------|----------|
| 间距完全凭感觉 | 使用 4vp/8vp 栅格体系，固定 token |
| 所有间距都一样大 | 按层级区分，大模块大间距，小元素小间距 |
| 内容贴边布局 | 保留固定屏幕边缘边距 |
| 同类型元素间距不同 | 建立统一间距 token |
| 忽略多设备适配 | 按手机/平板/智慧屏分别定义边距 |
| 间距过大导致页面松散 | 在呼吸感和信息密度之间找平衡 |

## 七、设计交付清单

向开发交付间距相关设计时，建议包含：

- [ ] 各元素的间距 token 标注（如 space_8、space_16）
- [ ] 页面边距标注（区分左右/上下）
- [ ] 同类型组件间距一致性检查
- [ ] 多设备下的间距差异说明
- [ ] 文本间距与元素间距的区分
