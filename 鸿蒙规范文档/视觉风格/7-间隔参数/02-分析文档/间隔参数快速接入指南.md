# 间隔参数快速接入指南

> 间隔参数是 HarmonyOS 设计系统的基础布局规范，**并非需要额外引入的复杂能力**。它本质上就是“用统一的间距值让界面更整齐”。对于一般项目，只要建立间距 token 并坚持使用，就能快速提升界面秩序感。

---

## 一、什么时候需要关注间隔参数

### 1.1 建议使用标准间隔参数的情况

| 场景 | 说明 |
|------|------|
| 页面元素感觉拥挤或松散 | 通过统一间距建立呼吸感 |
| 同类型组件间距不一致 | 需要统一 token 保证视觉协调 |
| 多页面风格不统一 | 建立全局间距规范，减少随意值 |
| 需要适配多设备 | 手机/平板/智慧屏需要不同边距 |
| 页面层级关系不明显 | 用间距大小区分模块层级 |

### 1.2 可以简化处理的情况

| 场景 | 说明 |
|------|------|
| 极简原型或 Demo | 临时使用硬编码间距可接受 |
| 完全自定义设计系统 | 有自己的间距规则时按品牌执行 |
| 单一简单页面 | 元素很少时可以凭视觉调整 |

## 二、快速接入三步法

### 第一步：识别页面中的间距关系

浏览页面，找出以下关系：

- 内容到屏幕边缘的距离（边距）
- 大模块之间的距离（模块间距）
- 模块内部控件之间的距离（元素间距）
- 文本之间的距离（文本间距）
- 卡片之间的距离（卡片间距）

### 第二步：按标准栅格选择间距值

HarmonyOS 推荐以 4vp/8vp 为基数的间距体系：

| 场景 | 推荐间距 | 说明 |
|------|----------|------|
| 文本行之间 | 2vp | 主次文本紧密关联 |
| 图标与文字之间 | 4vp ~ 8vp | 横向辅助信息 |
| 同一组内控件间 | 8vp | 无明显边界 |
| 卡片之间 | 12vp | 区分相邻卡片 |
| 有明显边界模块间 | 16vp | 模块感强 |
| 大模块之间 | 20vp ~ 24vp | 层级区分 |

### 第三步：在代码中设置 padding / margin

```typescript
Column() {
  // 内容
}
.padding({ left: 16, right: 16, top: 36, bottom: 28 })  // 手机屏幕边距
```

## 三、快速决策树

```
开始
  │
  ▼
间距发生在什么位置？
  │
  ├─ 内容到屏幕边缘 ──▶ 按设备选择边距
  │     ├─ 手机左右：16vp
  │     ├─ 手机顶部：36vp
  │     ├─ 手机底部：28vp
  │     ├─ 平板左右：32vp
  │     └─ 智慧屏左右：48vp
  │
  ├─ 文本之间 ──▶ 2vp（紧密）或 4vp（宽松）
  │
  ├─ 同一组内控件之间 ──▶ 8vp
  │
  ├─ 卡片之间 ──▶ 12vp
  │
  ├─ 有明显边界模块之间 ──▶ 16vp
  │
  └─ 大模块之间 ──▶ 20vp ~ 24vp
  │
  ▼
同类型元素是否已存在？
  │
  ├─ 是 ──▶ 与已有元素保持一致的间距 token
  └─ 否 ──▶ 按标准档位新增
```

## 四、最小可用示例

### float.json

```json
{
  "float": [
    { "name": "space_text_tight", "value": "2vp" },
    { "name": "space_xsmall", "value": "4vp" },
    { "name": "space_small", "value": "8vp" },
    { "name": "space_medium", "value": "12vp" },
    { "name": "space_large", "value": "16vp" },
    { "name": "space_xlarge", "value": "20vp" },
    { "name": "margin_page_horizontal", "value": "16vp" },
    { "name": "margin_page_top", "value": "36vp" },
    { "name": "margin_page_bottom", "value": "28vp" }
  ]
}
```

### 页面代码

```typescript
@Entry
@Component
struct SpacingDemoPage {
  build() {
    Column({ space: 16 }) {
      Column() {
        Text('主标题')
          .fontSize(18)
          .fontWeight(FontWeight.Bold)
        Text('副标题描述')
          .fontSize(14)
          .fontColor($r('app.color.text_secondary'))
          .margin({ top: 2 })
      }

      Row({ space: 8 }) {
        Image($r('app.media.icon')).width(24).height(24)
        Text('横向辅助信息').fontSize(14)
      }

      Column({ space: 12 }) {
        ForEach([1, 2, 3], (item: number) => {
          Column() {
            Text(`卡片 ${item}`)
          }
          .width('100%')
          .height(60)
          .backgroundColor($r('app.color.surface'))
          .borderRadius(8)
          .justifyContent(FlexAlign.Center)
        }, (item: number) => item.toString())
      }
    }
    .width('100%')
    .height('100%')
    .padding({
      left: 16,
      right: 16,
      top: 36,
      bottom: 28
    })
  }
}
```

## 五、注意事项

1. **不要 invent 新间距**：优先使用 4vp/8vp 栅格倍数，避免 5vp、7vp、13vp 等随意值。
2. **同类型一致**：所有卡片间距统一用一个 token，不要有的 10vp 有的 12vp。
3. **间距与层级正相关**：大模块之间间距大，小元素之间间距小。
4. **保留屏幕边缘留白**：内容不要贴边，手机左右至少 16vp。
5. **多设备适配**：通过资源目录覆盖不同设备的边距值。
6. **padding 还是 margin**：
   - `padding`：元素内部内容与边界的距离。
   - `margin`：元素与其他元素之间的距离。

---

## 六、一句话总结

> **间隔参数是“用统一留白让界面有呼吸感”的基础规范。只要记住 4vp/8vp 栅格、按层级选间距、保留屏幕边距，就能快速落地。**
