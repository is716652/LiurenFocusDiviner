# 间隔参数代码示范

> 本示例展示如何在 HarmonyOS ArkTS 中使用官方间隔参数，并通过 `float.json` 统一管理间距 token。

---

## 一、定义间距 Token

在 `entry/src/main/resources/base/element/float.json` 中新增间距 token：

```json
{
  "float": [
    {
      "name": "space_text_tight",
      "value": "2vp"
    },
    {
      "name": "space_xsmall",
      "value": "4vp"
    },
    {
      "name": "space_small",
      "value": "8vp"
    },
    {
      "name": "space_medium",
      "value": "12vp"
    },
    {
      "name": "space_large",
      "value": "16vp"
    },
    {
      "name": "space_xlarge",
      "value": "20vp"
    },
    {
      "name": "space_xxlarge",
      "value": "24vp"
    },
    {
      "name": "margin_page_horizontal",
      "value": "16vp"
    },
    {
      "name": "margin_page_top",
      "value": "36vp"
    },
    {
      "name": "margin_page_bottom",
      "value": "28vp"
    }
  ]
}
```

> 如果项目中已有其他 float token，直接在原有数组中追加即可，不要覆盖。

## 二、基础用法：间距设置

### 2.1 页面边距（手机）

```typescript
Column() {
  // 页面内容
}
.width('100%')
.height('100%')
.padding({
  left: $r('app.float.margin_page_horizontal'),
  right: $r('app.float.margin_page_horizontal'),
  top: $r('app.float.margin_page_top'),
  bottom: $r('app.float.margin_page_bottom')
})
```

### 2.2 文本间紧密间距（2vp）

```typescript
Column() {
  Text('主标题')
    .fontSize(18)
    .fontWeight(FontWeight.Bold)

  Text('副标题描述')
    .fontSize(14)
    .fontColor($r('app.color.text_secondary'))
    .margin({ top: $r('app.float.space_text_tight') })
}
```

### 2.3 元素间普通间距（8vp）

```typescript
Row({ space: 8 }) {
  Image($r('app.media.icon'))
    .width(24)
    .height(24)

  Text('辅助说明')
    .fontSize(14)
}
```

或使用 `.margin`：

```typescript
Row() {
  Image($r('app.media.icon')).width(24).height(24)
  Text('辅助说明').fontSize(14).margin({ left: 8 })
}
```

### 2.4 卡片间距（12vp）

```typescript
List({ space: 12 }) {
  ListItem() {
    // 卡片内容
  }
  ListItem() {
    // 卡片内容
  }
}
```

### 2.5 模块间大间距（16vp）

```typescript
Column({ space: 16 }) {
  Column() { /* 模块 A */ }
  Column() { /* 模块 B */ }
}
```

### 2.6 大模块间距（20vp）

```typescript
Column() {
  Column() { /* 顶部模块 */ }
    .margin({ bottom: 20 })

  Column() { /* 底部模块 */ }
}
```

## 三、统一间距工具类（可选）

如果项目中多处使用，可以封装一个 `SpacingTokens` 工具类：

```typescript
// entry/src/main/ets/styles/SpacingTokens.ets
export class SpacingTokens {
  static readonly textTight: Resource = $r('app.float.space_text_tight');  // 2vp
  static readonly xsmall: Resource = $r('app.float.space_xsmall');          // 4vp
  static readonly small: Resource = $r('app.float.space_small');            // 8vp
  static readonly medium: Resource = $r('app.float.space_medium');          // 12vp
  static readonly large: Resource = $r('app.float.space_large');          // 16vp
  static readonly xlarge: Resource = $r('app.float.space_xlarge');          // 20vp
  static readonly xxlarge: Resource = $r('app.float.space_xxlarge');        // 24vp
}

export class PageMargin {
  static readonly horizontal: Resource = $r('app.float.margin_page_horizontal'); // 16vp
  static readonly top: Resource = $r('app.float.margin_page_top');               // 36vp
  static readonly bottom: Resource = $r('app.float.margin_page_bottom');         // 28vp
}
```

使用方式：

```typescript
import { SpacingTokens, PageMargin } from '../styles/SpacingTokens';

Column() { ... }
  .padding({
    left: PageMargin.horizontal,
    right: PageMargin.horizontal,
    top: PageMargin.top,
    bottom: PageMargin.bottom
  })

Text('描述')
  .margin({ top: SpacingTokens.textTight })
```

## 四、多设备边距适配

如果应用需要同时适配手机和平板，可以在 `float.json` 中按设备目录放置不同值：

```
resources/
├── base/element/float.json        # 手机默认值
├── tablet/element/float.json      # 平板覆盖值
├── wear/element/float.json        # 穿戴覆盖值
```

例如 `resources/tablet/element/float.json`：

```json
{
  "float": [
    {
      "name": "margin_page_horizontal",
      "value": "32vp"
    }
  ]
}
```

代码中只需引用同一 token：

```typescript
Column() { ... }
  .padding({
    left: $r('app.float.margin_page_horizontal'),
    right: $r('app.float.margin_page_horizontal')
  })
```

系统会根据当前设备自动选择对应目录下的值。

## 五、常见组件推荐间距速查表

| 场景 | 推荐间距 | 说明 |
|------|----------|------|
| 文本行之间 | 2vp | 主次文本紧密关联 |
| 图标与文字之间 | 4vp ~ 8vp | 横向辅助信息 |
| 同一组内控件间 | 8vp | 无明显边界 |
| 卡片之间 | 12vp | 区分相邻卡片 |
| 有明显边界模块间 | 16vp | 模块感强 |
| 大模块之间 | 20vp ~ 24vp | 层级区分 |
| 手机页面左右边距 | 16vp | 内容安全区 |
| 手机页面顶部边距 | 36vp | 含状态栏 |
| 手机页面底部边距 | 28vp | 含导航栏 |
| 平板页面左右边距 | 32vp | 大屏更多留白 |
| 智慧屏页面左右边距 | 48vp | 远距离观看 |

---

## 六、注意事项

1. **统一 token 管理**：所有间距尽量通过 `float.json` 引用，避免页面中硬编码 `margin(15)` 等随意值。
2. **使用栅格倍数**：优先使用 2、4、8、12、16、20、24、28、32、36、40、48 vp。
3. **层级正相关**：大模块之间用大间距，小元素之间用小间距。
4. **同类型一致**：同场景间距保持相同 token。
5. **屏幕边缘留白**：不要出现内容贴边的情况。
6. **按设备适配**：多设备场景下，通过资源目录覆盖不同边距值。
