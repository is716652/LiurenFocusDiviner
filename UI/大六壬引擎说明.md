# 大六壬引擎说明（读象工作台 v1.x）

> 载体：`UI/大六壬万年历起课.html`（Web 原型，单文件 + `UI/_data/*.js` 数据）
> 理念：**理论全部 JSON 化、数据驱动**——改规则只改数据不改代码；每条规则带出处与置信度；校对记录可回溯。

## 二、抓用神主流程（runLeishen，随用神实时联动）

1. **选占事**（12 大类 chips）→ 显示落象提示词 + 信息完整度提示
2. **抓用神候选**：六亲地支（日干五行）+ **天将类神（按布列宫位反查）** + 地支取象 → pills 可切换
3. **动态三传**：以用神为初传，传来递生（c2=c.tp[c1], c3=c.tp[c2]）——换用神三传即变
4. **用神节点卡**：干支+六亲+乘将 + 旺衰/空亡/气机点 + **类象词云**（天将/地支/天干/纳音，可点选锚定）+ **起爆点**（冲/空/合/害/刑/与日干关系）+ **所带神煞**（真计算）
5. **盘态·气机链**：月建→旺衰(白话注)→十二长生(日支宫,[展开]全表)→气机点(下一气机)→冲宫 + 旬空/月将贵人助日/用神状态
6. **毕法格局区**：随用神动态三传判定；占事相关 ⭐ 展开、不相关折叠"其它格局"；点击展开五层定位（条件分支按真实盘值命中才显示）
7. **管辂象意直断**：507 条断语按 **盘态信号匹配**（乘将/用神支/落空/旺相/所带神煞）打分选句，标命中依据；**收光一句**（状态链+锚定象+最高分断语）

## 三、各引擎核心要点

### 盘态（computeDuxiang）
| 项 | 数据源 | 说明 |
|---|---|---|
| 旬空 | XUN_KONG（日柱定旬） | 甲子旬空戌亥…六旬 |
| 旺衰 | 旺衰休囚死.json | 日干×月支表（庚酉为旺）；12支按月令五行 |
| 气机点 | 十二宫气机点.json | 阳干顺/阴干逆 十二长生，冲宫提前窗口 |
| 关系 | 基础关系.json | 六冲/六合/六害/三刑/五行生克 |
| 月将助日 | 助日规则.json | 临干/生干/发用/旺相→助；克干/空/墓→不助 |
| 贵人助日 | 助日规则.json | 临干/生干/旺相/阴阳合→助；入墓/空/受制→无力 |

### 神煞（computeShensha，35 个）
- **岁煞**（年支）：太岁/岁破/病符/丧门/吊客/太阴
- **季煞**（月支→季）：天喜/孤辰/寡宿/皇书/死神
- **月煞**（月支）：月破/生气/死气/天马/天医/地医/月厌/成神/血忌/血支
- **旬煞**（日柱定旬）：旬空/旬丁(丁马)/旬癸(闭口)
- **干煞**（日干）：日德/日禄/游都/鲁都/飞符
- **支煞**（日支）：驿马/劫煞/亡神/华盖/桃花/破碎
- 每条含：分类/基准/查表/主事/吉凶/出处/**置信度**（确=通行；存疑=流派分歧已标注）

### 毕法格局（bifaForChuans，18 个可判定）
前后引从 / 首尾相见 / 帘幕贵人 / 六阳数足 / 六阴相继 / 旺禄临身 / 权摄不正禄临支 / 进茹空亡 / 退茹空亡 / 传财化鬼 / 传鬼化财 / 三传互克 / 闭口 / 富贵干支禄马 / 太阳射宅 / 干乘墓虎 / 虎乘遁鬼 / 官鬼临三四

- 判定依据：四课三传组合（天地盘为原料）；用神即初传 → 动态三传评估 → 格局随用神变
- 五层定位：**定性**（是什么事）/**定象**（在哪发生）/**定时**（何时转变）/**定策**（怎么办·破局点）/**定级**（多严重）
- 条件分支（裸词）引擎评估：若乘将为X/若逢空/若未空/若旺相/若休囚/若衰死/若临月建/若临太岁/若逢丁马——命中才显示
- 适用占事过滤：不相关格局折叠，相关 ⭐ 展开

## 四、数据驱动与质控

- **改规则不改代码**：旺衰表/神煞取法/毕法判定与定位/类象/断语全是 JSON
- **置信度**：每条规则标 确/存疑；存疑处（亡神/破碎/血支/飞符/太阴等）注明两说
- **校对记录**：`神煞/神煞校对记录.md`（32条）、`毕法赋/毕法赋校对记录.md`（39条），原件备份保留
- **单元测试**：旺衰/气机点/旬空/神煞35/格局18/条件分支——node 脚本验证
- **修复记录**：月份键（寅=1）、旬煞按旬查表（同支不同旬）、checkBifa 依赖顺序、条件分隔符（；。分段）等

## 五、关键设计决策（对暗号而非念口诀）

1. **用神=动态三传初传**：格局/读象随用神切换实时变化，断者所见即所选
2. **盘态真计算**：神煞/空亡/旺衰是算出来的，不是关键词猜测——管辂断语命中依据 `✓带驿马` 是真实盘值
3. **布局从简**：信息分层——候选→节点卡→盘态→格局→断语，逐层展开；格局默认折叠
4. **类象锚定**：词云点选落象（"银行/牢狱"），断语围绕锚定象生成，人机协作
5. **信息完整度提示**：不强制补信息，但提示"可补：年命/方位"以细化
