当采用两套不同的天干系统（日干遁天干和时干遁天干）时，与之紧密绑定的**十二天将（贵人神煞）的排布只看日干**

---

### **核心原理**

十二天将的排布，其起例依赖于一个明确的“基准天干”：日干：

| 日干 | 昼贵人 | 夜贵人 |
| ---- | ------ | ------ |
| 甲   | 丑     | 未     |
| 乙   | 子     | 申     |
| 丙   | 亥     | 酉     |
| 丁   | 酉     | 亥     |
| 戊   | 丑     | 未     |
| 己   | 子     | 申     |
| 庚   | 丑     | 未     |
| 辛   | 寅     | 午     |
| 壬   | 卯     | 巳     |
| 癸   | 巳     | 卯     |

1. 根据“昼贵”或“夜贵”口诀，确定天乙贵人的起始位置。
2. 顺逆排布其他天将。

**当基准天干改变时，整个天将系统的排布就会随之改变。**

### **具体影响**

在《中黄五变经》的两层天干系统中：

1. **当日干遁天干系统激活时（体）**：

   - 排布贵人神煞所依据的 **“基准天干”是原始的日干**。
   - 此时排出的天将盘，代表的是 **“本体固有的贵人运势与周遭环境”**。
2. **当时干遁天干系统激活时（用）**：

   - 排布贵人神煞所依据的 **“基准天干”任然是日干**。
   - 此时排出的天将盘，代表的是 **“在当前特定时机下，被引动和调用的贵人运势与临时环境”**。
