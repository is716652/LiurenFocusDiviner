## 一、总纲：中黄经是什么

**《大六壬五变中黄经》**为六壬秘本，演课与断法与诸书不同。序言【原文】：

> "一般六壬演课中的天干均以日干支的**旬遁**来排，而《中黄经》却以**日干及时干再演一次**，五鼠遁来排天干，因此有学者不认同此法。"

**核心差异一句话**：传统六壬用**旬遁**（天干固定），中黄经用**日干遁 + 时干遁**（天干随日、时变化）——"变"字即由此而来。

- ✅ **传承旁证**：《六壬神课金口诀》起课天干亦以日干再起五鼠遁排出，中黄经与之相通，非孤例。
- ✅ **渊源自注**：经文自注《玄门宝鉴》第百六卷"相克相生法"（全书本在河中府龙门县、荣和县后土宫）。

## 二、核心机制：三遁与"变干"

大六壬天干配支有三种遁法，中黄经将其**叠加使用**：

| 遁法 | 起遁基准 | 作用 | 中黄经定位 |
|---|---|---|---|
| **旬遁** | 日柱所在旬的甲 | 三传/盘面配干（标准六壬） | 传统层，作为对照 |
| **日干遁**（五子元遁） | **日干** | 全盘十二宫配干 | "体"——本体能量 |
| **时干遁**（复建） | **时干** | 再起五鼠遁全盘 | "用"——最终断课依据 |

**时干的来历**（关键）：时干 = 日干遁到**占时支**的干（六壬通用规则）。

**"变干"定义**：时干遁盘中，**占时支**对应之干即为"变干"——它是中黄断课的核心枢纽，一切吉凶围绕"变干是否克/生/助日干"展开。

> 【以天干为枢纽】"日干可变，以时支再遁出一干，称为变干，用于定十神、断神将相乘吉凶、入三传年命行年、看是否克日助日生日。"

## 三、算法（已验证）：日干遁 + 时干遁

### 五鼠遁口诀

> **甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。**

即：日干（或时干）决定"子宫"起始天干，顺地支顺序配十二宫（十干循环）。

| 起遁干 | 子宫干 |
|---|---|
| 甲 / 己 | 甲 |
| 乙 / 庚 | 丙 |
| 丙 / 辛 | 戊 |
| 丁 / 壬 | 庚 |
| 戊 / 癸 | 壬 |

### 三步算法

```
第 1 步 · 日干遁盘（体）：
   以日干起五鼠遁 → 十二宫配干
   例：庚日 → 子丙 丑丁 寅戊 卯己 辰庚 巳辛 午壬 未癸 申甲 酉乙 戌丙 亥丁

第 2 步 · 时干：
   日干遁盘[占时支] = 时干
   例：庚日未时 → 未宫=癸（时干癸）

第 3 步 · 时干遁盘（用/中黄盘）：
   以时干再起五鼠遁 → 十二宫配干
   例：时干癸 → 子壬 丑癸 寅甲 …（子宫得壬，即"时遁壬"）
   其中占时支对应的干 = 变干
```

### 经文课例反验（12 项全通过 ✅）

| 课例 | 经文标注 | 算法还原 |
|---|---|---|
| 庚辰日未时（释吉凶实意） | "日遁之鬼得丙戌、丙子" | 庚起丙子→戌宫丙、子宫丙 ✅ |
| 庚辰日未时 | "时遁壬，子中亦有壬" | 时干癸→癸起壬子→子壬 ✅ |
| 庚子日申时（释复建真鬼） | "五子元遁庚起丙子，故谓得庚辰乙酉" | 辰宫庚、酉宫乙 ✅ |
| 己未日巳时 | "日遁干在己巳" | 己同甲→巳宫己 ✅ |
| 戊戌日未时 | "今日天上遁戊临地下午" | 戊起壬子→午宫戊 ✅ |

## 五、体用神煞体系（十七精髓）

中黄断课以"**体用**"为纲：

| 层级 | 名称 | 含义 |
|---|---|---|
| 体 | 日干 | 立身之本、命局基石 |
| 用 | 时干 | 事端引线、变动枢机 |
| 变 | 中黄天干（变干） | 气运之化、最终吉凶 |

**十七精髓**（断课查察要点）：

1. **体**-日干为根 2. **用**-时干为引 3. **变**-变干为化
4. **遁**-五鼠遁双演 5. **鬼**-克我之干（灾厄） 6. **贼**-下克上（暗损）
7. **财**-我克之干（养命） 8. **父**-生我之干（庇护） 9. **子**-我生之干（解忧）
10. **兄**-同我之干（争夺） 11. **禄**-日干禄位 12. **贵**-天乙贵人
13. **生**-相生顺 14. **克**-相克逆 15. **合**-干合牵绊
16. **刑**-三刑六害 17. **破**-宫破干破传破

> **口诀**："看课之时，先定体用，再查鬼贼，寻其生克，观其合破。"

## 六、天将排布规则

### 天将固定顺序（贵人不重复）

天乙贵人 → 螣蛇 → 朱雀 → 六合 → 勾陈 → 青龙 → 天空 → 白虎 → 太常 → 玄武 → 太阴 → 天后

### 贵人落宫表（以日干为基准）

| 日干 | 昼贵 | 夜贵 | | 日干 | 昼贵 | 夜贵 |
|---|---|---|---|---|---|---|
| 甲 | 丑 | 未 | | 己 | 子 | 申 |
| 乙 | 子 | 申 | | 庚 | 丑 | 未 |
| 丙 | 亥 | 酉 | | 辛 | 寅 | 午 |
| 丁 | 酉 | 亥 | | 壬 | 卯 | 巳 |
| 戊 | 丑 | 未 | | 癸 | 巳 | 卯 |

### 顺逆判定（天门地户法）

- 贵人落地盘 **巳~戌**（巳午未申酉戌）→ **逆布**（逆时针）
- 贵人落地盘 **亥~辰**（亥子丑寅卯辰）→ **顺布**（顺时针）

> ⚠️ 重要澄清：天将排布**始终以日干为基准**（贵人表按日干），**不随日干遁/时干遁系统改变**——两套天干盘只影响"以何干断天将之气"，不影响天将落宫位置。

## 七、断课流程

```
1. 月将加时 → 排天地盘（天盘十二支加临地盘宫位）
2. 演四课（干上、支上…）
3. 九宗门取三传
4. 天将布列（日干定贵人 → 天门地户定顺逆）
5. 【中黄特有】双遁：
     日干遁盘（体）→ 定本体能量
     时干遁盘（用）→ 定变干 → 断课核心
6. 以变干断：
     变干克日 → 鬼（防官非疾病…）
     变干生日 → 父（得庇护文书…）
     我克变干 → 财（求财机会…）
     变干比日 → 兄（防争夺…）
     变干生我 → 子（逢凶化解…）
7. 查"建合"：日遁与时遁交加相合 → 建合（吉）；相合又相克 → 建合鬼（凶）
8. 参神煞、旺衰、年命 → 综合断
```

### "建合"概念（中黄特色，释复建真鬼）

> "日遁与时遁，上下建得交加相合，即言伤我今日救不止矣。"
> "建合又复建合鬼，伤我今日救不止。"

- **建合**：日遁干与时遁干**相合**（如庚辰日"得庚辰乙酉"，庚乙合）→ 夫妇相见，鬼不能克
- **建合鬼**：建合之中**又暗藏克**（合处有鬼）→ 反成凶

## 九、存疑待考清单

以下为经文标注存疑处，研习时注意：

1. ⚠️ **"其课建于甲申"**（释门类诸人）：乙日何以建甲？疑指年命/行年建干或时遁，待考
2. ⚠️ **"巳中先建癸，后建丁"**（释别男女相害）：巳藏丙戊庚，与常规藏干不符，或为复建之法，待考
3. ⚠️ **"酉中得乙临辰，辰中有庚"**（释五行正形课例二）：藏干对应关系较晦（酉藏辛、辰藏乙），乙庚合之理可通，具体所指待考
4. ⚠️ **"三传年命无建丙辛即吉"**（释五行正形课例二）：建丙辛具体指何，待考
5. ⚠️ **天干二次排法 vs 以天干为枢纽**：前者主张"全盘复排"，后者强调"变干"单点——经算法验证，两者统一（全盘复排中占时支的干即变干），但经文层面仍以课例标注为准
6. ⚠️ **部分篇章过短（0.5KB）**：释年命遁法/遷官/妻财/婚姻/伏藏等篇 md 可能转录未完整，需对照原 PDF 复核
