## 天罡生旺为公吏

> 天罡乘吏神贵神剋我今日，行年财禄为吏，建辰干坐贵神，行年复食贵人，初传是今日印，或建干在劫亡刑煞上，即可取有禄公人。
>
> 若建干不在贵神，或行年不食贵神，则建干剋日，带劫亡破，三刑六害来剋日，为无禄公人。若依前建干剋日，带劫亡，更乘天驿二马，主大吏公人矣。

## 戊加四孟主多军

> 戊加劫亡，行年食贵禄，财入空亡为军，建戌中于剋今日，又要今日鬼劫亡羊刃，行年食贵神太岁，初传是悬针，若戌勾陈系矣。

## 贵人带印剋今日，便是终身有禄人

> 若初传是贵神，为贵神为鬼剋日，却贵人建干与今日为财，名曰贵人自战。又初传生日，或贵人坐处不旺，必主有禄官人争财，或贵人剋日，三传无禄，或贵人入空亡，即虚名官人也。
>
> 假令，甲日丑为贵神临申，名曰坐印，为丑得乙丑，乙取壬为印，甲得壬申，故曰贵人坐印，且如甲午日丑将寅时占。

## 《释门类诸人第四》详解

> 详解依据：竖版原文 + 课例程序化校验（4 课例全部通过）。标注体系：【直释】= 经文原意；【推阐】= 基于经文的推导；【旁证】= 引用典籍佐证；【存疑】= 待考处，不强解。

### 一、篇旨：断"害我者为何等人"——以干支建化辨人物类别

本篇与第三篇（宗亲）相对，专论**外来的"门类诸人"**——即害我者是道人、僧尼、公吏、军卒、匠人、医者、媒婆，还是贱贫之人。断法以**建干（遁干）所临之地、所乘之将、所带之煞**综合取象。

核心取象线索：
- **寅长生+华盖** → 道人；
- **甲临死绝+天空+华盖/孤寡** → 僧尼；
- **天罡（辰）乘吏神贵神** → 公吏；
- **戊加四孟+劫亡** → 军卒；
- **申午相加+六合** → 牙人媒人；
- **天地二医** → 医者；
- **鬼绝败空亡** → 贱贫之人。

【旁证】此以神煞+建干取"人物身份"之法，与《管辂六壬杂占神书》"神将取象"思路同源（见卷首序言）。

### 二、逐节详解

#### 1. "寅若长生是道人"

【直释】建寅干临**长生**之地，行年入**华盖**，更初传是亥，寅干食神入贵（或食神落空亡）→ 可取为**道人（道士）**相害。

【推阐】取象拆解：
- 寅 = 道人之象（寅为仙道之方）；
- 长生 = 寅干所临有气之地；
- 华盖 = 僧道之煞；
- 亥 = 初传（亥为天门，通神之象）；
- 食神入贵 / 食神落空亡 → 或取外非（出家）。

**课例一解析**（戊戌日 丑将 戌时，校验通过 ✅）：

| 项目 | 内容 |
|:--:|:-----|
| 四课 | 申/戊、亥/申、丑/戌、辰/丑 |
| 取传 | 无贼克 → **遥克·弹射**（戊克亥）→ 亥寅巳 |
| 断语 | 初传亥临申（亥水长生在申），建癸亥于长生；中传甲寅；行年丑临，贵神辰落空亡（甲午旬辰巳空）→ **道士相害**，乘白虎主行室 |

【直释】"初传亥临申，建癸亥于长生"——亥水长生在申，初传亥加临申，为建干立长生之地；"贵神在辰落空亡"——戊戌日为甲午旬，辰巳空亡，贵人落空 → 道人之象。

#### 2. "甲临死绝行尼僧"

【直释】建甲申乘**天空**，行年二马，加今日禄财，行在**死绝之方**，本命行年在华盖，初传入今日**孤辰寡宿**，或有辰巳亥戌三传 → **僧尼相害**。

【推阐】僧尼与道人区别：
- 道人：寅长生、有气；
- 僧尼：甲临**死绝**、天空（空门）、华盖、孤寡（独身之象）。

**课例二解析**（乙丑日 丑将 未时，校验通过 ✅）：

| 项目 | 内容 |
|:--:|:-----|
| 四课 | 戌/乙、辰/戌、未/丑、丑/未 |
| 取传 | 贼克·重审（课1乙克戌，下贼上）→ 戌辰丑 |
| 断语 | 初传戌临辰朱雀、中传辰临戌太常、末传丑临未天后；建于甲申，又见庚申，绝于寅克乙；行年本命皆在辰临戌；寡宿、空亡华盖 → **僧人相害** |

【存疑】"其课建于甲申"——乙日何以建甲？疑指年命/行年建干或时遁，标注待考。

#### 3. "天罡生旺为公吏"

【直释】天罡（辰）乘**吏神**、贵神，克今日，行年财禄为吏；建辰干坐贵神，行年复食贵人，初传是今日印，或建干在劫亡刑煞上 → **有禄公人（官吏）**。

【推阐】公吏断法要点：
- 有禄公人：建干坐贵 + 行年食贵 + 初传印绶；
- 无禄公人：建干克日带劫亡破、三刑六害，不坐贵、不食贵；
- 大吏：建干克日带劫亡，更乘天驿二马。

#### 4. "戊加四孟主多军"

【直释】戊加**劫亡**，行年食贵禄，财入空亡为**军**；建戌中干克今日，又要今日鬼劫亡羊刃，行年食贵神太岁，初传是**悬针**，若戌乘勾陈 → 军卒（文面之军）。

**课例三解析**（乙亥日 丑将 亥时，校验通过 ✅）：

| 项目 | 内容 |
|:--:|:-----|
| 四课 | 午/乙、申/午、丑/亥、卯/丑 |
| 取传 | 有下贼上（课4卯克丑），经文取**遥克·蒿矢**（申克乙）→ 申戌子（中黄经倾向遥克取传）|
| 断语 | 初传申临午贵神（重悬针）；中传戌加申，**戊加四孟**；行年亦戊加四孟；亥为劫煞，行年食禄神 → **文面军人相害** |

【直释】"重悬针"——申为悬针煞（金之象）叠加贵神；"戊加四孟"——戌（戊之支）加临四孟位（寅申巳亥）主军；亥劫煞、行年食禄 → 文面（刺字）军人之象。

#### 5. "贵人带印剋今日，便是终身有禄人"

【直释】初传贵神为鬼克日，却贵人建干与今日为财（贵神自战）；或初传生日，贵人坐处不旺 → **有禄官人争财**；贵人克日、三传无禄、贵人入空亡 → 虚名官人。

【推阐】"贵人坐印"例：甲日丑为贵神临申，丑得乙丑，乙取壬为印（壬水生乙木），甲得壬申 → 贵人坐印。

【存疑】"甲日丑为贵神"——甲戊庚牛羊，甲日贵人确在丑未；但"临申坐印"及乙取壬为印的生克关系原文较晦，标注待考。

#### 6. "申午相加作天后，用神大吉媾婿亲"

【直释】午申为**媒神**；申午相加带克为今日鬼 → 主相害者作**牙人兼媒人**；初传天空亦准。

**课例解析**（乙卯日 申时，经文未列完整课表，仅作文字例）：
- 申克乙为鬼，申中寄庚；日上酉中有建乙 → 合来日上克乙 → 主**媒人**相害；
- 将得六合：主土木匠；动金火：烧铁匠；火土相加：石匠；水火：离匠；淳水：巧匠；淳火：窑匠；淳土：石匠；淳金：铁匠——**以五行相加断匠人种类**。

#### 7. "天地医同入空亡，学论须看旺相神"

【直释】天医加地医落**空亡**，为鬼克日 → 人口舌；诸医见天地二医在空亡之位亦无用。

【推阐】医者之断：天地医不空、旺相 → 医者可倚；空亡 → 医不得力（或医者相害）。

#### 8. "天地得戌剋日，绝败空亡是贱贫"

**课例四解析**（庚寅日 丑将 寅时，校验通过 ✅）：

| 项目 | 内容 |
|:--:|:-----|
| 四课 | 未/庚、午/未、丑/寅、子/丑 |
| 取传 | 多下贼上（课3寅克丑、课4丑克子）→ **比用**：庚阳日取阳支，课4上子为阳 → 子亥戌 |
| 断语 | 三传子亥戌；庚惧戌中遁丙为鬼；鬼加亥为**绝**地 → 主**贫穷人相害**；初传临沐浴，上下建二阳干 → 男子姜生、女人贫贱 |

【直释】"庚惧戊中遁丙"——戌中藏戊，遁丙火克庚金（庚金畏丙火）；"为鬼，谓加亥绝"——鬼（丙）立于亥为绝地，鬼绝则其势弱，故主贫穷之人（非显贵）。

### 三、总结：断"门类诸人"之要诀

```
看害我之鬼（建干）立于何地、乘何将、带何煞
    ↓
寅长生+华盖 → 道人    甲死绝+天空+孤寡 → 僧尼
    ↓
辰乘吏贵 → 公吏      戊加四孟+劫亡 → 军卒
    ↓
申午相加+六合 → 牙媒   天地医 → 医者
    ↓
鬼绝败空亡 → 贱贫     将得六合 → 按五行断匠人
```

**口诀**：
> 寅立长生是道人，甲临死绝僧尼身；
> 天罡乘吏为公吏，戊加四孟是军人；
> 申午相加作牙媒，天地二医辨医神；
> 鬼绝空亡是贱贫，六合五行定匠人。
