# 释宗亲第三

## 莫执行年本命亲

> 四课三传中，若有一处是本命行年剋日，便作亲人相害，理未尽全，在支干相合，三六合有德，方敢言亲人相害。若无干支合，兼煞无德，虽有年命剋日，则主外亲，不在宗亲之数限也。

## 干合支合为亲类

> 论亲，要今日官鬼，在干合、支合、三六合，兼是有贵有德，只取亲人相害。有德处即不是亲。

## 仔细消详认假真

> 虽有建干，为今日之鬼所临之地，鬼在三六合方上起，主亲人相害。若鬼在上下所临之地，在六害相冲战，又坐四煞处，虽上下相生，亦不相亲。或戊立于丑，甲日虽畏戌中辛，行年本命是戊，合亲谓甲至丑见贵，辛至寅有贵是有德合，主因亲人有凶事，谓戊立于丑。
>
> 丑，丑是戊刑之地，又为辰戌丑未，谓四煞，虽有德，鬼贼刑害是不亲，故曰认假真矣。

## 凶神剋害日辰上

> 虽不见剋，今日干上下又无制剥，即吉，亦恐有剋日上之神类者，看是何宗亲有凶，取五行断言吉凶矣。

## 与日何类辨无因

> 假令丙日，三传年命不见水，即吉。在论日上建，若日上见丁火，三传俱旺阴火，必主妻灾，旺阳火，主父兄灾。日上建水，三传俱旺水，必主在妻之外亲相害。日上见金，三传俱旺金，主母凶。日上阳水，只取为鬼，阴水为兄弟。心镜

> 论今日干上事，若论课中有鬼，即便取鬼断之。不见建鬼，又无显明鬼，即取日上断之。

## 生我祸中途远外

> 支干无建干乃是我，十二将青龙白虎乃是他人，又是外亲。
>
> 即主远人。如三传，神不剋日剋将，亦主远人，将剋神为近人，日剋将亦主远人，日上将生鬼，即为远亲，兼远人相害，故曰生我，言我生他方是合远。又云：所有一鬼剋今日，复见众生于鬼，即远人相害。

## 我生虽忧在比邻

> 将生神，相害人在比邻。神生将，损我人在他乡。虽见剋我之鬼，却化为他处，即主相害人近处为化，而势不能长合近，若转生鬼，其势厚大长久，主鬼贼来远矣。鬼贼无气合，主官事近处起，鬼无势，主行事不远矣。甲日以庚为鬼，甲上有壬癸亥子，日上即是生我，庚至子化水，无气不生，是鬼不生，兼生日上，是以合鬼，起在比邻。经云：鬼生势行远，其贼来，鬼绝不起，其凶比邻。依此断之。

## 《释宗亲第三》详解

> 详解依据：竖版原文 + 课例程序化校验（两个课例均通过）。标注体系：【直释】= 经文原意；【推阐】= 基于经文的推导；【旁证】= 引用典籍佐证；【存疑】= 待考处，不强解。

### 一、篇旨：断"亲人相害"——莫执年命，先辨真假亲

承接第二篇"三传年命皆他人"，本篇进一步区分：年命克日，**未必是亲人相害**。

核心警戒：
- **"莫执行年本命亲"**——不可一见行年、本命克日就断亲人相害；
- 须**干支相合、三六合有德**，方敢言"亲人相害"；
- 若无干支合、兼煞无德，虽年命克日，只主**外亲**（外人），不在宗亲之数。

【旁证】此与《大六壬指南》"日辰相合为亲、六合三合为姻亲"的思路一致，但中黄经强调"有德"（贵神/德神介入）才算真亲。

### 二、逐节详解

#### 1. "莫执行年本命亲" / "建合干下地支分"

【直释】论亲要看"建合"：干支相合、三六合有德之处才是亲人相害之象。

【推阐】**"建合"是中黄经的核心理念**：
- 建 = 遁干（五子元遁）；
- 合 = 干合（甲己、乙庚、丙辛、丁壬、戊癸）+ 支合（六合、三合）；
- "建合干下地支分"：遁干所合之处，看其下临地支如何，以此定亲疏。

**课例一解读**（甲戌日 丑将 巳时）：
- 初传戌临寅，遁得**甲戌**，戌下得**丙寅**；
- 戌中藏**辛**，寅中藏**丙**，**丙辛相合**，将得**六合**；
- → 主亲人因和合中生起口舌；丙生辛（作"丙火生戌土、戌土生辛金"之间接相生理解），不能相害。

【存疑】"丙生辛绝不能相害"一句，按藏干关系：丙火生戌土、戌土生辛金，属间接相生，故不相害——此解供参考，原文或另有深意。

#### 2. "干合支合为亲类" / "仔细消详认假真"

【直释】论亲：今日官鬼在**干合、支合、三六合**处，兼有贵有德，才是亲人相害；**有德处即不是亲**（真亲有德则相护）。

【推阐】"认假真"的辨析要点：
- 鬼在三六合方上起 → 主亲人相害；
- 鬼在**六害、相冲战、四煞**处，虽上下相生亦**不相亲**——有刑害无合德，是假亲（外人）。

**课例解读**（"戊立于丑"例）：
- 甲日畏戌中辛（辛金克甲木）；若行年本命是**戊**；
- 甲至丑见**贵**（甲戊庚牛羊，甲日贵人在丑未——甲至丑见丑贵）、辛至寅有贵——是有德合；
- 但丑是戊之**刑地**（丑刑戌），又为辰戌丑未**四煞**；
- → 虽有德，鬼贼刑害则不亲，故曰"认假真"。

#### 3. "凶神剋害日辰上" / "与日何类辨无因"

【直释】虽不见克日，日干上下又无制剥即吉；但恐有克**日上之神**者，看是何种宗亲有凶，取五行断言。

【推阐】这是"六亲归类"的纲要——**以日上建干配六亲**（假令丙日为例）：

| 日上见 | 三传俱旺 | 所主宗亲 | 说明 |
|--------|---------|---------|------|
| 丁火（阴火） | 阴火旺 | 妻灾 | 丁为丙之阴干 |
| 丙火（阳火） | 阳火旺 | 父兄灾 | 阳火为比劫 |
| 水 | 水旺 | 妻之外亲相害 | 水为丙之官鬼 |
| 金 | 金旺 | 母凶 | 金为丙之财？此处"母"或以纳音论 |
| 阳水 | — | 取为鬼 | 水克火为鬼 |
| 阴水 | — | 为兄弟 | — |

【存疑】"日上见金，三传俱旺金，主母凶"——金为丙火之财（我克），断"母凶"与常规六亲（印为母）不合；或以纳音/变通取象，标注待考。

#### 4. "生我即须寻父母" ~ "干合多在妻妾生"

【直释】六亲取用总纲：
- **生我**（印）→ 父母；
- **克我**（官鬼）→ 子孙？（此处经文"剋我相伤见子孙"依常规当为官鬼，存疑）；
- **同类**（比劫）→ 兄弟；
- **干合**（合我之干）→ 妻妾。

【推阐】取断次序：课中有鬼即取鬼断之；**不见建鬼、又无显明鬼，即取日上断之**。

**假令甲日例**：
- 三传不见克甲；寅上有**己**（或建己）→ 三传木克己 → 在**妻**事吉凶（己为甲合，妻象）；
- 寅上见**庚**，三传旺火，寅中复见**丙** → 在**子孙**之吉凶（火克庚）；
- 寅上见**戊** → 在**父**之吉凶。

【存疑】"剋我相伤见子孙"一句与常规六亲（克我为官鬼）相反，疑为传抄之误或中黄经变通取象，标注待考。

#### 5. "生我祸中途远外" / "我生虽忧在比邻"

【直释】远近之辨：
- "将生神，相害人在比邻；神生将，损我人在他乡"——看生与被生定远近；
- 鬼有气有势 → 其势厚大长久，**鬼贼来远**；
- 鬼无气 → 官事近处起，**其凶比邻**。

**甲日庚鬼例**：甲上见壬癸亥子（生我），庚（鬼）至子化水，无气不生，兼生日上 → 合鬼起在**比邻**。

【旁证】经云："鬼生势行远，其贼来；鬼绝不起，其凶比邻。"——《毕法赋》"鬼临绝地则凶减"同此理。

### 三、课例解析

#### 课例一：甲戌日 十一月丑将 巳时（校验通过 ✅）

| 项目 | 内容 |
|:--:|:-----|
| 四课 | 戌/甲、午/戌、午/戌、寅/午 |
| 克 | 仅课1下贼上（甲木克戌土）→ **重审课** |
| 三传 | **甲戌、庚午、丙寅**（天将：六合、白虎、天后） |
| 建合 | 初传戌临寅：戌藏辛、寅藏丙，**丙辛合**，将得六合 → 亲人因和合生口舌 |

**经文断语解读**：
- "初传戌临寅得甲戌，戌下得丙寅"——初传戌加临地盘寅，遁得甲戌，地盘寅遁得丙寅；
- "丙与辛合，将得六合，事主亲人，因和合中生起口舌"——建合主亲人，六合主和合，和合中起口舌；
- "中传午临戌，得庚午是白虎，因亲人和合得病难痊，为白虎自战"——庚午白虎临戌，白虎主病伤，自战（上下相克）主病难痊；
- "天上甲在戌，戌居寅，病故不死"——日干甲加临戌，戌居寅（寅为甲之禄地），故虽病不死。

#### 课例二：丙寅日 十一月酉时（校验通过 ✅）

| 项目 | 内容 |
|:--:|:-----|
| 四课 | 酉/丙、丑/酉、午/寅、戌/午 |
| 克 | 仅课1下贼上（丙火克酉金）→ **重审课** |
| 三传 | **酉丑巳** |

**经文断语解读**：
- "三传中不见正鬼"——酉丑巳为金局（巳酉丑三合金），不直接克丙火（金不克火，火克金）；
- "合取己丑为凶"——丑中藏己（己土），或取丑为己之象为凶；
- "日上是金，又三传酉丑巳，从革金，主母有官事凶"——从革（金）之象，断母（或与纳音相关）有官事。

【存疑】课例二断"主母有官事凶"，以金局断母，同前"金主母凶"之例，皆与常规六亲（印为母）不合，疑为中黄经变通或纳音取象，标注待考。

### 四、总结：断宗亲之要诀

```
年命克日 ──→ 未必是亲
    ↓
看干支合/三六合/有德 ──→ 有合有德 = 亲人相害
    ↓
无合无德（刑害四煞）──→ 外亲、外人
    ↓
日上建干定六亲：生我父母 / 克我官鬼 / 同类兄弟 / 干合妻妾
    ↓
鬼有气有势 → 远亲远人；鬼无气 → 比邻近凶
```

**口诀**：
> 莫执行年本命亲，建合干支仔细分；
> 干合支合有德处，方是宗亲来相侵；
> 刑害四煞无合德，假亲外人莫当真。

### 五、存疑标注

【存疑】"丙生辛绝不能相害"——依藏干间接相生理解（丙火→戌土→辛金），供参考。

【存疑】"日上见金，三传俱旺金，主母凶"（及课例二"从革金主母官事"）——金为丙火之财，断"母凶"与常规"印为母"不合，疑为纳音变通取象，待考。

【存疑】"剋我相伤见子孙"——克我当为官鬼，经文作"子孙"，疑传抄之误或变通取象，待考。

【存疑】课例二"合取己丑为凶"句，原文简略，己丑取凶之具体机理未明，待考。
