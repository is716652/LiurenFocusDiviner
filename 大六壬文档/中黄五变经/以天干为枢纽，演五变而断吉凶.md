### ✅ 一、中黄五变的基本结构

| 五变名称         | 变化对象             | 是否以天干为核心  |
| ---------------- | -------------------- | ----------------- |
| **一干变** | 天干再遁（时支再遁） | ✅ 是             |
| **二支变** | 地支冲合刑害         | ❌ 否             |
| **三神变** | 天将（如青龙、白虎） | ✅ 以天干定神将   |
| **四气变** | 五行旺衰             | ✅ 以天干定五行   |
| **五命变** | 年命参断             | ✅ 以天干代入年命 |

👉 **除了“支变”以外，其余四变皆以天干为轴心。**

---

### ✅ 二、为何“以天干演课”？

#### 1. **“干为事主”**

> 经文开篇即言：
> **“释己身第一，日为己身最要明”**
> ——日干即占事之人，**一切吉凶以日干为中心**。

#### 2. **“变干”是五变之首**

> 传统六壬：日干固定，看支上神将
> 中黄五变：**日干可变**，以时支再遁出一干，称为**“变干”**，用于：

- 定十神（财官印食等）
- 断神将相乘吉凶
- 入三传、年命、行年
- 看是否克日、助日、生日

#### 3. **“干”定神将五行**

> 神将虽依地盘支起，但其**五行属性**与**天干相关**，如：

- 青龙属木 → 甲乙为旺
- 白虎属金 → 庚辛为旺
- 玄武属水 → 壬癸为旺

👉 所以**天干决定神将之气**，进而决定其克应。

### ✅ 三、案例回顾：丙寅日戌时课

| 项目 | 传统六壬   | 中黄五变                         |
| ---- | ---------- | -------------------------------- |
| 日干 | 丙（固定） | 丙（基准）                       |
| 变干 | 无         | 时支戌 → 戊（再遁）             |
| 财   | 庚辛       | 戊（变干）为财                   |
| 三传 | 申亥寅     | 看是否克变干/日干                |
| 断语 | 神将克日   | **变干戊为财，财还家，吉** |

👉 **整个断课过程，围绕“丙”与“戊”展开**，而非只看支上神将。
