旬遁是大六壬中给“三传”配天干的一种方法，其核心思路是：
先据日干支找出本日所在的“旬”（即六甲旬），再在这一旬的十个干支里，按“地支对应”的原则把天干搬到三传的地支上去。具体可分三步掌握：

### 一、把六十甲子按“旬”分段

六十甲子共 6 旬，每旬 10 组干支，开头必为“甲×”：

1. 甲子旬：甲子 乙丑 丙寅 丁卯 戊辰 己巳 庚午 辛未 壬申 癸酉
2. 甲戌旬：甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰 辛巳 壬午 癸未
3. 甲申旬：甲申 乙酉 丙戌 丁亥 戊子 己丑 庚寅 辛卯 壬辰 癸巳
4. 甲午旬：甲午 乙未 丙申 丁酉 戊戌 己亥 庚子 辛丑 壬寅 癸卯
5. 甲辰旬：甲辰 乙巳 丙午 丁未 戊申 己酉 庚戌 辛亥 壬子 癸丑
6. 甲寅旬：甲寅 乙卯 丙辰 丁巳 戊午 己未 庚申 辛酉 壬戌 癸亥

（每旬末尾总有两个地支轮空，称为“空亡”）

### 二、定日旬

看所占之日的干支落在哪一段，即知“本日属何旬”。例：

- 丁卯日 → 在甲子旬
- 己丑日 → 在甲申旬
- 壬戌日 → 在甲寅旬

### 三、给三传“搬”天干

三传既已排出三个地支（初、中、末），再在本日所在的旬里找“同地支”的那一组干支，把它的天干搬过来即可。口诀可记为：
“三传地支不出旬，同支天干即遁干。”

**例 1** 甲子日占，得三传 午→卯→子

- 日干支“甲子”属“甲子旬”；
- 旬中午支对应“庚午” → 天干庚；
- 卯支对应“丁卯” → 天干丁；
- 子支对应“甲子” → 天干甲。
  于是旬遁干为：初传庚，中传丁，末传甲。
  （此即《大六壬基础18》里“午遁庚、卯遁丁、子遁甲”之来历。）

**例 2** 壬寅日占，得三传 辰→酉→子

- 壬寅日落在“甲午旬”；
- 旬内辰支是“庚辰” → 庚；
- 酉支是“乙酉” → 乙；
- 子支是“戊子” → 戊。
  遁干即：初庚、中乙、末戊。

### 四、快速查验口诀（五子元遁，备用）

若一时找不到旬表，可用“五子元遁”临时推出该旬首之天干，再顺推：
“甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。”
——先把日辰的“子”时天干定出来，就能顺数出整旬，但旬遁仍以“查旬表→同支取干”最简捷。

### 五、排盘顺序回顾

1. 依月将加时排天地盘 → 2. 演四课 → 3. 按九宗门取三传 → 4. 据日干支定旬 → 5. 旬内同支取干，配于三传 → 6. 布贵人、十二天将 → 7. 遁干既成，再排六亲、神煞，即可占断。

掌握“先定日旬，再同支搬干”这一句话，大六壬的旬遁排天干即可随手而成。
