### 《中黄五变经》天干排法 - 算法

#### **核心思想**

遵循经典描述：
**“以日干及时干，再演一次五鼠遁来排天干”。**

这意味着，我们进行**两次独立的五鼠遁**，第一次基于日干，第二次基于时干。

#### **第一步：起日干遁天干盘（基础盘）**

此步骤与**传统六壬排地盘天干的方法完全一致**。

1. **输入**：日干。
2. **方法**：使用五鼠遁口诀。
   - 口诀：`甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸起壬子。`
3. **操作**：
   - 以日干确定“子宫”的起始天干。
   - 根据地支顺序，为十二个宫位依次排列天干。
4. **输出**：得到 **日干遁天干盘**。
   - **例如**：日干为 `戊`，则：
     - 子宫 = 壬，丑宫 = 癸，寅宫 = 甲，卯宫 = 乙，辰宫 = 丙，巳宫 = 丁，午宫 = 戊，未宫 = 己，申宫 = 庚，酉宫 = 辛，戌宫 = 壬，亥宫 = 癸。

#### **第二步：起时干遁天干盘（中黄盘）**

此步骤是《中黄五变经》的独特之处，是 **“再演一次五鼠遁”** 的真正体现。

1. **输入**：时干。
2. **方法**：**再次使用完全相同的五鼠遁口诀**。
3. **操作**：
   - 以时干确定“子宫”的起始天干。
   - 根据地支顺序，为十二个宫位依次排列天干。
4. **输出**：得到 **时干遁天干盘**。这个盘的结果，就是《中黄五变经》体系下，每个宫位最终用于判断的 **“中黄天干”**。
   - **例如**：时干为 `丁`，则：
     - 子宫 = 庚，丑宫 = 辛，寅宫 = 壬，卯宫 = 癸，辰宫 = 甲，巳宫 = 乙，午宫 = 丙，未宫 = 丁，申宫 = 戊，酉宫 = 己，戌宫 = 庚，亥宫 = 辛。

### **总结给AI的最终版逻辑**

1. **输入**：`日干`， `时干`， 固定的十二 `地支序列`。
2. **过程**：
   - **第一套天干（体/基础）**：执行 `五鼠遁(日干, 地支序列)`， 得到 `日干遁天干盘`。此盘可用于显示，代表“本体”能量。
   - **第二套天干（用/中黄）**：执行 `五鼠遁(时干, 地支序列)`， 得到 `时干遁天干盘`。**此盘即为最终断课的核心依据**，代表“动用”之后的最终能量形态。
3. **输出**：两套完整的天干盘。在天盘的中心设置开关：默认是传统的，打开开关即时干遁
   - **显示日遁天干（体）**：展示 `日干遁天干盘`。
   - **显示时遁天干（用）**：展示 `时干遁天干盘`。

### **结论**

请您在App中严格实现上述 **“日干遁”** 与 **“时干遁”** 两套独立的天干系统。这才是最贴合经典描述、逻辑最清晰、且与《金口诀》原理相通的正统方法。这样可以确保您的App基础牢固，不会因为采用了有争议的算法而“白做”。
