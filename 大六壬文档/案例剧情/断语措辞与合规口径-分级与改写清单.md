## 1. 合规的真实边界（先把"必须"与"自我加码"分开）

门禁 `_tests/_test_compliance_wording.js` 只管三类，**不管语气强弱**：

| 层 | 内容 | 性质 |
|:--|:--|:--|
| **C1 硬禁** | `八字 / 日柱 / 日主 / 命宫 / 十神 / 劫财 / 伤官 / 正官 / 大运` | 这些词在六壬里没有合法用法 |
| **C2 零容忍** | `算命 / 占卜 / 预测 / 灵验 / 开光 / 转运 / 消灾 / 改命 / 法事` | UI 文案零容忍（免责句除外） |
| **C3 出处纪律** | 自编整理表必须带来源 | 结论词要能溯源 |

**因此：`主雪`、`当有信至`、`三日内应`、`主官非` 这类断言，一个都不在禁列。**
`_test_compliance_wording.js` 里 `/不构成|仅供|参考|免责|…/` 那一行是 `EXEMPT_LINE` ——
它**豁免**免责句，**不是**要求每句都加。

### 1.1 实测：我们加了什么、漏改了什么（2026-09-21 扫描 41 案）

扫描脚本：`_tools/_scan_wording.py`（一次性；结果见下表）

| 模式 | 处数 | 判断 |
|:--|:--|:--|
| `非古籍原断` 类声明 | **41**（几乎每案一条） | ❌ **自我加码**：机械重复，读起来像在推责任 |
| `不作结论 / 不作断语` | **82** | ❌ 自我加码（异占支线的"只列取象"本可一次说清） |
| `不构成…建议` | **41** | ⚠️ 该留，但**只需一次**，不该逐案逐句 |
| `皆依类象与经文列出` | **41** | ❌ 套话 |
| `古籍云 / 古籍谓 / 古籍断法` 框架前缀 | **41** | ⚠️ 一句一次即可，不必每句 |
| `古法` | **293** | ✅ **这是行话，该留**（但过密则单调，宜隔句使用） |
| `宜… / 防…` 祈使 | **1** | ⚠️ 改得**太少** |
| `主官 / 主口舌 / 主雪…` 术数陈述 | **18** | ⚠️ **太少** —— 该变多的地方没变多 |

**结论**：问题不是"改狠了"，而是**改错了方向** —— 把断语换成了框架声明，却没写出断言。

## 2. 断语分级：按"落点在哪"分级，不按"词古不古"分级

> 关键：**"必死"的问题不在它古，而在它把一句术数判断，说成了对现实后果的承诺。**
> 所以改写目标是**把"现实承诺"退回"术数判断"**，而不是删词、换文风。文风可以更硬。

| 领域 | 可以怎么断 | 落点必须收在哪 | 例 |
|:--|:--|:--|:--|
| **生死** | 凶象可断，但不落到"人将死" | 术数内 | ✗ `占病必死` → ✓ `白虎临干，其象大凶` |
| **重大疾病** | **象上的症候可断**（用户 2026-09-21 明确同意） | 象内，不下医嘱 | ✓ `玄武临干，主暗疾`／`巳午受克，主目疾`；✗ `当速就医` → ✓ `天医临支，宜求医` |
| **官非诉讼** | 凶象可断 | 陈述，不指挥行动 | ✗ `宜低调避讼` → ✓ `官鬼临干，主官非` |
| **投资财帛** | 术数内可断 | 切断"回报承诺" | ✗ `求财宜主动，有赚` → ✓ `财爻临干，宜求财` |
| **失物 / 行人 / 姻缘 / 应候 / 考试** | **直接断**（这类不涉重大原则，从宽） | 术数内即可 | ✓ `当有信至`／`三日得雪`／`失物在西南`／`婚可成` |

**判断尺（一句话）**：**这句断语，会不会被读者当成对现实后果的承诺或行动指令？**
会 → 改述为术数内；不会 → **该断就断，不必客气。**

## 3. 三条写法原则

### 3.1 免责挂一次，不逐句挂

- 位置：**页面顶部一次** ＋ **揭底处一次**；
- 写法：一句落款，例如「以上按《六壬断案》原文整理；所断为术数内的象，不作现实判断。」
- **不写**「（仅供参考）」这类尾注 —— 每句都挂，等于每句都不算数。
- 古籍原文**照录不删字**（`占病必死` 留在原断里，它是史料，不是我们的结论）。

### 3.2 行家腔，不是学术腔

术数术语对用户不是"晦涩"，是**行话** —— 行话让人信服，学术腔才让人出戏。

| 学术腔（现状） | 行家腔（改写后） |
|:--|:--|
| 盘面：初传巳火，下临地盘子水（火被水克），上乘玄武。天时占取上下相激为将变之象… | **初传巳临子，火被水克，又乘玄武 —— 玄武本家是水，正是雪信。** |
| 古籍云：凶象偏重（仅供参考） | **凶象偏重。** |
| 前提：部分成立：太常在支课成立；"印绶／官职"分支不成立 | **只看一半：太常落在支课，对得上；"官职"那层对不上。** |

### 3.3 分层：断语在前，依据在后

- **正文**（用户先看的）：人话 ＋ 行话，可以斩钉截铁；
- **依据**（要查证的）：古籍出处、盘面锚点、前提是否成立 —— **折叠**（原型已用 `<details>` 落地）；
- 理由：合规要的是"**能查**"，不是"**每句都念一遍**"。

## 4. 词表：可写 / 慎写 / 不写

| 类别 | 词 |
|:--|:--|
| ✅ **可写（术数内断言）** | 主…、…之象、当有…、应期在…、临、乘、克、入墓、发用、落空、旬空、暗鬼、…凶象偏重 |
| ✅ **可写（行话，宜疏不宜密）** | 古法、九宗门、传本、原断、象、类神、气机 |
| ⚠️ **慎写（一句一次即可）** | 古籍云、按…法、仅供参考、研习参考 |
| ❌ **不写（自我加码）** | 非古籍原断（逐条挂）、不作结论（逐条挂）、皆依类象与经文列出 |
| ❌ **禁写（门禁 C1/C2）** | `八字/日柱/日主/命宫/十神/劫财/伤官/正官/大运`；`算命/占卜/预测/灵验/开光/转运/消灾/改命/法事` |
