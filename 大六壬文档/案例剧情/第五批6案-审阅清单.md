## 三、请重点看的六件事（体验维度，不是对错）

1. **情境立不立得住**：`brief` 是否让你一眼知道"谁、何时、问什么"。我只用案例既有要素（月将·日干支·占时·出处·原文情境），没有编人物与结果。
2. **"取象链"是否说得通**：本批 6 案的原占都是**由盘面事实一步步推向古断**，例如
   委差案「中传亥乘贵人却落旬空 → 三传未亥卯合成木局 → 占月在巳属夏令、木在夏令为休气」；
   升迁案「初传辰自日支子上神发起 → 中传午 → 末传申乘螣蛇而落旬空 → 日干丙火在亥月为囚」；
   赴任案（郭巡辖）「初传寅乘青龙而落旬空 → 日禄日德同在巳宫、巳为日支申之上神 → 末传申乘天后与日支同支」。
   这条链有没有让你觉得"原来古断是这么来的"，还是太跳？
3. **线索是不是"引导"而非"告知"**：每条 `label` 是问句，`small` 写**能照着点的一处位置**（如"点三传「中传」与四课第三课的「上神」"、"点下方事实栏「旬空」"）——
   这是 §10 那条"锚点必须可点可达"的直接落地。请重点验证：**有没有哪一条你按 small 点不到**。
4. **占类跨得够不够**：本批从「役事 / 赴任 / 疾病 / 风水 / 仕宦」五类入手，异占又换成「亡盗 / 仕宦 / 己身 / 前程」。
   坦白说本批占类**不如前四批铺得开**（原因见第二节末），若你觉得占类矩阵比"有应验的钩子"更重要，下一批我可以改为优先铺类。
5. **揭晓有没有落差**：本批**五案有可核的结局**（委差案"果于七月另委他人"、赴任案"果六年至任，八年丧归"、
   占病案"其人死者，传归死墓也"、家宅案"当年其人果死，其孙又亡"、郭巡辖案"次年八月始得到任"），
   只有升迁案原文只有断语与趋势语（"难以升迁""目下必有阻""堂上孺人定难久远"），按 §8 第 1 条约定的处置：ending 只揭古断，不编应验。
6. **生死类断语的边界**：本批**两案涉生死**——占病案原文"其人死者"、家宅案原文"有重丧…当年其人果死，其孙又亡"。
   两案的 `hint` 一律不写生死，只写可复算的支、乘将与神煞（末传所归之墓库、末传乘白虎、酉宫带死神），
   生死古断**只在原占 ending 揭原文时出现**；异占支线（己身）一律不写，且明标"不构成对现实身体状况的判断或建议"。
   占病案原文另有"咳嗽狂言""主肺主嗽"这类病位与医理文字，**hint 全部不写**，只留给原占 ending 揭原文。

本批复算课体分别为：涉害（黄氏占委差）、返吟（何知丞）、遥克·弹射（占病）、遥克·蒿矢（占家宅）、重审（马知丞）、比用（郭巡辖）——

**坑 2（新踩，最值得记）：「某支乘某将」这个句式，主语若写成"宫"，极易与"该宫位天盘支的乘将"混淆。**
我最初把 `{kind:"jiang", ref:"午/朱雀"}`（占病案）与 `{kind:"jiang", ref:"巳/青龙"}`（郭巡辖案）当成"午宫/巳宫的乘将"，
闸门立刻报 2 条 FAIL（锚点落不到复算盘面）。原因是**引擎把乘将挂在支上，而不是挂在宫上**：
`jiangAt(z) = jiangMap[gongOf(tp, z)]` —— 取的是"该**支**落在哪个宫、那个宫的地支上乘什么将"。
- 占病案：天地盘为 `午→未(朱雀)`，即天盘未乘朱雀，`jiangAt('未')='朱雀'`；`jiangAt('午')` 取的是卯宫的将＝**六合**，所以"午宫乘朱雀"是错的。
- 郭巡辖案：`巳→寅(青龙)`，即天盘寅乘青龙、`jiangAt('寅')='青龙'`；`jiangAt('巳')` 取的是亥宫的将＝**太常**。
- 修法：**乘将锚点一律以"天盘支/将"写**（`寅/青龙`、`未/朱雀`）；文案里凡指宫位，改写为"X宫之天盘为Y"，不当成该宫的乘将。
- 顺带发现两条同类表述已改：占病案"午宫之天盘乘朱雀"→删去（改用干支上神与旺衰），郭巡辖案"巳所乘之将为青龙"→"巳宫之天盘为寅"。

**坑 3（审计器「支带煞名」判据与文案基名的粒度冲突）**。
马知丞案异占 `ending.text` 原写"干上神未带旬癸"，审计器报 **FAIL**：
判据把 `未带旬癸` 里的煞名 token（**`旬癸`**）拿去核对本案该支的神煞表，而引擎给该宫的名称是带括号的全名 **`旬癸(闭口)`** → 判"未带旬癸"不成立。
注意：同一句法写在 `hint` 里（本批原占 hint 的"未宫带旬癸"）没有被这条判据拦下（该判据扫 `ending` / `ending.note`），
所以**同一件事在 hint 与 ending 里的容忍度不同**，容易一批过、一批不过。
- 修法：把 ending 里的句子改成 **"干上神所临之未宫带旬癸"**（煞名不再紧跟前一个支，避开 `<支>带<煞名>` 的连写），其余文案不动。
- 结论（并进第三批"煞名一律用『X 宫带 Y』句式"那条）：**只要写神煞，就写成"某宫带某煞"，不要让支与煞名紧挨着出现**；
  锚点仍写引擎全名（`旬癸(闭口)`），文案仍写基名（`旬癸`）——锚点与文案两套口径各自成立，别互相污染。
