## 三、请重点看的五件事（体验维度，不是对错）

1. **情境立不立得住**：`brief` 是否让你一眼知道"何将何时、何日、问什么、出自哪一门"。要素只取自该案 `input`（月将/日干支/占时/年干支）与 `source`/`chapter`（《中黄五变经》门次），没有编人物与结果。
2. **"取象链"是否说得通**：本批 5 案的原占都是**由三传与乘将一步步推向经文古断**，例如
   己身案「日上神为申而申乘螣蛇 → 中传亥落旬空 → 末传寅乘白虎而为丙火长生 → 巳宫带日德日禄」；
   亡盗案「柔日昴星取天盘酉下之神发用 → 三传亥寅巳三将（天后/朱雀/青龙）→ 玄武乘天盘酉落酉宫 → 末传巳乘青龙而落旬空」；
   远行案「三传子亥戌三将（白虎/太常/玄武）→ 中传亥乘太常、末传戌乘玄武 → 日干甲木在子月为相」。
   这条链有没有让你觉得"原来古断是这么来的"，还是太跳？
3. **线索是不是"引导"而非"告知"**：每条 `label` 是问句，`small` 写**能照着点的一处位置**（如"点三传「中传」与下方事实栏「旬空」「日干旺衰」"、"点盘上酉宫所在格的「乘将」行与「神煞」行"）。请重点验证：**有没有哪一条你按 small 点不到**。
4. **长案有没有被"缩写"得失去味道**：亡盗案原文 545 字（含贼之来路去路、住家方位、里数、院前林木院后水等），远行案 442 字（含行年、里数、隔表、来期）。
   我的处置是：**只取引擎能复算的那一段**（三传 / 乘将 / 旬空 / 日干旺衰 / 神煞），方位与里数的推算法一概不入支线；
   原文的方位与里数只留在原占揭晓时的 `tip` 里。你觉得这样"瘦身"是否可惜？若可惜，可另议"原文对读"面板。
5. **揭晓有没有落差**：本批**五案都没有可核的结局**（见第二节末）。因此钩子不在"应验"，而在
   **经文原文断语本身**（如亡盗案「贼住家院前有林木，后有水」、远行案「无财、无病、行二千六十里还家、无阻」），
   原占 `tip` 把这些原句照录并逐句对照盘面。若你觉得"没应验就不够抓人"，可议：是否给中黄案加一层"经文断法说明"而不动原文。
