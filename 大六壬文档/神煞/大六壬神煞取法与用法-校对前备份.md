## 一、总论:何谓神煞

大六壬之学,以"四课三传"为体,以"天将神煞"为用。体者,定吉凶之骨架;用者,见克应之形貌。古诀云:"**三传吉凶有狐疑,全凭煞到解心迷**",又云"**将无神不灵,神无煞不应**"。天将若无神煞附丽,则不显灵;神煞若不乘天将降临,则不应事。二者相须为用,缺一不可。

### 1.1 神煞的两层意义

- **神**:天盘十二神将(贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后),其位随天盘转,主性情、身份、形象。
- **煞**:依年、月、季、旬、干、支起算的固定符号,其位不随天盘变,主事类、克应、吉凶。

### 1.2 六大分类总览

| 分类 | 起算基准 | 性质 | 核心神煞举例 |
| :--- | :--- | :--- | :--- |
| **岁煞** | 当年太岁(年支) | 重大、迟缓、应于全年 | 太岁、岁破、病符、丧门、吊客 |
| **季煞** | 四季(春、夏、秋、冬) | 季节性,应于当季 | 天喜、孤辰、寡宿、天赦、皇书 |
| **月煞** | 月建(当月地支) | 月内事,较速 | 生气、死气、天马、天医、月厌 |
| **旬煞** | 六十甲子旬 | 旬内事,最速 | 旬奇、旬仪、旬丁、旬癸、旬空 |
| **干煞** | 占日天干 | 干系占主自身 | 日德、日禄、游都、鲁都、飞符 |
| **支煞** | 占日地支 | 干系宅、身外物 | 驿马、劫煞、亡神、华盖、桃花 |

> 取算顺序:占时先看年(岁煞),次看月(月煞、季煞),再看日(干煞、支煞),再看旬(旬煞)。层层叠用,方能精细。

### 1.3 神煞应用的三大原则

1. **神煞为克应之关键**:精研者皆重视神煞,因它能补充天将、六亲难以描述的精确事象(如用太岁表天子,日德表高人,游都表贼兵)。
2. **作用需有"引子"**:神煞并非孤立生效,需借助五行生克和神将组合才能发挥影响。"**凡看神煞,须干支神将刑克,其事乃发**"。若神煞与课传无关联,则如无源之水,难以应事。
3. **吉凶贵在权衡**:同一神煞,因位置、所乘天将、所占事项不同,吉凶可翻转。占病逢"生气"反主病情加重;占贼逢"鬼作生气",或主贼人将再来。神煞之妙,在乎灵活。

## 二、岁煞(以年支起算)

岁煞以当年地支(太岁)为基准,主全年之大事、朝廷之兆、迟缓之应。古以年为尊,故岁煞最重,关乎天子、年运、家国。

### 2.1 太岁

- **取法**:当年地支即是。如 2026 丙午年,太岁在午。
- **主事**:天子、元首、朝廷、国家、君父、一年之总运。
- **吉凶**:中性,本身不主吉凶,视其所乘天将、所在宫位而定。
- **喜忌**:
  - 太岁乘青龙、天乙:主天子恩赐、皇恩浩荡、贵人扶持。
  - 太岁乘白虎、玄武:主朝中有变、君臣不睦、贼兵犯境。
  - 太岁临日干、年命:主当年有大变动,非吉即凶。
  - 太岁空亡:主政令不行,事有虚象。
  - 太岁受刑冲:主太岁不安,主政动荡。
- **配将参考**:太岁加辰戌(天乙入狱),占讼主大凶;太岁加亥(登天门),占科甲高中。

### 2.2 岁破(大耗)

- **取法**:太岁所冲之支。如午年太岁,岁破在子(子午相冲)。
- **主事**:破财、破败、耗费、损失、大耗。
- **吉凶**:大凶。主耗散、破败、破产。
- **喜忌**:
  - 岁破临日干:主一年大破其财。
  - 岁破乘青龙(财神):财来财去,聚散无常。
  - 岁破乘太常(衣食):主田宅破败。
  - 岁破作空亡:凶力减半,名"空破",先破后无。
  - 占财最忌岁破临干支,主求财反耗。

### 2.3 病符

- **取法**:太岁后第五位。如午年,病符在未(未为午之后第五:申酉戌亥子,误,实为太岁后第五)。
  - 正法:病符 = 太岁 + 5 辰。午年,午→未→申→酉→戌→亥,病符在亥。
  - 又说:病符 = 太岁前一辰(误,实为后五)。各本有异,今以《六壬大全》后五辰为正。
- **主事**:旧病、陈年旧疾、宿疾复发、隐患。
- **吉凶**:中性偏凶,主"旧事重提"。
- **喜忌**:
  - 病符临支克支:主家中旧病复发。
  - 病符作生气:旧病将愈,反主康复。
  - 病符乘白虎:旧病沉重,恐有生命之忧。
  - 病符乘太常(病符克宅):主全家染病。
  - 占病遇病符,须看是否作死气、克日。

### 2.4 丧门

- **取法**:太岁前二辰。如午年,丧门在辰(午前二:巳→辰,误;实为午前二:巳、辰,故丧门在辰)。
  - 正法:丧门 = 太岁 - 2 辰。午年:午→巳→辰,丧门在辰。
- **主事**:死丧、孝服、哭泣、丧亡之事。
- **吉凶**:凶。主丧亡。
- **喜忌**:
  - 丧门临支:主家中有丧。
  - 丧门乘白虎:大凶,主有重丧。
  - 丧门作空亡:凶力减半,虚惊一场。
  - 丧门受冲(被对冲):主丧事可解。
  - 占病最忌丧门加临,恐有不测。

### 2.5 吊客(吊丧)

- **取法**:太岁后二辰。如午年,吊客在申(午后二:未→申)。
- **主事**:吊丧、探病、外出奔丧。
- **吉凶**:凶,主奔丧之事。
- **喜忌**:
  - 吊客临日干:主有远客来吊、或自己外出吊丧。
  - 吊客乘白虎:丧事更重。
  - 吊客加支:主有外丧来宅。
  - 丧门吊客全逢(同时出现):主有大丧。

### 2.6 太阴(岁阴)

- **取法**:太岁前八辰。如午年,午前八:巳辰卯寅丑子亥戌,故太阴在戌。
  - 又说:太阴 = 太岁前五辰。实为前五,前八之说异。
  - 正法以《六壬大全》:**太阴 = 太岁 - 5 辰**。午年:午→巳→辰→卯→寅→丑,太阴在丑。
- **主事**:皇后、母亲、女性长辈、阴私之事、财帛(因太阴主藏)。
- **吉凶**:中性偏吉,主阴柔之德。
- **喜忌**:
  - 太阴乘太岁临日干:主母后恩赐。
  - 太阴临支克支:主女性为祸。
  - 太阴作财爻:主暗中得财。
  - 太阴作日鬼:主阴私之事祸身。

### 2.7 招摇(岁煞)

- **取法**:太岁前一辰之对冲。如午年招摇在卯(午前一是巳,巳对冲是亥,误;实为太岁前一位 = 巳,招摇在巳之冲亥)。
  - 正法:**招摇 = 太岁前一辰**。即巳年招摇在辰,午年招摇在巳。
- **主事**:摇动、不安、惊恐、官司。
- **吉凶**:凶。
- **喜忌**:
  - 招摇临干:主身不安、多惊恐。
  - 招摇作天乙:主贵人动摇,不可依。
  - 占行人遇招摇:主行人被阻。

### 2.8 小结:岁煞速记

| 神煞 | 取法 | 主事 | 吉凶 | 占时最忌 |
| :--- | :--- | :--- | :--- | :--- |
| 太岁 | 当年地支 | 天子、朝廷 | 中 | 受冲 |
| 岁破 | 太岁对冲 | 破财、大耗 | 大凶 | 临日干 |
| 病符 | 太岁后五辰 | 旧病 | 偏凶 | 乘白虎 |
| 丧门 | 太岁前二辰 | 死丧 | 凶 | 临支 |
| 吊客 | 太岁后二辰 | 吊丧 | 凶 | 临日干 |
| 太阴 | 太岁前五辰 | 女性、阴私 | 中 | 作鬼 |
| 招摇 | 太岁前一辰 | 惊恐 | 凶 | 临干 |

## 三、季煞(以四季起算)

季煞以季节为基准,主当季之事,时效一季(三个月)。季节的判定以月令为据:寅卯辰为春,巳午未为夏,申酉戌为秋,亥子丑为冬。

### 3.1 天喜

- **取法**:春戌、夏丑、秋辰、冬未。
  - 春(寅卯辰月):天喜在戌
  - 夏(巳午未月):天喜在丑
  - 秋(申酉戌月):天喜在辰
  - 冬(亥子丑月):天喜在未
- **主事**:喜庆、恩泽、婚姻、生育、升迁、恩赐。
- **吉凶**:大吉。
- **喜忌**:
  - 天喜临日干、年命:主有喜事临身。
  - 天喜乘青龙:喜上加喜,主婚嫁、添丁。
  - 天喜临支:主家中喜事。
  - 天喜作空亡:喜事成空,名"喜空"。
  - 占婚、占孕、占升迁遇天喜最验。

### 3.2 孤辰

- **取法**:春巳、夏申、秋亥、冬寅。
  - 推导:四季之"孤"在四季孟月后的中位。
  - 春(寅卯辰):孤在巳(辰后一位)。
  - 夏(巳午未):孤在申(未后一位)。
  - 秋(申酉戌):孤在亥(戌后一位)。
  - 冬(亥子丑):孤在寅(丑后一位)。
- **主事**:孤独、单身、寡居、形单影只。
- **吉凶**:中性偏凶,主孤独。
- **喜忌**:
  - 孤辰临年命:主命犯孤星,婚姻迟来。
  - 孤辰作日鬼:主因孤独生疾。
  - 孤辰乘六合反吉:虽有孤独,有和合之象。

### 3.3 寡宿

- **取法**:春丑、夏辰、秋未、冬戌。
  - 春(寅卯辰):寡在丑(辰前五位)。
  - 夏(巳午未):寡在辰(未前五位)。
  - 秋(申酉戌):寡在未(戌前五位)。
  - 冬(亥子丑):寡在戌(丑前五位)。
- **主事**:与孤辰同,主寡居,惟更偏于女命。
- **吉凶**:中性偏凶。
- **喜忌**:
  - 寡宿临女命年命:主命犯寡宿,克夫。
  - 寡宿乘太阴、天后:妇人之灾更重。
  - 孤寡同临:大凶,主孤苦无依。

### 3.4 天赦

- **取法**:春戊寅、夏甲午、秋戊申、冬甲子。
  - 春占逢戊寅日(寅月或寅日得戊干):天赦。
  - 夏占逢甲午日:天赦。
  - 秋占逢戊申日:天赦。
  - 冬占逢甲子日:天赦。
- **主事**:赦罪、解厄、逢凶化吉、官非消散。
- **吉凶**:大吉。
- **喜忌**:
  - 天赦临干支或发用:主一切罪咎可消。
  - 占讼遇天赦:主有赦免、得解脱。
  - 占病遇天赦:主病有转机。
  - 天赦逢空:赦免不成,反凶。

### 3.5 皇书(天帝符)

- **取法**:春丑、夏辰、秋未、冬戌(与寡宿同位)。
- **主事**:科名、词讼、文书、考试。
- **吉凶**:中性偏吉,主文书、词讼相关。
- **喜忌**:
  - 皇书临日干、年命:占考必中。
  - 皇书乘朱雀:主词讼成、奏章达。
  - 皇书作日鬼:主因词讼惹祸。

### 3.6 浴盆

- **取法**:子午卯酉年取辰,寅申巳亥年取戌,辰戌丑未年取丑。
  - 简化:子午卯酉年:辰;寅申巳亥年:戌;辰戌丑未年:丑。
- **主事**:小儿产厄、生产之灾。
- **吉凶**:凶,主生产不顺。
- **喜忌**:
  - 浴盆临产期、产母年命:大凶,恐有产厄。
  - 浴盆受冲:凶力减。
  - 浴盆乘太常、青龙:虽有惊无险。

### 3.7 死神(季煞)

- **取法**:春酉、夏午、秋卯、冬子。
  - 春(寅卯辰):死神在酉(金死春)。
  - 夏(巳午未):死神在午(火死夏)。
  - 秋(申酉戌):死神在卯(木死秋)。
  - 冬(亥子丑):死神在子(水死冬)。
- **主事**:死丧、凶事。
- **吉凶**:凶。
- **喜忌**:
  - 死神临年命:主该季有死亡之危。
  - 死神作空亡:凶力减。
  - 死神乘白虎:大凶,主暴亡。

### 3.8 小结:季煞速记

| 神煞 | 取法 | 主事 | 吉凶 | 占时最忌 |
| :--- | :--- | :--- | :--- | :--- |
| 天喜 | 春戌夏丑秋辰冬未 | 喜庆、恩泽 | 大吉 | 空亡 |
| 孤辰 | 春巳夏申秋亥冬寅 | 孤独 | 偏凶 | 临年命 |
| 寡宿 | 春丑夏辰秋未冬戌 | 寡居 | 偏凶 | 临女命 |
| 天赦 | 春戊寅夏甲午秋戊申冬甲子 | 赦罪解厄 | 大吉 | 逢空 |
| 皇书 | 同寡宿 | 科名词讼 | 偏吉 | 乘鬼 |
| 浴盆 | 三组年分 | 产厄 | 凶 | 乘太常反吉 |
| 死神 | 春酉夏午秋卯冬子 | 死丧 | 凶 | 乘白虎 |

## 四、月煞(以月支起算)

月煞以月建(当月地支)为基准,主月内之事,时效一月(约三十日),较岁煞速、较日煞广。

### 4.1 月建

- **取法**:当月地支。如正月建寅,二月建卯,三月建辰,四月建巳,五月建午,六月建未,七月建申,八月建酉,九月建戌,十月建亥,十一月建子,十二月建丑。
- **主事**:月令、当月总纲、朝廷本月之政。
- **吉凶**:中性,为月内万事之纲。
- **喜忌**:
  - 月建临日干:本月大吉,主有进益。
  - 月建发用:本月事应。
  - 月建作空亡:本月事多虚。
  - 月建冲破:本月有变。

### 4.2 月破

- **取法**:月建所冲之支。如正月寅,月破在申。
- **主事**:破败、破财、损耗。
- **吉凶**:大凶,主本月破败。
- **喜忌**:
  - 月破临日干:本月大破。
  - 月破乘玄武:主失盗。
  - 月破作空亡:名"月破逢空",先破后空,反凶减轻。

### 4.3 生气

- **取法**:正月起子,顺行十二。即正月子在,二月丑在,三月寅在...十二月亥在。
  - 正月:子在;二月:丑在;三月:寅在;四月:卯在;五月:辰在;六月:巳在;七月:午在;八月:未在;九月:申在;十月:酉在;十一月:戌在;十二月:亥在。
- **主事**:解凶增吉、生命、活力、转机、贵人。
- **吉凶**:大吉。
- **喜忌**:
  - 生气临干支:本月有生气、贵人助。
  - 生气发用:主事可成,遇难能解。
  - 生气作日财:主财源滚滚。
  - 生气作日鬼:不吉反凶,主病重(占病)。
  - 生气空亡:吉力减。
  - 占孕、占病、占讼最重生气。

### 4.4 死气

- **取法**:正月起午,顺行十二。与生气相对。
  - 正月:午在;二月:未在;...十二月:巳在。
- **主事**:死丧、衰败、终结。
- **吉凶**:凶。
- **喜忌**:
  - 死气临干支:本月有死气、凶事。
  - 死气发用:主事将终,难成。
  - 死气作生气之对:凶中藏吉(死里逃生)。
  - 死气作日鬼:大凶,占病主亡。
  - 死气乘白虎:大凶。

### 4.5 天马

- **取法**:正月起午,顺行十二。与驿马不同,天马以月建起算。
  - 正月:午在;二月:未在;三月:申在;四月:酉在;五月:戌在;六月:亥在;七月:子在;八月:丑在;九月:寅在;十月:卯在;十一月:辰在;十二月:巳在。
- **主事**:迁动、出行、信息、书信。
- **吉凶**:中性,主动。
- **喜忌**:
  - 天马临干支:本月主迁动。
  - 天马发用:主事速。
  - 天马空亡:动而空。
  - 占行人最验。

### 4.6 天医

- **取法**:正月起戌,顺行十二。
  - 正月:戌在;二月:亥在;三月:子在;四月:丑在;五月:寅在;六月:卯在;七月:辰在;八月:巳在;九月:午在;十月:未在;十一月:申在;十二月:酉在。
- **主事**:医生、医药、治病之人。
- **吉凶**:中性偏吉。
- **喜忌**:
  - 天医临日干:有良医。
  - 天医作日财:医药耗财。
  - 占病遇天医:有救。
  - 天医乘太常(病符):病可治。

### 4.7 地医

- **取法**:与天医对冲。即天医在戌,地医在辰;天医在亥,地医在巳;以此类推。
- **主事**:与天医同,惟更偏于地下、阴治。
- **喜忌**:同天医。

### 4.8 月厌

- **取法**:正月起戌,逆行十二。
  - 正月:戌在;二月:酉在;三月:申在;四月:未在;五月:午在;六月:巳在;七月:辰在;八月:卯在;九月:寅在;十月:丑在;十一月:子在;十二月:亥在。
- **主事**:忌嫁娶、行兵、动土。
- **吉凶**:凶。
- **喜忌**:
  - 月厌临干支:本月忌婚嫁、出行。
  - 月厌作日鬼:大凶。
  - 月厌发用:事多阻。
  - 占婚最忌月厌。

### 4.9 成神

- **取法**:正月起巳,顺行十二。
  - 正月:巳在;二月:午在;三月:未在;四月:申在;五月:酉在;六月:戌在;七月:亥在;八月:子在;九月:丑在;十月:寅在;十一月:卯在;十二月:辰在。
- **主事**:所谋遂意、成就。
- **吉凶**:大吉。
- **喜忌**:
  - 成神发用:主谋事可成。
  - 成神临日干:本月所谋皆遂。
  - 成神空亡:成而不久。

### 4.10 血忌

- **取法**:正月起丑,顺行十二。
  - 正月:丑在;二月:寅在;三月:卯在;四月:辰在;五月:巳在;六月:午在;七月:未在;八月:申在;九月:酉在;十月:戌在;十一月:亥在;十二月:子在。
- **主事**:血光、产厄、针刺。
- **吉凶**:凶。
- **喜忌**:
  - 血忌临产期:忌生产、忌动刀。
  - 血忌发用:主有血光。
  - 血忌受冲:凶减。

### 4.11 阳贵、阴贵

- **取法**:即天乙贵人之分昼、夜。详见"十二天将"。
- **主事**:贵人(显贵、暗助)。
- **喜忌**:
  - 阳贵(昼贵)临干:贵人显助。
  - 阴贵(夜贵)临干:贵人暗助。
  - 阳贵作日鬼:白天官非。
  - 阴贵作日鬼:夜间、暗处官非。

## 五、旬煞(以六十甲子旬起算)

旬煞以占日所在的六十甲子一旬(十日)为基准,主旬内之事,时效最短(最速),应验最快。

### 5.1 旬奇(旬遁之奇)

- **取法**:占日地支为旬中第几位,遁取天干。
  - 旬中十位对应十天干:第一位甲、第二乙、第三丙、第四丁、第五戊、第六己、第七庚、第八辛、第九壬、第十癸。
  - 旬奇常指遁取之甲、丙、戊、庚、壬(阳干)或乙、丁、己、辛、癸(阴干)。
  - 大六壬中的"旬奇"特指:**旬中所遁之"奇"位**。通用取法:看占日地支在本旬中的位置,遁干"甲"则为旬奇。
- **主事**:逢凶化吉、贵人、扶助。
- **吉凶**:吉。
- **喜忌**:
  - 旬奇临干支:主有贵人暗中相助。
  - 旬奇发用:主事可解。
  - 旬奇空亡:吉力减。

### 5.2 旬仪(旬遁之仪)

- **取法**:与旬奇同法,惟取"戊"或"己"。"戊"为阳仪,"己"为阴仪。
- **主事**:仪仗、威严、礼仪、官府。
- **吉凶**:中性偏吉。
- **喜忌**:
  - 旬仪临日干:主有贵人显助。
  - 旬仪作日鬼:主因礼仪惹祸。
  - 旬仪乘朱雀(文):主文书成、奏章达。

### 5.3 旬丁(六丁神,丁马)

- **取法**:占日地支为旬中第几位,遁取之"丁"位。
  - 具体取法:
    - 甲子旬(甲子至癸酉):丁为卯位,即卯日得丁。
    - 甲戌旬(甲戌至癸未):丁为丑位,即丑日得丁。
    - 甲申旬(甲申至癸巳):丁为亥位,即亥日得丁。
    - 甲午旬(甲午至癸巳):丁为酉位,即酉日得丁。
    - 甲辰旬(甲辰至癸卯):丁为未位,即未日得丁。
    - 甲寅旬(甲寅至癸丑):丁为巳位,即巳日得丁。
- **主事**:主动、摇动、不安、信息、传信。
- **吉凶**:中性,主"动"。
- **喜忌**:
  - 旬丁发用:主事速,主动摇。
  - 旬丁乘天马:主动更速。
  - 旬丁临日干:主身动。
  - 金日(庚辛)逢旬丁:凶祸动。
  - 水日(壬癸)逢旬丁:财动。
  - 旬丁作空亡:动而不实。
  - 旬丁乘白虎:主血光、丧亡。

### 5.4 旬癸(闭口)

- **取法**:占日地支为旬中第十位癸。旬中最后一位,即癸日。
- **主事**:闭口、不言、机关、隐情、密谋。
- **吉凶**:中性,主"闭"。
- **喜忌**:
  - 旬癸发用:主事闭口难言,机谋莫测。
  - 旬癸临日干:主言不由衷、隐情。
  - 旬癸乘玄武:主阴谋、盗窃。
  - 旬癸作日财:主暗中得财。
  - 闭口格(详见毕法赋第三十八法):旬尾加旬首,或旬首乘玄武,主捕贼、闭口。

### 5.5 旬空(六甲旬空)

- **取法**:六甲旬中所空之二支。
  - 甲子旬(甲子至癸酉):空在戌亥。
  - 甲戌旬(甲戌至癸未):空在申酉。
  - 甲申旬(甲申至癸巳):空在午未。
  - 甲午旬(甲午至癸巳):空在辰巳。
  - 甲辰旬(甲辰至癸卯):空在寅卯。
  - 甲寅旬(甲寅至癸丑):空在子丑。
- **主事**:空亡、不实、落空。
- **吉凶**:中性,吉凶皆减。
- **喜忌**:
  - 旬空临日干:吉凶皆空,作事不成。
  - 旬空作日财:求财不得。
  - 旬空作日鬼:凶力减,鬼力空。
  - 旬空乘天空:更加空。
  - 旬空逢冲(冲实):名"冲空则实",空亡被冲则反实。
  - 旬空逢填(填实):逢月令填实则不空。
  - 大六壬特别重视旬空,见毕法赋第十七法"进茹空亡宜退步"、第十八法"踏脚空亡进用宜"。

### 5.6 伏吟(壬盘)

- **取法**:天盘与地盘同位,即四课三传皆同干支。如甲子日伏吟(干上午加午、子上子加子)。
- **主事**:伏藏、呻吟、忧虑、迟滞。
- **吉凶**:中性偏凶,主伏而不动。
- **喜忌**:
  - 伏吟占病:主呻吟之疾。
  - 伏吟占讼:主事久不决。
  - 伏吟逢丁马:主静中有动。
  - 刚日(阳日)为"自任",柔日(阴日)为"自信"。

### 5.7 反吟

- **取法**:天盘与地盘相冲,即四课三传皆为对冲。
- **主事**:反覆、变动、来往。
- **吉凶**:凶,主反复。
- **喜忌**:
  - 反吟占事:主反复不定。
  - 反吟占行人:主即返。
  - 反吟作空亡:反复成空。
  - 详见毕法赋相关各法。

### 5.8 旬煞速记总表

| 神煞 | 取法 | 主事 | 吉凶 | 简诀 |
| :--- | :--- | :--- | :--- | :--- |
| 旬奇 | 旬遁之甲 | 扶助 | 吉 | 逢凶化吉 |
| 旬仪 | 旬遁之戊/己 | 仪仗 | 偏吉 | 威严之应 |
| 旬丁 | 旬遁之丁 | 摇动 | 中 | 动之应 |
| 旬癸 | 旬中所遁之癸 | 闭口 | 中 | 不言之应 |
| 旬空 | 旬中所空二支 | 不实 | 中 | 落空 |
| 伏吟 | 天盘与地盘同位 | 伏藏 | 偏凶 | 静而不动 |
| 反吟 | 天盘与地盘相冲 | 反覆 | 凶 | 反复不定 |

## 六、干煞(以日干起算)

干煞以占日天干为基准,主占主自身之事,与"我"直接相关。

### 6.1 日德

- **取法**:
  - 甲己:德在寅
  - 乙庚:德在申
  - 丙辛:德在戌
  - 壬癸:德在巳
  - 丁:德在亥(戊:德在巳)
  - 简化:甲己寅德,乙庚申德,丙辛戌德,壬癸巳德,丁壬亥德(误,实为丁在亥,戊在巳)
  - 正诀:**甲己寅,乙庚申,丙辛戌,丁壬亥,戊癸巳**。即阳干取与合干之长生位,阴干取与合干之墓库位。
- **主事**:福佑、转凶为吉、贵人、德行。
- **吉凶**:大吉。
- **喜忌**:
  - 日德临日干:主有德人助。
  - 日德发用:主事可成,凶事转吉。
  - 日德空亡:吉力减。
  - 日德作日鬼:不吉,德反为鬼。
  - 占科甲遇日德加亥(天门):必高中,名"德入天门格"(见毕法赋第三法)。

### 6.2 日禄

- **取法**:日干所临禄位。
  - 甲禄在寅,乙禄在卯,丙禄在巳,丁禄在午,戊禄在巳,己禄在午,庚禄在申,辛禄在酉,壬禄在亥,癸禄在子。
- **主事**:俸禄、财源、食禄、官禄。
- **吉凶**:中性偏吉。
- **喜忌**:
  - 日禄临日干:主有禄可食,占前程必得。
  - 日禄临支:主权摄不正,主受宅禄。
  - 日禄作空亡:名"空禄",俸禄难求。
  - 日禄作日鬼(被克):名"禄被元夺",主先成后败。
  - 日禄乘白虎:名"衔禄自杀",主因禄致祸。
  - 旺禄临身徒妄作(见毕法赋第七法):禄旺而日干亦旺,不可妄作。

### 6.3 游都(贼盗)

- **取法**:
  - 甲己:游都在丑
  - 乙庚:游都在子
  - 丙辛:游都在寅
  - 丁壬:游都在巳
  - 戊癸:游都在申
- **主事**:盗贼、敌兵、贼巢。
- **吉凶**:凶。
- **喜忌**:
  - 游都临日干、年命:主贼来。
  - 游都发用:主盗贼之事。
  - 游都乘玄武:贼必现。
  - 游都受冲(被对冲):贼去。
  - 游都作空亡:贼不来。
  - 游都加支:贼入境内。
  - 占贼:必看游都所在,以定贼方。

### 6.4 鲁都(贼来路)

- **取法**:与游都相反。游都在丑,鲁都在未(对冲);游都在子,鲁都在午(对冲);以此类推。
- **主事**:贼之来路、方向。
- **喜忌**:
  - 鲁都发用:主贼从鲁都方来。
  - 鲁都乘玄武:贼之来路显。
  - 游都、鲁都并用,可定贼之方向、远近。

### 6.5 飞符(干煞)

- **取法**:日干所起。
  - 甲己:飞符在卯
  - 乙庚:飞符在寅
  - 丙辛:飞符在酉
  - 丁壬:飞符在午
  - 戊癸:飞符在巳
- **主事**:惊恐、官非、远行失路。
- **吉凶**:凶。
- **喜忌**:
  - 飞符临干:主远行失路。
  - 飞符发用:百事勿举。
  - 飞符乘白虎:大凶。

### 6.6 飞魂

- **取法**:日干所起,常以"游魂"取。
  - 甲己:游魂在寅
  - 乙庚:游魂在卯
  - 丙辛:游魂在巳
  - 丁壬:游魂在午
  - 戊癸:游魂在申
- **主事**:魂不守舍、夜梦、惊悸。
- **喜忌**:主夜梦不安,与占梦、占病相关。

### 6.7 血支(干煞)

- **取法**:日干起。
  - 甲乙:血支在丑
  - 丙丁:血支在寅
  - 戊己:血支在卯
  - 庚辛:血支在辰
  - 壬癸:血支在巳
- **主事**:血光、产厄、针刺。
- **喜忌**:同血忌。

### 6.8 干煞速记总表

| 神煞 | 取法 | 主事 | 吉凶 | 简诀 |
| :--- | :--- | :--- | :--- | :--- |
| 日德 | 阳干取合干长生,阴干取合干墓库 | 福佑 | 大吉 | 转凶为吉 |
| 日禄 | 日干禄位 | 俸禄 | 偏吉 | 食禄 |
| 游都 | 甲己丑,乙庚子,丙辛寅,丁壬巳,戊癸申 | 盗贼 | 凶 | 贼巢 |
| 鲁都 | 游都对冲 | 贼来路 | 中 | 贼向 |
| 飞符 | 干起 | 惊恐 | 凶 | 远行失路 |
| 飞魂 | 干起 | 夜梦 | 中 | 神不守 |
| 血支 | 干起 | 血光 | 凶 | 忌针刺 |

## 七、支煞(以日支起算)

支煞以占日地支为基准,主宅、身外物、外事,与自己相对应。

### 7.1 驿马

- **取法**(三合局对冲):
  - 申子辰日:马在寅(寅申冲)
  - 亥卯未日:马在巳(巳亥冲)
  - 寅午戌日:马在申(申寅冲)
  - 巳酉丑日:马在亥(亥巳冲)
  - 口诀:"**申子辰马在寅,寅午戌马在申,亥卯未马在巳,巳酉丑马在亥**"。
- **主事**:迁动、出行、远行、信息。
- **吉凶**:中性,主动。
- **喜忌**:
  - 驿马临日干、年命:主身动、出行。
  - 驿马发用:事速,主迁动。
  - 驿马乘青龙:迁官、迁宅,吉。
  - 驿马乘白虎:远行有险。
  - 驿马作空亡:动而空,名"空马"。
  - 驿马受冲:动之更速。
  - 驿马作日财:主求财远方得。
  - 驿马作日鬼:主因动致祸。
  - 驿马、天马(支煞与月煞)并用,可定动之远近。
  - 占行人最验:驿马临干,行人已动;驿马临支,行人在途。
  - 真富贵格(毕法赋第四十一法):干上有支驿马,支上有干禄神,大贵之象。

### 7.2 劫煞

- **取法**(三合局后一位):
  - 申子辰日:劫在巳(申子辰后一位)
  - 亥卯未日:劫在申
  - 寅午戌日:劫在亥
  - 巳酉丑日:劫在寅
  - 口诀:"**申子辰劫巳,亥卯未劫申,寅午戌劫亥,巳酉丑劫寅**"。
- **主事**:劫盗、伤杀、损失。
- **吉凶**:凶。
- **喜忌**:
  - 劫煞临日干:主有劫盗之危。
  - 劫煞发用:主事多劫。
  - 劫煞乘玄武:失盗必应。
  - 劫煞作空亡:凶减。

### 7.3 亡神

- **取法**(三合局前一位):
  - 申子辰日:亡在亥
  - 亥卯未日:亡在巳
  - 寅午戌日:亡在巳(实为巳,异说)
  - 巳酉丑日:亡在申
  - 口诀:"**申子辰亡亥,亥卯未亡巳,寅午戌亡巳,巳酉丑亡申**"。
- **主事**:亡失、损失、消散。
- **吉凶**:凶。
- **喜忌**:
  - 亡神临日干:主有亡失。
  - 亡神发用:主事将散。
  - 亡神乘玄武:失物难寻。
  - 亡神受冲:亡而不久。

### 7.4 华盖

- **取法**(三合局墓库):
  - 申子辰日:华盖在辰
  - 亥卯未日:华盖在未
  - 寅午戌日:华盖在戌
  - 巳酉丑日:华盖在丑
  - 口诀:"**申子辰盖辰,亥卯未盖未,寅午戌盖戌,巳酉丑盖丑**"。
- **主事**:华盖、覆盖、隐遁、艺术、孤高。
- **吉凶**:中性。
- **喜忌**:
  - 华盖临日干:主人孤高、有艺术气质。
  - 华盖覆日(华盖加临日干之上,详见毕法赋第五十九法):主昏晦、坐难明白。
  - 华盖乘六合(六合为华盖之神):主艺术、隐居。
  - 华盖空亡:主无依。
  - 占官、占学遇华盖:主有名而不显。

### 7.5 桃花(咸池)

- **取法**(三合局对冲之下一位):
  - 申子辰日:桃花在酉
  - 亥卯未日:桃花在子
  - 寅午戌日:桃花在卯
  - 巳酉丑日:桃花在午
  - 口诀:"**申子辰桃酉,亥卯未桃子,寅午戌桃卯,巳酉丑桃午**"。
- **主事**:桃花、淫乱、口舌、感情。
- **吉凶**:中性偏凶。
- **喜忌**:
  - 桃花临日干、年命:主有桃花。
  - 桃花发用:主事涉男女。
  - 桃花乘六合、天后:主私情。
  - 桃花乘白虎、玄武:主因色致祸。
  - 桃花作日财:主因妻致祸或因色破财。
  - 桃花空亡:桃花无力。
  - 桃花受冲:桃花发动。
  - 占婚、占色最验。

### 7.6 破碎(红煞、跌打煞)

- **取法**:
  - 子午卯酉日:破碎在辰
  - 寅申巳亥日:破碎在未
  - 辰戌丑未日:破碎在丑
  - 口诀:"**子午卯酉破辰,辰戌丑未破丑,寅申巳亥破未**"。

  - 破碎作空亡:凶减。
  - 破碎作日财:财破。
  - 破碎受冲:凶减。

### 7.7 孤虚

## 八、十二天将(天盘神煞)

天盘十二神将,又称十二天乙、十二月将之副。其位随天盘转,主性情、身份、形象,与神煞分司其职。

### 8.1 天乙(贵人)

- **取法**:起贵人诀,详见大六壬基础。此处略。
- **主事**:贵人、显贵、君子、贵气。
- **吉凶**:大吉。
- **喜忌**:
  - 贵人临干:主有贵人助。
  - 贵人乘青龙:喜事、恩赐。
  - 贵人作日鬼:鬼作贵人(辛日午加干之类,见毕法赋第四十八法),反为吉,名"鬼乘天乙乃神祗"。
  - 贵人入狱(加辰戌):贵人受制,作事难成。
  - 贵人空亡:贵人无力。
  - 贵人受克:贵人难求(见毕法赋第四十九法"两贵受克难干贵")。
  - 帘幕贵人(昼占得夜贵,夜占得昼贵):暗中相助,占考必中(见毕法赋第三法)。

### 8.2 螣蛇(蛇)

- **取法**:贵人后一位起。
- **主事**:惊恐、怪异、虚惊、变幻。
- **吉凶**:凶。
- **喜忌**:
  - 蛇临干:主惊恐不安。
  - 蛇作日鬼:怪异之祸。
  - 蛇乘旺相:惊恐不大。
  - 蛇空亡:惊恐一场。
  - 蛇火鬼同临:大凶(两蛇夹墓,见毕法赋第五十三法)。

### 8.3 朱雀

- **取法**:贵人次后一位起。
- **主事**:文书、口舌、词讼、考试、火灾。
- **吉凶**:中性偏凶。
- **喜忌**:
  - 朱雀临干:主有文书、口舌。
  - 朱雀乘午(真朱雀,见毕法赋第三法):占考必中。
  - 朱雀作日鬼:主火灾、口舌。
  - 朱雀乘青龙:文合上意。
  - 朱雀克帘幕:文不合主试意。
  - 朱雀乘丁马:文动(高中或走失)。

### 8.4 六合

- **取法**:贵人后第三位起。
- **主事**:和合、婚姻、合作、中介。
- **吉凶**:中性偏吉。
- **喜忌**:
  - 六合临干:主有和合。
  - 六合作日财:主因和合得财。
  - 六合乘天后(后合占婚,见毕法赋第四十法):主私情、占婚不需媒。
  - 六合作日鬼:主因合致祸。
  - 六合空亡:和合不成。

### 8.5 勾陈

- **取法**:贵人后第四位起。
- **主事**:迟滞、拘捕、田宅、官府、争斗。
- **吉凶**:中性偏凶。
- **喜忌**:
  - 勾陈临干:主迟滞。
  - 勾陈作日鬼:主官非、捕。
  - 勾陈乘月建:田宅事。
  - 勾陈受冲:迟滞可解。
  - 勾陈发用:事多阻。

### 8.6 青龙

- **取法**:贵人后第五位起。
- **主事**:喜庆、财帛、婚嫁、文章、东方。
- **吉凶**:大吉。
- **喜忌**:
  - 青龙临干:主喜庆、财喜。
  - 青龙乘日财:大发财。
  - 青龙空亡:喜事成空。
  - 青龙作日鬼:不吉(财化作鬼)。
  - 青龙乘丁马:喜动。
  - 龙加生气(见毕法赋第九十二法):吉迟迟(迟来而终吉)。

### 8.7 天空

- **取法**:贵人后第六位起。
- **主事**:虚假、欺诈、不实、欺骗、欺诈文书。
- **吉凶**:凶。
- **喜忌**:
  - 天空临干:主事虚。
  - 天空乘日鬼:虚惊。
  - 天空作日财:财虚。
  - 天空乘玄武:大盗、欺诈。
  - 课传俱贵(遍地贵人,见毕法赋第四十四法):反为大凶,因贵多不贵。

### 8.8 白虎

- **取法**:贵人后第七位起。
- **主事**:凶险、死亡、孝服、血光、刚烈。
- **吉凶**:大凶。
- **喜忌**:
  - 白虎临干:主有凶险。

  - 白虎乘旺:凶更甚。

  - 虎视逢虎(见毕法赋第五十四法):力难施。
  - 催官使者(白虎乘日鬼加干,见毕法赋第四法):赴任极速。

### 8.9 太常

- **主事**:衣食、财帛、印绶、酒食、平常。
- **吉凶**:中性偏吉。
- **喜忌**:
  - 太常临干:主有衣食之福。
  - 太常乘日财:酒食丰盛。
  - 太常空亡:衣食不足。
  - 太常作日鬼:主因饮食致祸。
  - 太常乘病符:病可治。

### 8.10 玄武

- **取法**:贵人后第九位起。
- **主事**:盗贼、欺诈、阴私、暗昧、北方。

### 9.2 神煞与课体的配合

神煞须入课传(初、中、末)方有力;在干支上者次之;在年命上者亦验。

| 课体 | 主要神煞 | 应事 |
| :--- | :--- | :--- |
| 伏吟 | 驿马、旬丁 | 静中有动 |
| 反吟 | 驿马、旬丁 | 反复不定 |
| 三光课 | 三光(贵、日、旺) | 大吉 |
| 三阳课 | 三阳(天乙、太阳、旺相) | 大吉 |
| 三阴课 | 三阴(玄武、白虎、天空) | 大凶 |
| 重阴课 | 重阴 | 阴私 |
| 六合课 | 六合 | 和合 |
| 伏反合 | 伏吟 + 六合 | 静中有合 |
| 别责课 | 旬奇 | 扶助 |

### 9.3 喜忌权衡七例

1. **占病逢生气反凶**:生气本吉,然占病时若生气作日鬼,主病虽生机尚存,然鬼力正盛,病重难愈。
2. **占贼逢鬼作生气**:鬼作生气,主贼人将再来(生气主生,即再来之意)。
3. **占婚逢桃花作日鬼**:主因色致祸,婚不成。
4. **占财逢驿马空亡**:主远方求财不得。
5. **占讼逢天赦空亡**:主赦免不成,仍受罪。
6. **占孕逢浴盆临产期**:大凶,产厄。
7. **占官逢日德作日鬼**:本吉,然作鬼则德力难施,官难求。

### 9.4 断课顺序(口诀)

1. 先看年命(岁煞为主)。
2. 次看月令(月煞、季煞为辅)。
3. 复看日干支(干煞、支煞为用)。
4. 再看旬中(旬煞为期)。
5. 再看天盘(十二天将性情)。
6. 再看四课三传(格局、吉凶)。
7. 综合权衡,方下断语。

古诀云:"**年命为体,月令为用,日辰为主,旬中为期,天将为神,三传为事**。"此六者,贯通为一,方为完整的六壬断课。

### 9.5 排盘速查建议

排盘时建议按以下顺序标注神煞:

1. 在天盘各宫位上标"月将"(如太阳)。
2. 在四课三传上标"旬煞"(旬奇、旬丁、旬空)。
3. 在干支上标"干煞"和"支煞"(日德、日禄、驿马、劫煞等)。
4. 在年命上标"年支神煞"(太岁、岁破、病符等)。
5. 在月令上标"月煞"(生气、死气、天马等)。
6. 在季节上标"季煞"(天喜、孤辰、寡宿等)。
7. 在十二天将上标性情。

如此标注后,神煞一目了然,断课时方可一览而明。

## 后记

神煞之用,贵在灵活。所谓"**法有定而神无定**",排盘所得皆为"定",而所应之事则为"神"。同一驿马,占出行则吉,占讼则凶;同一白虎,占病则危,占出兵则利(威猛之师)。学者当于"定"中求"变",于"理"中求"神",方能登堂入室,神而明之。

> 若需更深入的研究,可参《神煞赋》《神煞图》《大六壬探源·神煞卷》《六壬大全·神煞门》等;若需将神煞做成可枚举的规则集(每条带判定条件 + 例课),可直接拆为 JSON / 数据库表,适于排盘系统调用。
