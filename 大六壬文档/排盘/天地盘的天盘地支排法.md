



## 大六壬天盘地支排法 - 文字说明

### **核心原理**

天盘的排布遵循 **“月将加占时”** 的原则。其本质是将象征太阳的 **“月将”** 与象征当时的 **“占时”** 对齐，从而模拟出特定时刻太阳在黄道十二宫（即十二次）上的投影，并将其映射到固定的地盘之上，形成一个动态的“天盘”。

### **排法步骤**

#### **第一步：确认基础要素**

1.  **确定月将**：
    - 月将是太阳在黄道上所处宫位的名称。通常根据 **节气** 来确定。
    - 具体规则是：太阳过宫换将。例如：雨水后月将为亥（娵訾），春分后月将为戌（降娄）等。需要查阅 **“月将过宫表”** 来精确确定当前时间的月将。

2.  **确定占时**：
    - 占时是用户问事的具体时辰（地支表示），如子时、午时等。

3.  **准备好地盘**：
    - 地盘是固定不变的十二地支盘，顺序从子到亥，顺时针排列。

#### **第二步：进行“月将加占时”的叠加**

1.  **定位**：
    - 将确定的 **月将（地支）**，放置到 **地盘** 上对应 **占时（地支）** 的宫位之上。
    - **口诀**：**月将加占时，顺布十二支**。

2.  **排布**：
    - 以这个叠加点为起点，将月将所属的这支“天军”的十二位“神将”（即十二地支），按照 **顺时针** 的顺序，依次填入地盘的十二个宫位之中。
    - 这样，每个地盘宫位的上方，就都对应了一个天盘地支。

### **举例说明**

假设：
- **占时**：午时
- **月将**：亥（登明）
- **地盘**：固定为 `[子, 丑, 寅, 卯, 辰, 巳, 午, 未, 申, 酉, 戌, 亥]`

**排盘过程**：

1.  **定位**：将月将 `亥`，加到地盘的 `午` 宫之上。
2.  **顺排**：从地盘的午宫开始，顺时针填入十二地支：
    - 地盘 **午** 宫 → 天盘 **亥**
    - 地盘 **未** 宫 → 天盘 **子**（亥之后是子）
    - 地盘 **申** 宫 → 天盘 **丑**
    - 地盘 **酉** 宫 → 天盘 **寅**
    - 地盘 **戌** 宫 → 天盘 **卯**
    - 地盘 **亥** 宫 → 天盘 **辰**
    - 地盘 **子** 宫 → 天盘 **巳**
    - 地盘 **丑** 宫 → 天盘 **午**
    - 地盘 **寅** 宫 → 天盘 **未**
    - 地盘 **卯** 宫 → 天盘 **申**
    - 地盘 **辰** 宫 → 天盘 **酉**
    - 地盘 **巳** 宫 → 天盘 **戌**

**结果**：这样就得到了一个完整的天盘地支系统。

### **总结**

天盘地支的排法是一个 **机械但严谨** 的过程：
- **输入**：月将（地支）、占时（地支）、固定的地盘序列。
- **操作**：找到占时在地盘上的位置，将月将放在此处，然后顺时针排完十二地支。
- **输出**：一个与地盘一一对应的天盘地支序列。

这个由“月将加时”动态生成的天盘，是六壬课式发用的根本基础，四课、三传皆由此而生。
