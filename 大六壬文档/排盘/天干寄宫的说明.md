# 天干寄宫说明

> **文档定位**：大六壬排盘软件理论基础文档之一。与《天地盘的天盘地支排法》《大六壬指南的四课三传的四课排法》《大六壬指南的四课三传的三传排法》《天盘-三传-四课的天干-五子元遁法》共同构成完整排盘算法链。
> 本文档定义**天干如何定位到地盘宫位**（即"寄宫"），是四课排法与三传排法的**输入层**。

---

## 一、什么是天干寄宫

### 1.1 要解决的问题

六壬的地盘只有十二地支（子丑寅卯辰巳午未申酉戌亥），**天干并不直接落在地盘上**。然而排四课第一课要求先确定"日干所在宫位"，日干（例如"辛"）必须先找到一个落脚点，这个落脚点就是**寄宫**。

### 1.2 定义

**天干寄宫**：每个天干寄居于地盘某一个地支宫位的固定规则。寄宫之后，该天干在排盘中就"位于"这个地支宫位，该宫位上方的天盘神即为**干上神**。

### 1.3 在排盘中的作用

1. **四课第一课（干上神）**：日干 → 寄宫 → 地盘宫位 → 该宫上方天盘神；
2. **三传特殊宗门**：昴星、别责、八专、伏吟等法中"日干上神 / 日支上神"的定位依据；
3. **全课逻辑起点**：六壬以日干为尊，寄宫是日干参与排盘的第一步。

## 二、核心规则

### 2.1 规则总纲

- **阳干寄禄**：甲、丙、戊、庚、壬 → 寄于本干**禄位（临官位）**；
- **阴干寄冠带**：乙、丁、己、辛、癸 → 寄于本干**冠带位**（逆行十二长生第三位）；
- **记忆口诀**：`甲寅乙辰丙戊巳，丁己未宫庚申是，辛戌壬亥癸丑真`。

### 2.2 完整寄宫表

| 天干 | 五行 | 寄宫 | 宫位五行 | 规则依据 | 备注 |
|------|------|------|---------|---------|------|
| 甲 | 木 | 寅 | 木 | 甲禄在寅（临官） | 干支同气 |
| 乙 | 木 | 辰 | 土 | 乙冠带在辰 | 借宫寄居 |
| 丙 | 火 | 巳 | 火 | 丙禄在巳（临官） | 干支同气 |
| 丁 | 火 | 未 | 土 | 丁冠带在未 | 借宫寄居 |
| 戊 | 土 | 巳 | 火 | 戊禄在巳，同丙 | 借宫寄居 |
| 己 | 土 | 未 | 土 | 己冠带在未，同丁 | 干支同气 |
| 庚 | 金 | 申 | 金 | 庚禄在申（临官） | 干支同气 |

## 三、理论依据详解

### 3.1 为什么阳干寄禄（临官）

五行寄生十二宫，**阳干顺行**：长生 → 沐浴 → 冠带 → 临官（禄） → 帝旺 → 衰 → 病 → 死 → 墓 → 绝 → 胎 → 养。"禄"即"临官"，是干气正盛之位：

| 阳干 | 长生 | … | 临官（禄） | 寄宫 |
|------|------|---|-----------|------|
| 甲木 | 亥 | … | 寅 | 寅 ✅ |
| 丙火 | 寅 | … | 巳 | 巳 ✅ |
| 戊土 | 寅 | … | 巳 | 巳 ✅ |
| 庚金 | 巳 | … | 申 | 申 ✅ |
| 壬水 | 申 | … | 亥 | 亥 ✅ |

阳干之气**主动而进**，气旺于外，故寄于禄地。

### 3.2 为什么阴干寄冠带

阴干**逆行**十二长生。冠带为逆行第三位（长生 → 沐浴 → 冠带），如人"冠带成人"，是阴干由生转旺之位：

| 阴干 | 长生 | 沐浴 | 冠带 | 寄宫 |
|------|------|------|------|------|
| 乙木 | 午 | 巳 | 辰 | 辰 ✅ |
| 丁火 | 酉 | 申 | 未 | 未 ✅ |
| 己土 | 酉 | 申 | 未 | 未 ✅ |
| 辛金 | 子 | 亥 | 戌 | 戌 ✅ |
| 癸水 | 卯 | 寅 | 丑 | 丑 ✅ |

阴干之气**主静而退**，寄于冠带位。注意阴干一律**不寄禄**——例如己禄在午，但己寄未而非午。

### 3.3 戊己的特殊性（随丙丁）

戊己为中央土，无专属旺地，六壬主流取"**戊随丙寄巳、己随丁寄未**"。

### 3.4 补充观察：阴干寄宫与本气藏干（辅助记忆）

阴干所寄之宫，恰为其**本气藏干**所在：

- 辰藏干：戊、乙、癸 → 乙寄辰
- 未藏干：己、丁、乙 → 丁、己寄未
- 戌藏干：戊、辛、丁 → 辛寄戌
- 丑藏干：己、癸、辛 → 癸寄丑

即：阳干"旺居于禄"，阴干"退藏于库"，互为对照。此规律可用于**记忆与程序校验**，但寄宫的法定依据仍是"阳干寄禄、阴干寄冠带"。

## 四、排盘中的应用（软件算法视角）

### 4.1 四课第一课的定位流程

```
日干（如"辛"）
  │ ① 查寄宫表
  ▼
地盘宫位（"戌"）
  │ ② 取该宫上方的天盘神
  ▼
干上神（"未"）──→ 构成第一课：辛 → 未
```

### 4.2 伪代码

```python
# 寄宫表（固定数据，直接查表，无需计算）
JI_GONG = {
    "甲": "寅", "乙": "辰", "丙": "巳", "丁": "未", "戊": "巳",
    "己": "未", "庚": "申", "辛": "戌", "壬": "亥", "癸": "丑",
}

def 干上神(gan, 天盘):
    """天盘: dict，键为地盘宫位，值为该宫上方的天盘地支"""
    宫位 = JI_GONG[gan]      # ① 日干 → 寄宫（地盘宫位）
    return 天盘[宫位]         # ② 宫位上方天盘神

# 示例：辛丑日，月将辰（天盘戌宫之上为未）
# 干上神 = 天盘["戌"] = "未"  → 第一课：辛 / 未
```

### 4.3 软件实现易错点

1. **寄宫只用于日干定位**：课中其它天干（如五子元遁配出的天干）不再寄宫；
2. **戊寄巳**（勿误为寄辰），**己寄未**（勿误为寄午）；
3. **寄宫 ≠ 五子元遁**：寄宫是"天干 → 地盘宫位"（定位置），五子元遁是"地支 → 天干"（配干支），两套机制不可混用；
4. **查询的是地盘宫位**：上神取"该宫上方的天盘神"，与天盘自身序列无关；
5. **甲寄寅不是特例**：与其它阳干同为"阳干寄禄"，规则一致（四课文档中"甲寄寅是特例"的表述仅为强调，实际规则相同）。

1. 寄宫是**日干参与排盘的第一步**，把天干安放到地盘十二宫之一；
2. 规则简洁：**阳干寄禄、阴干寄冠带、戊随丙、己随丁**，十干寄宫均为固定值，适合查表实现；
