

天乙贵人（简称“贵人”）是六壬、八字、奇门等术数里**第一尊神**，排法只有一句话：

> **甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸蛇兔藏，六辛逢马虎，此是贵人方。**

### **正确的十二天将排布规则（区分昼夜）**

#### **一、定昼夜（用于选择“贵人”的地支）**
- **昼**：占时在日支之后。使用 **“昼贵人”** 口诀所对应的地支（如甲日昼贵在丑）。
- **夜**：占时在日支之前。使用 **“夜贵人”** 口诀所对应的地支（如甲日夜贵在未）。

**这一步的目的，仅仅是确定“贵人”这个基准点应该放在哪个地支上。**

#### **二、定顺逆（关键规则，与“昼夜”无关）**
天将盘的顺布或逆布，**唯一取决于“贵人”所在地盘宫位的“天门地户”分野**：

- **顺布（顺时针排布）**：当**贵人**落在地盘的**亥、子、丑、寅、卯、辰** 这六个宫位时。
  - 口诀：**“天门辰巳地户戌亥，贵人临天门（及之前）则顺行”**
  - 逻辑：亥至辰为阳气上升、事务发端之位，故天将顺布以应之。

- **逆布（逆时针排布）**：当**贵人**落在地盘的**巳、午、未、申、酉、戌** 这六个宫位时。
  - 口诀：**“贵人临地户（及之后）则逆行”**
  - 逻辑：巳至戌为阴气渐盛、事务收降之位，故天将逆布以应之。

#### **三、排布流程**
1.  **定基准**：根据昼夜，选定“贵人”的地支（如夜占得未）。
2.  **安贵人**：将选定的“贵人”地支，加临地盘**占时**的宫位之上（贵加占时）。
3.  **判顺逆**：看“贵人”**在地盘上**落在哪个宫位（亥至辰则顺，巳至戌则逆）。
4.  **布神将**：
    - **顺布**：从贵人开始，按 **贵→螣→朱→六→勾→青→空→白→常→玄→阴→后** 的顺序，在天盘上顺时针填入后续宫位。
    - **逆布**：从贵人开始，按 **贵→后→阴→玄→常→白→空→青→勾→六→朱→螣** 的顺序，在天盘上逆时针填入后续宫位。

> **说明**：贵人加于占时，而非初传。排盘管线为"月将加占时排天盘 → 排四课 → 排三传 → 布天将"；贵人由日干+昼夜占时确定，随天盘阶段即定，不能依赖三传（初传）结果，否则布将与三传形成循环依赖。

### **总结**
- **昼夜** 只影响用哪个“贵人”（丑还是未）。
- **顺逆** 只取决于“贵人”**落地盘的哪个区域**（亥辰顺，巳戌逆）。

所以，您最初的那句话应修正为：
**“十二天将以固定顺序，根据贵人落地盘之宫位，分顺逆两种方向排布于天盘之上。”**

### 二、校验发现的问题与修正

**问题 1：'定昼夜'规则与主流矛盾（已修正）**

文档"定昼夜"一节称"占时在日支之后为昼、在日支之前为夜"，这与同文档"卯酉分界"规则**相互矛盾**，且"日支比较法"并非主流规则。

- 主流规则（《六壬大全》体系）：**纯以占时定昼夜**——卯至申为昼、酉至寅为夜，与日支无关；
- **修正**：数据文件采用卯酉分界，日支比较法未纳入。

**问题 2：'安贵人'位置（已定论：贵加占时）**

原稿曾称"将贵人地支对准**天盘初传**位置"，经校验确定不采用：

- **定论**：统一采用主流"**贵人加于占时**"（贵加占时）——贵人由**日干 + 昼夜占时**确定，随天盘阶段即定，加临地盘占时宫位；
- **理由**：排盘管线为"排天盘 → 排四课 → 排三传 → 布天将"，若贵人依赖初传，布将需等待三传结果，形成**循环依赖**，排盘引擎无法单向执行；
- 数据文件 `../json/十二天神与贵人.json` 已按此定论更新。

**问题 3：十二天将属性缺失（已补充）**

文档未给出十二天将的**五行、阴阳、吉凶、所主**属性，排盘显示与断课需要。已按标准六壬资料补充于 JSON 的 `十二天将.属性`（含干支、五行、吉凶、所主），并按传统**六吉六凶**分类（吉：贵人、六合、青龙、太常、太阴、天后；凶：螣蛇、朱雀、勾陈、天空、白虎、玄武）。
