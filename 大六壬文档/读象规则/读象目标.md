### 目标

- 将“读象”从堆信息转为“抓主象、给线索、可解释、可复盘”。

- 以场景化、证据化、叙事化三条主线组织界面与算法，使使用者更容易“看见”关键。‘

  

  

### 核心理念

- 主象先行：先给“1–3个最关键象”，再渐进展开细节。

- 场景驱动：根据问题类别（财、婚、出行、健康等）动态重排权重与展示。

- 证据链闭环：每条结论都可点开看到来源、规则、冲突与置信度。

- 轻量动效：仅用微动与高亮传达重点，避免华而不实的动画。

### 交互层（读象入口）

- 焦点模式：在 LiurenPaipan.ets 顶部加入“场景 Chips”（如 财/婚/出行/健康 ），切换后只显示该场景的主象与相关证据。

- 主象卡片：以卡片列出 Top-3 信号，包含“象名、强度、方向（吉/凶）、一句断语草稿”。点击展开证据。

- 证据卡片群：围绕 四课 与 三传 的来源明确列出“来源、规则、权重、冲突/合、时效性”。

- 高亮引导：复用现有 isLearningMode 与 shouldHighlightElement ，在焦点模式下仅高亮当前场景相关的盘位与文字。

- 渐进披露：默认只见主象与一句话结论；需要时再展开详细信息（ heavenData 、 heavenGods 、 sikeResult ）。

- 工具式提示：使用现有 showTooltip/tooltipContent 输出“下一步建议”（如“查看初传是否制化官鬼”）。

  
### 算法层（信号与评分）

- 信号抽取：从 四课/三传/月将/贵人/合冲刑害 等生成标准化“信号”，每个信号含 id/source/polarity/weight/scope/confidence 。

- 场景权重表：为 财/婚/出行/健康 等定义不同权重映射，使同一盘在不同场景呈现不同主象。

- 聚合与冲突：将信号聚合为“主象/辅象/噪声”，对合冲刑害做冲突消解（如官鬼被合制则降权）。

- 置信度模型：根据来源层级（ 三传 > 四课 > 其他 ）、一致性、时效性（占时相关）计算 confidence 。

- 一句话生成：模板化 断语草稿 （如“财象旺而受制，短期收益有波折”），并附可编辑区。



### 呈现层（视觉表达）

- 盘面热度环：在天盘内圈加细窄“热度环”，颜色深浅表示信号强度，不改布局、不遮挡文字。

- 关键位标注：仅对与主象相关的地支/天干增粗描边或轻微背景色（避免大面积动效）。

- 证据路径：在卡片内用“来源标签”（ 三传·初传 、 四课·上神 等）串联证据链。

- 决策提示：卡片底部用 tag 告知“建议观察项”（如“有制合，警惕暗损”）。

### 学习层（引导与复盘）

- 读象路径：在学习模式中新增“场景→主象→证据→冲突→结论”的导航序列。

- 自评与校准：展示“我与系统结论的差异”，记录个人判断并生成复盘笔记。

- 案例对照：接入 ZhongHuang_EntrytotheEssence.ets 的条目作为经典提示，卡片内引用相关条文。


### 数据结构建议

- Signal ： { id, source, scope, polarity, weight, confidence, summary, relatedNodes } 。

- SignalScope ： '财' | '婚' | '出行' | '健康' | '通用' 。

- AggregatorResult ： { primary: Signal[], secondary: Signal[], noise: Signal[] } 。

- Narrative ： { oneLiner, rationale[], conflicts[] } 。
