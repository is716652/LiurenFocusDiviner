在大六壬中，“贵人”是否对日干（即第一课的下神）产生帮助，需依据以下几个核心规则来判断：

---

### ✅ 一、贵人是否**临日干**或**发用**

这是最直接的判断标准：

- **贵人加临日干上神**（即第一课的上神），或**贵人入传发用**，主有贵人扶持，即使课体凶，也可转凶为吉。
- 若贵人**临日德**或**作日德**，更是吉上加吉，主意外之喜、升迁、得助等。

---

### ✅ 二、贵人是否**生扶日干**

贵人虽临，但若**所临之神克日干**，或**贵人下神克日干**，则反而为“化鬼”，贵人无力，甚至为害：

- 例：贵人临德神，但德神克日干，且其下神也克日干，称为“德神化鬼”，反为凶象。
- 若贵人所临之神**生扶日干**，或其下神生扶日干，则贵人真正发挥作用，主有实质帮助。

---

### ✅ 三、贵人是否**受制、入墓、空亡**

贵人虽临，但若处于以下状态，则**无力助人**：

| 状态                               | 含义     | 影响                       |
| ---------------------------------- | -------- | -------------------------- |
| **贵人入墓**（如丑贵入辰宫） | 贵人被困 | 无力相助，甚至主官非、入狱 |
| **贵人受制**（如被下神克）   | 用神受伤 | 不可依仗，反主阻碍         |
| **贵人空亡**                 | 虚而不实 | 虽有贵人名，无其实助       |
| **贵人逆行**                 | 动而无力 | 主事多反复，贵人不应       |

---

### ✅ 四、贵人是否**乘旺相之气**

贵人所乘之神（即其所在的地支）若**旺相**，则贵人有力；若**休囚死绝**，则贵人虽在，亦难发力：

- 旺相贵人：主贵人主动出面，助力明显。
- 死绝贵人：主贵人冷漠、无力，或仅表面答应。

---

### ✅ 五、贵人是否**与日干阴阳相合**

贵人与日干**阴阳相合**（如甲日见丑贵，己日见子贵），为“阴阳得配”，主贵人真心相助，内外呼应。

---

### ✅ 总结：贵人助日干的五大条件

| 条件                      | 说明               |
| ------------------------- | ------------------ |
| 1. 临日干或发用           | 贵人主动出面       |
| 2. 生扶日干               | 所临之神或下神生干 |
| 3. 不受制、不入墓、不空亡 | 贵人有实权         |
| 4. 乘旺相之气             | 贵人有力量         |
| 5. 阴阳相合               | 贵人与日干气场契合 |

---
